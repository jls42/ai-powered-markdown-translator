Markdown फ़ाइलों का एक भाषा से दूसरी भाषा में अनुवाद करता है और उनकी
संरचना सुरक्षित रखता है: कोड ब्लॉक, इनलाइन कोड, URL, एंकर, तालिकाएँ और फ़्रंट
मैटर। मॉडल को कॉल करने के ग्यारह तरीके — पाँच API, उपयोग के हिसाब से
शुल्क लिए बिना चार सदस्यताएँ, दो राउटर — और हर मॉडल वास्तव में क्या
सुरक्षित रखता है, इसका प्रकाशित मापन।

## संक्षेप में

- **प्रदाता तक पहुँचने के ग्यारह रास्ते**: OpenAI, Mistral, Claude, Gemini और Grok की API;
  उपयोग के हिसाब से शुल्क लिए बिना ChatGPT (Codex), Grok, Google (Antigravity) और Claude (Claude
  Code) की सदस्यताएँ; OpenCode राउटर (ओपन सोर्स, मुफ़्त या स्थानीय) और OpenRouter
  (400 से अधिक मॉडल)।
- **टोकन खोने से कोई गड़बड़ी नहीं**: कोड ब्लॉक, इनलाइन कोड,
  URL, एंकर और उद्धरणों को कॉल से पहले टोकन से बदला जाता है और
  उत्तर मिलने पर जाँचा जाता है। एक भी टोकन गायब हो, तो फ़ाइल नहीं लिखी जाती।
- **लंबे दस्तावेज़**: मॉडल की संदर्भ विंडो के अनुसार खंडों में विभाजन।
- **`--news` मोड**: अंग्रेज़ी उद्धरणों की सुरक्षा और
  भाषा के अनुसार फ़्लैग का प्रबंधन, निगरानी लेखों के लिए।
- **`--eco` मोड**: तेज़ और कम खर्चीले मॉडल।
- वैकल्पिक **अनुवाद संबंधी टिप्पणी**, ऊपर, नीचे या दोनों जगह।

## स्थापना

```bash
pip install ai-powered-markdown-translator     # ou : pipx install ai-powered-markdown-translator
aipmt --help                                   # ou : python -m aipmt --help
```

Python 3.10 या उससे नया संस्करण। रिपॉज़िटरी से स्थापित करने के लिए,
[योगदान दें](#योगदान-दें) देखें।

## कॉन्फ़िगरेशन

कुंजियाँ तीन स्थानों से पढ़ी जाती हैं, सबसे अधिक प्राथमिकता से सबसे कम प्राथमिकता के क्रम में; हर स्थान
केवल वही जानकारी भरता है जिसे पिछला स्थान खाली छोड़ता है।

|     | कहाँ                                            | किस लिए                             |
| --- | --------------------------------------------- | ------------------------------------- |
| 1   | परिवेश चर                     | CI, कंटेनर, अस्थायी बदलाव |
| 2   | मौजूदा डायरेक्टरी (या किसी पैरेंट डायरेक्टरी) की `.env` | किसी परियोजना की अपनी कुंजी            |
| 3   | `~/.config/aipmt/.env`                        | एक बार स्थापित करें, हर जगह लागू       |

```bash
mkdir -p ~/.config/aipmt
cat > ~/.config/aipmt/.env <<'EOF'
OPENAI_API_KEY=votre-clé-api-openai
XAI_API_KEY=votre-clé-api-xai
MISTRAL_API_KEY=votre-clé-api-mistral
ANTHROPIC_API_KEY=votre-clé-api-anthropic
GOOGLE_API_KEY=votre-clé-api-google
OPENROUTER_API_KEY=votre-clé-api-openrouter
EOF
chmod 600 ~/.config/aipmt/.env
```

`GOOGLE_API_KEY` के स्थान पर `GEMINI_API_KEY` स्वीकार किया जाता है। उपयोगकर्ता
फ़ाइल `XDG_CONFIG_HOME` (केवल पूर्ण पथ) और Windows पर `%APPDATA%`
का पालन करती है। कोई कुंजी न मिलने पर, कमांड तीनों स्थानों की सूची दिखाता है।

**किसी परियोजना की `.env` न कॉल को दूसरी जगह भेज सकती है, न चलाया जाने वाला प्रोग्राम
चुन सकती है।** वह कुंजियाँ देती है, कभी गंतव्य या बाइनरी नहीं: `_BASE_URL`, `_API_BASE`, `_ENDPOINT` या `_BIN` वाले सभी
चर (`CODEX_BIN`,
`GROK_BIN`, `OPENCODE_BIN`, `AGY_BIN`), `GROK_HOME`, प्रॉक्सी (`HTTP_PROXY`,
`HTTPS_PROXY`, `ALL_PROXY`), प्रमाणपत्र भंडार (`SSL_CERT_FILE`,
`SSL_CERT_DIR`, `REQUESTS_CA_BUNDLE`, `CURL_CA_BUNDLE`) और `XDG_CONFIG_HOME` /
`APPDATA` को इसमें चेतावनी के साथ अनदेखा किया जाता है। क्लोन की गई रिपॉज़िटरी को
आपकी कुंजी किसी और जगह भेजने या पहले अनुवाद पर ही अपना प्रोग्राम चलवाने
की अनुमति नहीं होनी चाहिए। यह फ़ाइल इंटरपोलेशन के बिना भी पढ़ी जाती है:
`NOM=${OPENAI_API_KEY}` इसमें कुंजी की प्रतिलिपि नहीं बनाता। ये चर
परिवेश में या `~/.config/aipmt/.env` में रखें।

वैकल्पिक चर: `XAI_BASE_URL` (डिफ़ॉल्ट `https://api.x.ai/v1`),
`CLAUDE_TIMEOUT` (प्रति कॉल सेकंड, डिफ़ॉल्ट 900), `CODEX_BIN`, `CODEX_TIMEOUT`
(डिफ़ॉल्ट 600), `GROK_BIN`, `GROK_HOME` (डिफ़ॉल्ट `~/.grok`), `GROK_TIMEOUT`
(डिफ़ॉल्ट 900), `GROK_TRANSLATE_SANDBOX`, `AGY_BIN`, `AGY_TIMEOUT` (डिफ़ॉल्ट 900),
`OPENCODE_BIN`, `OPENCODE_TIMEOUT` (डिफ़ॉल्ट 600), `OPENROUTER_BASE_URL`
(`https://` आवश्यक), `OPENROUTER_TIMEOUT` (डिफ़ॉल्ट 900),
`OPENROUTER_PREFLIGHT_TIMEOUT` (डिफ़ॉल्ट 30)। हर चर का विवरण उसके
प्रदाता के अनुभाग में दिया गया है।

## शुरुआत करें

```bash
# un fichier
aipmt --file document.md --target_dir out/ --source_lang fr --target_lang en

# un répertoire
aipmt --source_dir content/fr --target_dir content/en --source_lang fr --target_lang en

# un autre provider
aipmt --use_gemini --file document.md --target_dir out/ --target_lang ja
```

`document.md` का स्पेनी में अनुवाद करने पर `--target_dir` में `document-es.md` मिलता है;
`--include_model` के साथ, `document-es-gpt-5.6-terra.md`। एक्सटेंशन हमेशा
`.md` बनता है — `article.mdx` से `article-en.md` बनता है — सिवाय
`--keep_filename` के साथ, जो मूल नाम बनाए रखता है। पहले से मौजूद अनुवाद
को `--force` के बिना छोड़ दिया जाता है।

निकास कोड: सब कुछ सफल होने या छोड़ दिए जाने पर `0`, किसी फ़ाइल के
विफल रहने पर `1` (मानक त्रुटि आउटपुट पर सूची), कॉन्फ़िगरेशन की समस्या होने पर `2`।
विफल फ़ाइल कभी नहीं लिखी जाती, भले ही लिखने की प्रक्रिया ही विफल हो:
सामग्री पहले बगल की फ़ाइल में लिखी जाती है, फिर उसका नाम बदला जाता है। दोबारा चलाना ही काफ़ी है।

इससे क्या सीख मिलती है:

- **अस्वीकृत अनुवाद, बिगड़ा हुआ अनुवाद नहीं है।** उत्तर में कोई टोकन
  गायब होने पर फ़ाइल नहीं लिखी जाती और उस भाषा को
  अस्वीकृत गिना जाता है। लेख पर Grok के साथ यही होता है: पाँचों गैर-लैटिन
  लिपियों में पहले खंड से ही चार इनलाइन कोड और
  तीन URL खो जाते हैं।
- **एक वाक्य के कारण मॉडल पूरे दस्तावेज़ को अस्वीकार कर सकता है।** Opus 5.5
  इस README का बिना किसी अंतर के अनुवाद करता है, लेकिन किसी निगरानी लेख का नहीं: उसकी
  सुरक्षा जाँचें जीवविज्ञान की एक छोटी ख़बर पर उत्तर रोक देती हैं। फ़ाइल
  नहीं लिखी जाती और aipmt कारण बताता है।
- **यह सुरक्षा व्यवस्था शीर्षकों, तालिकाओं, फ़्रंट मैटर या
  पाठ की जाँच नहीं करती।** कोई मॉडल एक अनुभाग हटा दे, तो उपकरण उस फ़ाइल को
  बिना आपत्ति लिख देता है — Mistral के साथ यही होता है। इन तत्वों को
  टोकन से नहीं बदला जा सकता और मौजूदा सुरक्षा जाँचें इन्हें नहीं परखतीं;
  `scripts/compare_structure.py` खोए हुए अनुभाग का पता लगाता है, लेकिन बाद में।
- **इस README पर Grok का मूल्यांकन नहीं है**: बारह
  भाषाओं के बाद उसका CLI सत्र समाप्त हो गया, जिनमें ग्यारह में कोई अंतर नहीं था। अधूरे परीक्षण अभियान का मूल्यांकन नहीं किया जाता।
- **भाषा से अधिक दस्तावेज़ का घनत्व मायने रखता है।** Grok सामान्य
  README पर ठीक रहता है और लिंक से भरे लेख पर लड़खड़ा जाता है, यहाँ तक कि
  डच में भी।

## सभी विकल्प

| विकल्प                   | विवरण                                                                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------------------------- |
| `--file`                 | अनुवाद के लिए एकल Markdown फ़ाइल (`--source_dir` का विकल्प)                                             |
| `--source_dir`           | Markdown फ़ाइलों वाली स्रोत डायरेक्टरी (डिफ़ॉल्ट: `content/posts`)                                   |
| `--target_dir`           | अनूदित फ़ाइलों के लिए आउटपुट डायरेक्टरी (डिफ़ॉल्ट: `traductions_en`)                                    |
| `--source_lang`          | स्रोत भाषा (डिफ़ॉल्ट: `fr`)                                                                                  |
| `--target_lang`          | लक्ष्य भाषा (डिफ़ॉल्ट: `en`)                                                                                   |
| `--model`                | उपयोग करने के लिए विशिष्ट मॉडल                                                                                  |
| `--eco`                  | किफ़ायती मॉडलों का उपयोग करें                                                                              |
| `--use_mistral`          | Mistral AI API का उपयोग करें                                                                                     |
| `--use_claude`           | Claude API का उपयोग करें                                                                                         |
| `--use_gemini`           | Gemini API का उपयोग करें                                                                                         |
| `--use_grok`             | xAI (Grok) API का उपयोग करें — `XAI_API_KEY` आवश्यक है                                                           |
| `--use_codex`            | ChatGPT सदस्यता के कोटे पर Codex CLI का उपयोग करें                                                    |
| `--use_grok_cli`         | Grok सदस्यता के कोटे पर Grok CLI का उपयोग करें                                                        |
| `--use_antigravity`      | Google AI Pro या Ultra सदस्यता के कोटे पर Antigravity CLI (`agy`) का उपयोग करें                       |
| `--use_claude_code`      | Claude Pro या Max सदस्यता के कोटे पर Claude Code CLI (`claude -p`) का उपयोग करें                      |
| `--use_opencode`         | OpenCode में कॉन्फ़िगर किए गए प्रदाता के साथ OpenCode (ओपन सोर्स) का उपयोग करें ; `--model provider/modèle` आवश्यक है |
| `--use_openrouter`       | OpenRouter का उपयोग करें — `OPENROUTER_API_KEY` और `--model fournisseur/modèle` आवश्यक हैं                          |
| `--force`                | दोबारा अनुवाद अनिवार्य करें                                                                                       |
| `--keep_filename`        | मूल फ़ाइल नाम बनाए रखें                                                                          |
| `--news`                 | समाचार मोड : अंग्रेज़ी उद्धरणों को सुरक्षित रखता है, भाषा के अनुसार फ़्लैग सँभालता है                                      |
| `--add_translation_note` | अनुवाद संबंधी टिप्पणी जोड़ें                                                                                |
| `--note_position`        | टिप्पणी का स्थान : `top`, `bottom` (डिफ़ॉल्ट), या `both`                                                     |
| `--note_format`          | टिप्पणी का प्रारूप : `legacy` (डिफ़ॉल्ट, बोल्ड अनुच्छेद) या `marker`                                            |
| `--include_model`        | आउटपुट फ़ाइल में मॉडल का नाम शामिल करें                                                            |

नौ `--use_*` फ़्लैग परस्पर अनन्य हैं : इनमें से दो को एक साथ इस्तेमाल करना
अस्वीकार किया जाता है।

## प्रदाता

### API के ज़रिए : OpenAI, Mistral, Claude, Gemini, Grok

```bash
aipmt --source_dir content/fr --target_dir content/en --target_lang en             # OpenAI, défaut
aipmt --use_mistral --source_dir content/fr --target_dir content/es --target_lang es
aipmt --use_claude  --source_dir content/fr --target_dir content/de --target_lang de
aipmt --use_gemini  --source_dir content/fr --target_dir content/ja --target_lang ja
aipmt --use_grok    --source_dir content/fr --target_dir content/pt --target_lang pt
```

`--eco` प्रत्येक प्रदाता के किफ़ायती स्तर पर स्विच करता है।

| प्रदाता    | गुणवत्ता (डिफ़ॉल्ट)                                                     | किफ़ायती (`--eco`)      |
| ----------- | -------------------------------------------------------------------- | ------------------------- |
| OpenAI      | `gpt-5.6-terra`                                                      | `gpt-5.6-luna`            |
| Claude      | `claude-sonnet-5-5`                                                  | `claude-haiku-5-5`        |
| Mistral     | `mistral-large-latest`                                               | `mistral-small-latest`    |
| Gemini      | `gemini-3.7-flash`                                                   | `gemini-3.1-flash-lite`   |
| Codex       | `gpt-6.1-sol` (`--model` के ज़रिए `gpt-5.6-sol`, `terra` और `luna` भी) | `gpt-5.6-luna`            |
| Grok API    | `grok-4.6`                                                           | `grok-4.3`                |
| Grok CLI    | `grok-4.7`                                                           | वही — `--eco` का कोई प्रभाव नहीं |
| Antigravity | `gemini-3.8-flash-medium`                                            | `gemini-3.7-flash-low`    |
| Claude Code | `sonnet`, प्रयास `low`                                               | वही — `--eco` का कोई प्रभाव नहीं |
| OpenCode    | `--model provider/modèle` अनिवार्य                                | वही — `--eco` का कोई प्रभाव नहीं |
| OpenRouter  | `--model fournisseur/modèle` अनिवार्य                             | वही — `--eco` का कोई प्रभाव नहीं |

### ChatGPT सदस्यता पर : `--use_codex`

आधिकारिक Codex CLI चलाता है : अनुवाद की खपत ChatGPT सदस्यता के कोटे से
कटती है, इसके लिए API कुंजी या उपयोग के आधार पर बिलिंग नहीं होती।

```bash
pip install openai-codex-cli-bin   # package officiel OpenAI (~250 Mo), ou : npm install -g @openai/codex
codex login
aipmt --use_codex --eco --file README.md --target_dir . --target_lang it
```

- बाइनरी पहले `CODEX_BIN` में, फिर `PATH` में, फिर
  `openai-codex-cli-bin` पैकेज में खोजी जाती है। `~/.codex/auth.json` कभी नहीं पढ़ा जाता।
- `OPENAI_API_KEY` और `CODEX_API_KEY` को उपप्रक्रिया के एनवायरनमेंट से
  हटा दिया जाता है : मौजूद कुंजी कभी भी API पर स्विच नहीं कराती।
- प्रत्येक खंड में 5 घंटे की अवधि का कम से कम एक « संदेश » खर्च होता है — सत्यापन
  विफल होने और दोबारा प्रयास करने पर दो। OpenAI के अनुमान के अनुसार,
  Plus प्लान पर `gpt-5.6-luna` (`--eco`) के लिए
  250-2 000 संदेश/5 h और `gpt-5.6-sol` के लिए 10-100 संदेश मिलते हैं।
- `--model gpt-5.6-sol`, जो 1.16.3 तक डिफ़ॉल्ट था, `--model gpt-5.6-terra`
  और `--model gpt-5.6-luna` भी सदस्यता के ज़रिए चलते हैं।
- सर्वर से 429 मिलने पर फ़ाइल नहीं खोती : Codex अपने आप दोबारा जुड़ता है,
  aipmt बारी पूरी होने की प्रतीक्षा करता है, और यदि अंत में भी 429 रहता है, तो खंड पर
  30 और फिर 60 सेकंड बाद दोबारा प्रयास होता है। जिस मॉडल की खाते को अनुमति नहीं है, वह 400 देता है :
  « ChatGPT खाते के साथ Codex का उपयोग करते समय यह मॉडल समर्थित नहीं है »।
- API से धीमा है, और दस्तावेज़ बड़ा होने पर अंतर बढ़ता है : इस README पर,
  `gpt-5.6-sol` के साथ प्रति भाषा माध्यिका समय 6 min 46 s है, जबकि
  `gemini-3.7-flash` के लिए 36 s है।
- CI में अस्वीकृत (`CI` या `GITHUB_ACTIONS` सेट होने पर) : सदस्यता का प्रमाणीकरण
  व्यक्तिगत सत्र फ़ाइल से होता है, जिसे साझा रनर पर नहीं रखा जाना चाहिए।
- वेरिएबल : `CODEX_BIN`, `CODEX_TIMEOUT` (प्रति खंड सेकंड, डिफ़ॉल्ट 600)।

### Grok सदस्यता पर : `--use_grok_cli`

आधिकारिक Grok Build CLI के साथ भी यही सिद्धांत लागू होता है, SuperGrok या
X Premium+ सदस्यता पर।

```bash
curl -fsSL https://x.ai/cli/install.sh | bash
grok login                                      # ou : grok login --device-code
aipmt --use_grok_cli --file README.md --target_dir . --target_lang pl
```

- **Codex से कमज़ोर अलगाव।** Grok का OS सैंडबॉक्स कई नए Linux
  कंप्यूटरों पर लागू नहीं होता (AppArmor, कंटेनर रनटाइम के
  सॉकेट), और लागू न हो सकने वाला प्रोफ़ाइल बिना बताए
  अलगाव के बिना शुरू हो जाता है। इसलिए स्क्रिप्ट डिफ़ॉल्ट रूप से कोई प्रोफ़ाइल नहीं माँगती, इसकी सूचना देती है, और
  CLI के `--deny` नियमों पर निर्भर करती है, जिनमें सभी मामलों पर लागू `*` भी है — यही एकमात्र
  परत है जो बिना बताए सुरक्षा हटाने के बजाय शुरू होने से मना
  करती है। `GROK_TRANSLATE_SANDBOX=read-only` के लिए OS सैंडबॉक्स अनिवार्य है, और यदि मशीन इसे
  लागू नहीं कर सकती तो शुरुआत विफल हो जाती है।
- कोटा साप्ताहिक है, Chat, Imagine और Voice के साथ साझा होता है, और उसे
  पढ़ने के लिए कोई कमांड नहीं है : एक बैच बिना किसी संकेत के बातचीत के
  उपयोग का कोटा खर्च कर सकता है।
- वेरिएबल : `GROK_BIN`, `GROK_HOME` (CLI की डायरेक्टरी, डिफ़ॉल्ट `~/.grok`),
  `GROK_TIMEOUT` (डिफ़ॉल्ट 900), `GROK_TRANSLATE_SANDBOX`।

टोकन के हिसाब से बिल नहीं बनता। इस कोटे तक पहुँचने का यही एकमात्र तरीका है : Gemini CLI
18 जून 2026 से इन खातों के लिए उपलब्ध नहीं है
([घोषणा](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)),
और Antigravity SDK केवल API कुंजी या Google Cloud प्रोजेक्ट स्वीकार करता है।

```bash
# agy 1.2.11 ou plus récent : https://antigravity.google/docs/cli/install/
agy                                  # une fois : se connecter avec le compte de l'abonnement
aipmt --use_antigravity --file README.md --target_dir . --target_lang en
agy -p /usage --output-format json   # quota restant, sans en consommer
```

- **भुगतान वाला कोई रास्ता खुला नहीं रहता।** agy को आपके
  एनवायरनमेंट से केवल वेरिएबल की एक निश्चित सूची मिलती है — `PATH`, भाषा और समय क्षेत्र,
  टर्मिनल, पहचान, प्रॉक्सी और प्रमाणपत्र, सत्र बस — और कोई कुंजी नहीं :
  इसके कई वेरिएबल बिना कुछ दिखाए कॉल का रास्ता बदल देते हैं (मापन में पाया गया :
  एक दस्तावेज़ को तृतीय पक्ष के गेटवे पर भेजता है, दूसरा बिल किए जाने वाले
  Google Cloud प्रोजेक्ट पर), और निषिद्ध वेरिएबल की सूची की हर समीक्षा में कुछ छूट जाते थे।
  किसी भी खंड से पहले, `agy -p /config`, जिसमें कोई कोटा खर्च नहीं होता, को दिखाना
  होगा कि भुगतान वाले AI क्रेडिट अक्षम हैं और न API कुंजी है, न Google Cloud प्रोजेक्ट — कोई
  सेटिंग अनुपस्थित होने पर अस्वीकृति होती है —, वरना कोई अनुवाद नहीं होता ; इसके बाद प्रत्येक
  कॉल के लॉग में सदस्यता की पुष्टि (`authMethod=consumer`) होनी चाहिए, वरना
  उत्तर अस्वीकार कर दिया जाता है।
- **अलगाव।** प्रत्येक कॉल एक निजी, अस्थायी होम डायरेक्टरी में
  चलता है, ऐसे अनुवाद एजेंट के साथ जिसके पास कोई टूल नहीं है : आपकी सेटिंग, नियम,
  प्लगइन, MCP सर्वर और agy हुक उसमें नहीं पहुँचते, आपके इतिहास
  में कुछ नहीं जुड़ता, और लॉगिन कीरिंग में रहता है, जिसे aipmt कभी नहीं पढ़ता।
  एजेंट न मिलने पर agy चुपचाप अपने कोडिंग एजेंट
  और उसके टूल पर लौट जाता है : लॉग की एक पूरी पंक्ति में सही एजेंट की पुष्टि होनी चाहिए — उस
  संदेश को उद्धृत करने वाला दस्तावेज़ उसका विकल्प नहीं है —, वरना अस्वीकृति होती है।
- **प्लेटफ़ॉर्म** : Linux, ऐसे सत्र में जिसमें कीरिंग हो (D-Bus सत्र
  बस, Secret Service) ; macOS स्वीकार किया जाता है, लेकिन उस पर मापन नहीं किया गया है। Windows
  पर अस्वीकृत, जहाँ agy प्रत्येक कॉल को अलग रखने वाले वेरिएबल नहीं पढ़ता, और
  सत्र बस के बिना Linux पर भी — SSH सत्र, कंटेनर, सर्वर : वहाँ agy
  अपना टोकन `~/.gemini` की एक फ़ाइल में रखता है, जिसे अलगाव छिपा देता है।
  किसी भी लॉन्च से पहले कारण सहित अस्वीकृति मिलती है, लॉगिन कोड के लिए
  एक मिनट की प्रतीक्षा के बजाय।
- **मॉडल** : `agy models` के मॉडल। Gemini के नाम में प्रयास शामिल होता है
  (`gemini-3.8-flash-medium`…) : प्रत्यय के बिना नाम कॉल से पहले ही अस्वीकार कर दिया जाता है,
  और `--reasoning_effort` का कोई प्रभाव नहीं होता। डिफ़ॉल्ट `gemini-3.8-flash-medium` है,
  और `--eco` में `gemini-3.7-flash-low` ; जिन परीक्षण अभियानों के आधार पर इन्हें चुना गया, उनका
  वर्णन [विस्तृत मापन](#विस्तृत-माप) में है। Claude और GPT-OSS
  का अपना कोटा है, जो बहुत छोटा है : मापी गई प्रत्येक कॉल में 5 घंटे की अवधि का
  लगभग 1 %, जबकि Flash में 0,05 %।
- **कोटा** : प्रत्येक समूह के लिए 5 घंटे की एक अवधि और एक साप्ताहिक अवधि,
  टोकन लागत के अनुपात में। लेखक के खाते पर मापा गया : प्रति दस लाख स्रोत अक्षरों पर
  5 घंटे की अवधि के लगभग 16 अंक
  `gemini-3.8-flash-medium` में, 14 अंक `gemini-3.7-flash-medium` में और कम
  प्रयास पर 7 से 8 अंक — इसलिए 40 000 अक्षरों के README में आधे
  अंक से थोड़ा अधिक खर्च होता है। साप्ताहिक सीमा स्तर पर निर्भर करती है। दोबारा प्रयास
  agy के पुनः प्रयास योग्य बताए गए मामलों के अनुसार होता है ; अन्यथा, समाप्त हो चुकी अवधि में कभी
  दोबारा प्रयास नहीं होता : `/usage` में दिखाए गए रीसेट तक
  हर फ़ाइल विफल होती है।
- **API से धीमा** : मापन वाले सघन लेख पर, प्रति भाषा माध्यिका समय
  `gemini-3.8-flash-medium` में 3 min 59 s और
  `gemini-3.7-flash-medium` में 3 min 14 s है, जबकि API से Gemini 3.7 Flash के लिए 1 min 18 s है।
- **बीच में रोकना** : Ctrl-C या टर्मिनल बंद करने पर agy भी
  कमांड के साथ रुक जाता है, उसे आपके कोटे पर अपनी बारी पूरी करते रहने नहीं दिया जाता ; यही
  Codex, Grok CLI और OpenCode के लिए भी लागू होता है। `nohup` के अंतर्गत अनुवाद जारी रहता है।
- CI में अस्वीकृत (`CI` या `GITHUB_ACTIONS` सेट होने पर) : लॉगिन व्यक्तिगत
  कीरिंग में रहता है। रनर पर, `GOOGLE_API_KEY` के साथ `--use_gemini` का उपयोग करें।
- वेरिएबल : `AGY_BIN` (अन्यथा `PATH`, फिर `~/.local/bin/agy`),
  `AGY_TIMEOUT` (प्रति खंड सेकंड, शुरुआत का समय शामिल, डिफ़ॉल्ट 900)।

**केवल सार्वजनिक दस्तावेज़।** उन्हीं शर्तों के अनुभाग 5 के अनुसार,
आदान-प्रदान — प्रॉम्प्ट, उत्तर, मेटाडेटा — Google के उत्पादों और मशीन लर्निंग
को बेहतर बनाने के लिए इस्तेमाल किए जा सकते हैं और मनुष्यों द्वारा पढ़े जा सकते हैं,
भुगतान वाली सदस्यता में भी। इससे बाहर निकलने के लिए

### Claude सदस्यता पर: `--use_claude_code`

यही सिद्धांत Claude Code के आधिकारिक CLI `claude` पर भी `-p` मोड में लागू होता है: जो
Claude Pro या Max के लिए भुगतान करते हैं, उनके अनुवाद की खपत सदस्यता के
कोटे से काटी जाती है, प्रति टोकन शुल्क नहीं लिया जाता। इसे
`--use_claude` से भ्रमित न करें, जो Anthropic का API है और उपयोग के अनुसार शुल्क लेता है।

```bash
claude                                   # une fois : /login avec le compte de l'abonnement
aipmt --use_claude_code --file README.md --target_dir . --target_lang en
```

- **भुगतान वाला कोई रास्ता खुला नहीं रहता, और हर कॉल इसका प्रमाण देता है।** Claude
  Code को आपके परिवेश से केवल चरों की एक सीमित सूची मिलती है — न
  API कुंजी, न टोकन, न क्लाउड प्रदाता, न उस Claude Code सत्र का कोई चिह्न
  जिससे aipmt शुरू किया गया हो। पहले खंड से पहले, `claude auth status` में
  Console कुंजी के बिना सदस्यता वाला लॉगिन दिखना चाहिए, और `/usage`, जो
  कोई कोटा खर्च नहीं करता, को इसकी पुष्टि करनी चाहिए; हर कॉल भी अपनी
  आरंभीकरण घटना में इसकी पुष्टि करता है, अन्यथा उत्तर अस्वीकार कर दिया जाता है।
- **« अतिरिक्त उपयोग » अक्षम करें** (claude.ai, सेटिंग्स → उपयोग), ताकि
  खर्च शून्य यूरो बना रहे: सक्षम होने पर, यह किसी अवधि का कोटा समाप्त होते ही
  उसकी जगह ले लेता है और बिना त्रुटि दिखाए शुल्क लगाता है। किसी कॉल की
  कोटा रिपोर्ट में इसका संकेत मिलते ही aipmt अनुवाद रोक देता है, लेकिन उस कॉल की खपत तब तक गिनी जा चुकी होती है।
- **कोटा आपके Claude Code सत्रों के साथ साझा होता है।** हर कॉल
  5 घंटे और सप्ताह की अवधियों का उपयोग बताता है; 80 % से अधिक होने पर
  (`AIPMT_CLAUDE_MAX_UTILIZATION`), कोई अगला खंड शुरू नहीं किया जाता, ताकि
  आपके काम के लिए उपयोगी कोटा समाप्त न हो जाए।
- **पृथक्करण।** हर कॉल बिना किसी टूल के, एक निजी और
  अस्थायी निर्देशिका में, बिना अनुकूलन वाले मोड में चलता है: न आपके `CLAUDE.md`, न आपके प्लगइन,
  हुक, MCP सर्वर या सेटिंग्स लोड किए जाते हैं, और सत्र का
  कुछ भी सहेजा नहीं जाता। संलग्नक बंद रहते हैं: आपके दस्तावेज़ में मौजूद `@chemin`
  केवल पाठ बना रहता है और कोई फ़ाइल नहीं खोलता (मापकर जाँचा गया)।
- **मॉडल**: डिफ़ॉल्ट रूप से `sonnet`, प्रयास स्तर `low` पर, और `--eco` में भी:
  `--eco` इस रास्ते पर कुछ नहीं बदलता। उन्हीं दस्तावेज़ों पर मापने पर, `haiku`
  दोगुना धीमा है — यह तर्क करता है और इसे रोकना संभव नहीं है — जबकि
  लागत बस थोड़ी कम है, और `opus` जीवविज्ञान की कुछ सामग्री अस्वीकार करता है (अगला
  बिंदु)। दोनों `--model` के माध्यम से उपलब्ध रहते हैं; ये उपनाम अपने
  परिवार के नवीनतम मॉडल का अनुसरण करते हैं। `fable` और `[1m]` रूपांतर अस्वीकार किए जाते हैं,
  क्योंकि वे सशुल्क क्रेडिट इस्तेमाल करते हैं। `--reasoning_effort` प्रयास स्तर नियंत्रित करता है,
  जिससे अनुवाद को कोई लाभ नहीं होता: मापा गया तर्क शून्य या लगभग शून्य है।
- **Opus जीवविज्ञान की कुछ सामग्री अस्वीकार करता है।** इसके सुरक्षा उपाय
  Sonnet से अधिक कड़े हैं, और Anthropic का त्रुटि संदेश चेतावनी देता है कि वे
  « कभी-कभी जीवविज्ञान अनुसंधान से संबंधित काम को भी चिह्नित कर सकते हैं »। माप में पाया गया:
  उत्पन्न किए गए 279 अणुओं पर एक संक्षिप्त समाचार के कारण लेख सभी चौदह
  भाषाओं में अस्वीकार हुआ। कुछ भी नहीं लिखा जाता: aipmt अधूरा उत्तर अस्वीकार करता है,
  सुरक्षा उपायों का नाम बताता है और `--model sonnet` की सलाह देता है।
- CI में (`CI` या `GITHUB_ACTIONS` निर्धारित होने पर) और Windows पर अस्वीकार किया जाता है (मापा नहीं गया)।
- चर: `AIPMT_CLAUDE_BIN` (अन्यथा `PATH`, फिर `~/.local/bin/claude`),
  `AIPMT_CLAUDE_TIMEOUT` (प्रति खंड सेकंड, डिफ़ॉल्ट 900),
  `AIPMT_CLAUDE_MAX_UTILIZATION` (डिफ़ॉल्ट 0.8), `CLAUDE_CONFIG_DIR` (Claude Code का
  खाता, कभी भी किसी परियोजना के `.env` से नहीं लिया जाता); कार्य निर्देशिकाएँ
  `XDG_CACHE_HOME/aipmt/claude-code` के अंतर्गत (डिफ़ॉल्ट `~/.cache`)।

प्रमाण-पत्रों से अनुरोध भेजने की अनुमति नहीं देता », तृतीय-पक्ष
टूलों के लिए API कुंजी को प्राथमिकता देता है, « मुक्त स्रोत परियोजनाओं सहित »,
और उनके उपयोग को सशुल्क क्रेडिट से काटने का अधिकार सुरक्षित रखता है
([Claude सहायता](https://support.claude.com/en/articles/13189465-logging-in-to-your-claude-account))।
कोई भी पाठ ऐसे वितरित टूल के मामले पर स्पष्ट निर्णय नहीं देता जो बाइनरी चलाता है।

**डेटा**: Free, Pro और Max खातों पर, गोपनीयता सेटिंग की अनुमति होने पर
मॉडल प्रशिक्षण Claude Code पर भी लागू होता है
([डेटा पृष्ठ](https://code.claude.com/docs/en/data-usage))। aipmt
कोई स्थानीय प्रतिलेख नहीं रखता (`--no-session-persistence`)। इसके माध्यम से
कोई गोपनीय सामग्री न भेजें।

### अपनी पसंद के प्रदाता की ओर: `--use_opencode`

[OpenCode](https://opencode.ai) एक मुक्त स्रोत कोड एजेंट (MIT) है जो
अपने भीतर कॉन्फ़िगर किए गए प्रदाताओं तक अनुरोध पहुँचाता है: API कुंजी, सदस्यता,
OpenCode Zen गेटवे (मुफ़्त मॉडल, बिना खाते के) या स्थानीय मॉडल। यहाँ दो
रास्तों, Zen और Ollama, को आरंभ से अंत तक मापा गया है।

```bash
curl -fsSL https://opencode.ai/install | bash   # ou : npm install -g opencode-ai
opencode models                                 # les modèles, au format provider/modèle
opencode auth login                             # facultatif : brancher un fournisseur

# gratuit, sans compte ni clé — données utilisables pour l'entraînement
aipmt --use_opencode --model opencode/mimo-v2.5-free --file README.md --target_dir . --target_lang en
# local, hors ligne
aipmt --use_opencode --model ollama/qwen2.5:7b --file README.md --target_dir . --target_lang de
# sur un abonnement déjà payé
aipmt --use_opencode --model github-copilot/gpt-5 --file README.md --target_dir . --target_lang ja
```

`--model` अनिवार्य है: इसके बिना, OpenCode ऐसे मुफ़्त मॉडल पर लौट जाएगा
जिसके संवाद प्रशिक्षण में इस्तेमाल हो सकते हैं, और यह चुनाव आपकी जगह नहीं किया जाता।

हर कॉल का पृथक्करण:

- एक अंतर्निहित कॉन्फ़िगरेशन, जिसे आपके कॉन्फ़िगरेशन पर प्राथमिकता मिलती है, `aipmt` एजेंट निर्धारित करता है,
  जिसके सभी टूल अस्वीकृत हैं (`permission: { "*": "deny" }`), सत्र साझा करना
  अक्षम है, `--pure`, कभी `--auto` नहीं;
- खाली, अस्थायी कार्य निर्देशिका, `OPENCODE_DISABLE_PROJECT_CONFIG` और
  `OPENCODE_DISABLE_CLAUDE_CODE` निर्धारित — इनके बिना, OpenCode प्रॉम्प्ट में
  वर्तमान निर्देशिका का `AGENTS.md` और `~/.claude/CLAUDE.md` जोड़ देता है। वैश्विक
  `~/.config/opencode/AGENTS.md` फिर भी जोड़ा जाता है, OpenCode उसे
  हटाने की अनुमति नहीं देता;
- आउटपुट अनुबंध: वापसी कोड 0, कोई `error` घटना नहीं, कोई
  टूल कॉल नहीं, अंतिम चरण `stop` में, पाठ खाली नहीं, और `aipmt` एजेंट
  वास्तव में लोड हुआ हो — अज्ञात `--agent` से OpenCode विफल नहीं होता, वह
  चुपचाप कोडिंग एजेंट पर लौट जाता है;
- `aipmt` की कोई कुंजी नहीं भेजी जाती, सिवाय `OPENCODE_API_KEY` के, जो
  OpenCode की अपनी कुंजी है। प्रदाताओं को OpenCode में कॉन्फ़िगर किया जाता है,
  `aipmt` के `.env` में नहीं।

जानने योग्य बातें:

- Zen के मुफ़्त मॉडल बदलते रहते हैं, उनकी सीमाएँ दस्तावेज़ों में दर्ज नहीं हैं, और
  उनके संवाद प्रशिक्षण के लिए इस्तेमाल हो सकते हैं: सार्वजनिक दस्तावेज़ों
  के लिए, निजी सामग्री के लिए नहीं।
- स्थानीय मॉडल में कम से कम 16 k टोकन का संदर्भ होना चाहिए, क्योंकि खंड
  16 000 वर्णों तक के होते हैं। Ollama अक्सर इसे 4 096 पर कॉन्फ़िगर करता है:
  `PARAMETER num_ctx 32768` के साथ `Modelfile` इस्तेमाल करें।
- `--eco` का कोई प्रभाव नहीं है; `--reasoning_effort` को OpenCode के
  `--variant` के रूप में ज्यों का त्यों भेजा जाता है।
- OpenCode हर सत्र का लॉग `~/.local/share/opencode/` में रखता है।
- चर: `OPENCODE_BIN` (अन्यथा `PATH`, फिर `~/.opencode/bin/opencode`),
  `OPENCODE_TIMEOUT` (प्रति खंड सेकंड, डिफ़ॉल्ट 600)। `OPENCODE_CONFIG`
  ज्यों का त्यों OpenCode को भेजा जाता है।

Ollama के माध्यम से स्थानीय मॉडल का उदाहरण, `~/.config/opencode/opencode.json` में:

```bash
ollama pull gpt-oss:20b
printf 'FROM gpt-oss:20b\nPARAMETER num_ctx 32768\n' > gpt-oss-20b-32k.Modelfile
ollama create gpt-oss-20b-32k -f gpt-oss-20b-32k.Modelfile
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama (local)",
      "options": { "baseURL": "http://127.0.0.1:11434/v1" },
      "models": {
        "gpt-oss-20b-32k": {
          "name": "gpt-oss 20B (32k, sans réflexion)",
          "limit": { "context": 32768, "output": 8192 },
          "options": { "reasoningEffort": "none" }
        }
      }
    }
  }
}
```

`reasoningEffort: "none"` उस चिंतन को बंद करता है जिसे Ollama इन
मॉडलों पर डिफ़ॉल्ट रूप से सक्रिय करता है और जिसे Modelfile अक्षम नहीं कर सकता। छह
शब्दों के एक वाक्य पर मापा गया: विकल्प के बिना 919 चिंतन टोकन और 68 सेकंड, विकल्प के साथ 9 टोकन।

### 400 से अधिक मॉडलों की ओर: `--use_openrouter`

OpenRouter उपयोग के अनुसार शुल्क लेने वाला राउटर है, जो एक ही क्रेडिट शेष से
तृतीय पक्षों द्वारा होस्ट किए गए मॉडलों तक पहुँच देता है — इनमें खुले चीनी
मॉडल भी हैं, जिन्हें यहाँ कोई अन्य प्रदाता उपलब्ध नहीं कराता।

```bash
aipmt --use_openrouter --model z-ai/glm-5.2 --file README.md --target_dir . --target_lang en
```

`--model` अनिवार्य है। किसी भी शुल्क से पहले चलाई जाने वाली प्रारंभिक जाँच,
रूटिंग की दो विशेषताओं को संभालती है:

- **एक ही मॉडल दर्जनों होस्टिंग प्रदाताओं से मिलता है, जिनकी अधिकतम सीमाएँ
  अलग-अलग होती हैं** — `z-ai/glm-5.3-flash` के लिए 23 होस्टिंग प्रदाता हैं, जिनमें से एक की सीमा
  2 048 आउटपुट टोकन है। प्रारंभिक जाँच `/api/v1/models/{modèle}/endpoints` पढ़ती है,
  8 000 आउटपुट टोकन से कम सीमा वाले या खराब स्थिति वाले प्रदाताओं को हटाती है, और
  बाकी को `allow_fallbacks: false` से तय करती है।
- **तर्क का शुल्क आउटपुट की दर से लिया जाता है** — `z-ai/glm-5.2` के
  « ठीक है » उत्तर पर 2 के बजाय 107 टोकन। इसे डिफ़ॉल्ट रूप से बंद किया जाता है; जो मॉडल
  इसे अनिवार्य करते हैं, उन्हें उनके द्वारा स्वीकृत न्यूनतम प्रयास स्तर दिया जाता है, क्योंकि
  सूची का डिफ़ॉल्ट अनुवाद पूरा होने से पहले आउटपुट सीमा भर सकता है।
  `--reasoning_effort` को प्राथमिकता मिलती रहती है।

```
→ OpenRouter : 30 hébergeur(s) épinglé(s) sur 33, contexte 1048576 tokens,
  sortie plafonnée à 32768, raisonnement coupé
```

- संदर्भ विंडो सूची से ली जाती है। 16 400 टोकन से कम वाला मॉडल
  किसी भी कॉल से पहले अस्वीकार कर दिया जाता है: प्रॉम्प्ट और खंड के लिए 8 400,
  और आउटपुट के लिए कम से कम 8 000।
- सूची में स्लग न होने, सूची तक पहुँच न होने, या
  अधिकतम सीमा पूरी करने वाला होस्टिंग प्रदाता न मिलने पर कमांड रुक जाती है।
- खाली आउटपुट के साथ `finish_reason=length` का अर्थ है कि बजट
  तर्क में खर्च हुआ है, आउटपुट कटा नहीं है: संदेश यह अंतर स्पष्ट करता है।
- `--eco` का कोई प्रभाव नहीं है।
- चर: `OPENROUTER_API_KEY` (<https://openrouter.ai/keys>),
  `OPENROUTER_BASE_URL` (डिफ़ॉल्ट `https://openrouter.ai/api/v1`, `https://`
  आवश्यक), `OPENROUTER_TIMEOUT` (डिफ़ॉल्ट 900), `OPENROUTER_PREFLIGHT_TIMEOUT`
  (डिफ़ॉल्ट 30)।

### अनुवाद टिप्पणी

`--add_translation_note` एक टिप्पणी जोड़ता है, `bottom` (डिफ़ॉल्ट), `top` (फ्रंट मैटर
के बाद) या `both` (`--note_position`) में, `legacy` प्रारूप (मोटे अक्षरों वाला
अनुच्छेद, डिफ़ॉल्ट) या `marker` (`--note_format`) में। `marker` प्रारूप एक
अदृश्य Markdown संदर्भ परिभाषा है,
`[ai-translation-note-<placement>]: <> "v=1 source=… target=… model=… date=…"`,
जिसके बाद मोटे अक्षरों में एक उद्धरण आता है: GitHub पर पढ़ने योग्य, और बिल्ड के दौरान
remark प्लगइन द्वारा इस्तेमाल करने योग्य।

```bash
aipmt --file article.mdx --target_lang en --add_translation_note --note_format marker --note_position top
```

## विस्तृत माप

सभी माप `aipmt` से वास्तव में किए गए अनुवादों के हैं,
चौदह भाषाओं में: en, es, de, it, pt, nl, pl, sv, ro, ja, ko, zh, ar, hi।
**लिखी गईं** उन फ़ाइलों की संख्या है जिन्हें सुरक्षा जाँचों ने पास किया; **बिना
अंतर** वे हैं जिनमें `scripts/compare_structure.py` को कुछ नहीं मिलता — अनुभागों,
उपशीर्षकों, लिंक, अलग-अलग URL, कोड ब्लॉक,
इनलाइन कोड, तालिका पंक्तियों, उद्धरण ब्लॉक और मोटे अक्षरों वाले शब्दों की संख्या समान है।

« बिना अंतर » का अर्थ « कुछ पता नहीं चला » है, « बिल्कुल समान » नहीं: तुलना करने वाला
घटकों को गिनता है, उनकी सामग्री नहीं पढ़ता। वह न तो हटाए गए स्तर 4 के शीर्षक,
न बदले गए इनलाइन कोड के पाठ, न बदले गए ध्वज,
और न ही एक अतिरिक्त कोष्ठक के साथ बने ऐसे आंतरिक लिंक को पकड़ता है,
`[texte]((#ancre))`, जो अब कहीं नहीं जाता — और वह भाषा का
मूल्यांकन भी नहीं करता।

`--use_antigravity` की पंक्तियाँ 26 सितंबर को उसी
लेख पर, एक साथ चार अनुवाद चलाकर मापी गईं: सुबह `gemini-3.7-flash-medium`,
दोपहर `gemini-3.8-flash-medium`। अंग्रेज़ी में, दोनों ने उद्धरणों के नीचे की

और अंग्रेज़ी उद्धरण जस के तस रहे: वैकल्पिक सफ़ाई प्रक्रिया को
कुछ नहीं करना पड़ा। `--eco` (`gemini-3.7-flash-low`) में, केवल चार भाषाओं
(en, ja, ar, hi) पर: 4 में से 4 लिखी गईं, सभी बिना अंतर के, माध्यिका
1 min 52 s। उसी दिन समाचार संकलन के एक अधिक हालिया अंक,
25 सितंबर के अंक (438 पंक्तियाँ, 2 अंग्रेज़ी उद्धरण) पर पुष्टि परीक्षण किया गया,
जिसका ब्लॉग से बाहर `gemini-3.7-flash-medium` से अनुवाद किया गया: 14 में से 14 लिखी गईं, सभी बिना अंतर के, प्रति भाषा
87 से 128 s।

`--use_claude_code` की पंक्तियाँ 26 सितंबर को उसी
लेख पर, एक साथ चार अनुवाद चलाकर, प्रयास स्तर `low` पर मापी गईं। `sonnet` के साथ,
चौदहों भाषाओं में अंग्रेज़ी उद्धरण जस के तस रहे और अंग्रेज़ी में
मॉडल ने फ़्रांसीसी अनुवाद वाली पंक्तियाँ खुद हटा दीं, बिना कोई
ध्वज गढ़े। `opus` ने किसी भी भाषा में नहीं लिखा: हर भाषा में, उसके सुरक्षा उपायों ने
अंतिम खंड पर उत्तर रोक दिया, क्योंकि एक संक्षिप्त समाचार में एक बंधन स्थल के लिए
उत्पन्न 279 अणुओं का उल्लेख था। अकेले भेजने पर भी यह समाचार
« जैव » श्रेणी के अंतर्गत अस्वीकार हुआ; `sonnet` ने इसे हर भाषा में अनूदित किया। `haiku`
चौदहों भाषाओं में लिखता है; तीन में (en, pl, ro), एक अनुभाग का शीर्षक

आउटपुट टोकन का 61 % —, इसलिए इसे `sonnet` से दोगुने से भी अधिक समय लगता है।

### इन मापों को क्या नहीं समझना चाहिए

- **यह संपूर्ण रैंकिंग नहीं है**: अकेला OpenRouter चार सौ से अधिक
  मॉडल उपलब्ध कराता है, लगभग पंद्रह का मापन किया गया है।
- **समय केवल संकेत के लिए हैं**: अभियान के अनुसार तीन से छह अनुवाद एक साथ
  किए गए, और किसी प्रदाता की गति दिन भर बदलती रहती है।
- **ये निश्चित तारीखों के अवलोकन हैं**: एक ही नाम के अंतर्गत मॉडल बदलते रहते हैं, और आपके
  दस्तावेज़ हमारे दस्तावेज़ों से अलग हैं।

```bash
python scripts/compare_structure.py reference.md out/reference-ja.md
# « structure identique », ou la liste des écarts — sortie 0 si identique, 1 sinon
```

## योगदान दें

```bash
git clone https://github.com/jls42/ai-powered-markdown-translator.git
cd ai-powered-markdown-translator
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt   # les dépendances, lock entièrement épinglé
pip install -e .                  # le paquet lui-même, en mode éditable
```

दोनों पंक्तियाँ आवश्यक हैं: `pip install -e .` के बिना, `python -m aipmt`
`No module named aipmt` उत्तर देता है।

गुणवत्ता जाँच के उपकरण, वैकल्पिक लेकिन अनुशंसित:

```bash
pipx install pre-commit               # hors venv — absent des requirements
pip install -r requirements-dev.txt   # detect-secrets, pip-audit, mypy, lizard
pre-commit install                    # hooks rapides à chaque commit
pre-commit install --hook-type pre-push  # mypy, SAST, pip-audit, tests avant chaque push
```

रिपॉज़िटरी के 28 अनुवाद (README और CHANGELOG, चौदह भाषाएँ)
`./regen_translations.sh --force` से दोबारा बनाए जाते हैं — डिफ़ॉल्ट रूप से ChatGPT की सदस्यता पर Codex और `gpt-6.1-sol`,
एक साथ चार। `REGEN_PROVIDER` और
`REGEN_MODEL` प्रक्रिया बदलते हैं: `antigravity` सदस्यता पर ही रहता है,
जो Google की है, और बिना किसी विशेष छूट के चलता है; शुल्क वाली API (`openai`, `gemini`,
`grok`, `openrouter`) को `REGEN_ALLOW_PAID_API=1` के बिना अस्वीकार किया जाता है;
`REGEN_JOB_TIMEOUT` हर जॉब की समय सीमा तय करता है (600 s, Codex और
Antigravity पर 1 800 s)। उपकरणों का विवरण `CLAUDE.md` में है।

  केवल स्थानीय मॉडल का उपयोग करने पर ही कोई डेटा आपकी मशीन से बाहर नहीं जाता।
- **API कॉल का शुल्क आपसे लिया जाता है।** यह प्रोग्राम
  खर्च की सीमा तय नहीं करता: लंबे दस्तावेज़, विफलता के बाद दोबारा प्रयास या अधिक तर्क-विचार करने वाले
  मॉडल की लागत अधिक होती है।
- **प्रकाशित माप निश्चित तारीखों के अवलोकन हैं**, गारंटी नहीं।

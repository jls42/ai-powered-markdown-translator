संरचना को सुरक्षित रखते हुए Markdown फ़ाइलों का एक भाषा से दूसरी भाषा में अनुवाद करता है: कोड ब्लॉक, इनलाइन कोड, URL, एंकर, तालिकाएँ और front matter। मॉडल को कॉल करने के दस तरीके — पाँच API, बिना उपयोग-आधारित बिलिंग वाले तीन सब्सक्रिप्शन, दो राऊटर — और प्रत्येक मॉडल वास्तव में क्या संरक्षित रखता है, इसका एक प्रकाशित माप।

## संक्षेप में

- **दस प्रोवाइडर मार्ग**: OpenAI, Mistral, Claude, Gemini और Grok API;
  बिना उपयोग-आधारित बिलिंग वाले ChatGPT (Codex), Grok और Google (Antigravity)
  सब्सक्रिप्शन; OpenCode (ओपन सोर्स, मुफ़्त या स्थानीय) और OpenRouter
  (400 से अधिक मॉडल) राऊटर।
- **खोए हुए टोकन के कारण कुछ भी गलत नहीं**: कोड ब्लॉक, इनलाइन कोड,
  URL, एंकर और उद्धरणों को कॉल से पहले टोकन से बदल दिया जाता है और
  वापसी पर सत्यापित किया जाता है। यदि कोई भी गायब है, तो फ़ाइल नहीं लिखी जाती है।
- **लंबे दस्तावेज़**: मॉडल की विंडो के अनुसार विभाजन।
- **`--news` मोड**: निगरानी लेखों के लिए अंग्रेज़ी उद्धरण सुरक्षित और भाषा के अनुसार झंडे प्रबंधित।
- **`--eco` मोड**: तेज़ और अधिक किफायती मॉडल।
- वैकल्पिक **अनुवाद टिप्पणी**, ऊपर, नीचे या दोनों जगह।

## कॉन्फ़िगरेशन

कुंजियाँ तीन स्थानों से पढ़ी जाती हैं, सर्वोच्च प्राथमिकता से न्यूनतम तक; प्रत्येक केवल उसी को भरता है जिसे पिछला खाली छोड़ देता है।

|     | कहाँ                                          | किसके लिए                             |
| --- | --------------------------------------------- | ------------------------------------- |
| 1   | पर्यावरण चर (Environment variables)          | CI, कंटेनर, एकमुश्त छूट              |
| 2   | वर्तमान (या पैरेंट) डायरेक्टरी की `.env` | किसी प्रोजेक्ट की अपनी कुंजी          |
| 3   | `~/.config/aipmt/.env`                        | एक बार इंस्टॉल किया गया, हर जगह मान्य |

```bash
mkdir -p ~/.config/aipmt
cat > ~/.config/aipmt/.env <<'EOF'
OPENAI_API_KEY=votre-clé-api-openai
XAI_API_KEY=votre-clé-api-xai
MISTRAL_API_KEY=votre-clé-api-mistral
ANTHROPIC_API_KEY=votre-clé-api-anthropic
GOOGLE_API_KEY=votre-clé-api-google
OPENROUTER_API_KEY=votre-clé-api-openrouter
EOF
chmod 600 ~/.config/aipmt/.env
```

`GOOGLE_API_KEY` के स्थान पर `GEMINI_API_KEY` स्वीकार किया जाता है। उपयोगकर्ता फ़ाइल
Windows पर `XDG_CONFIG_HOME` (केवल निरपेक्ष पथ) और `%APPDATA%` का पालन करती है।
कुंजी के बिना, कमांड तीनों स्थानों की सूची दिखाता है।

**किसी प्रोजेक्ट की `.env` न तो कॉल को रीडायरेक्ट कर सकती है और न ही निष्पादित प्रोग्राम चुन सकती है।** यह कुंजियाँ प्रदान करती है, कभी गंतव्य या बाइनरी नहीं: `_BASE_URL`, `_API_BASE`, `_ENDPOINT` या `_BIN` (`CODEX_BIN`,
`GROK_BIN`, `OPENCODE_BIN`, `AGY_BIN`), `GROK_HOME`, प्रॉक्सी (`HTTP_PROXY`,
`HTTPS_PROXY`, `ALL_PROXY`), प्रमाणपत्र स्टोर (`SSL_CERT_FILE`,
`SSL_CERT_DIR`, `REQUESTS_CA_BUNDLE`, `CURL_CA_BUNDLE`) और `XDG_CONFIG_HOME` /
`APPDATA` में कोई भी चर चेतावनी के साथ अनदेखा कर दिया जाता है। एक क्लोन किए गए रिपॉजिटरी को पहली अनुवाद पर आपकी कुंजी चुराने या अपना स्वयं का प्रोग्राम चलाने में सक्षम नहीं होना चाहिए। यह फ़ाइल बिना इंटरपोलेशन के भी पढ़ी जाती है:
`NOM=${OPENAI_API_KEY}` इसमें कुंजी की प्रतिलिपि नहीं बनाता है। इन चरों को पर्यावरण में या `~/.config/aipmt/.env` में सेट करें।

वैकल्पिक चर: `XAI_BASE_URL` (डिफ़ॉल्ट `https://api.x.ai/v1`),
`CLAUDE_TIMEOUT` (प्रति कॉल सेकंड, डिफ़ॉल्ट 900), `CODEX_BIN`, `CODEX_TIMEOUT`
(डिफ़ॉल्ट 600), `GROK_BIN`, `GROK_HOME` (डिफ़ॉल्ट `~/.grok`), `GROK_TIMEOUT`
(डिफ़ॉल्ट 900), `GROK_TRANSLATE_SANDBOX`, `AGY_BIN`, `AGY_TIMEOUT` (डिफ़ॉल्ट 900),
`OPENCODE_BIN`, `OPENCODE_TIMEOUT` (डिफ़ॉल्ट 600), `OPENROUTER_BASE_URL`
(`https://` आवश्यक), `OPENROUTER_TIMEOUT` (डिफ़ॉल्ट 900),
`OPENROUTER_PREFLIGHT_TIMEOUT` (डिफ़ॉल्ट 30)। प्रत्येक का विवरण उसके प्रोवाइडर अनुभाग में दिया गया है।

## शुरुआत

```bash
# un fichier
aipmt --file document.md --target_dir out/ --source_lang fr --target_lang en

# un répertoire
aipmt --source_dir content/fr --target_dir content/en --source_lang fr --target_lang en

# un autre provider
aipmt --use_gemini --file document.md --target_dir out/ --target_lang ja
```

स्पैनिश में अनुवादित `document.md`, `--target_dir` में `document-es.md` देता है;
`--include_model` के साथ, `document-es-gpt-5.6-terra.md`। एक्सटेंशन हमेशा `.md` बन जाता है — `article.mdx` से `article-en.md` मिलता है — सिवाय
`--keep_filename` के, जो मूल नाम को बनाए रखता है। पहले से मौजूद अनुवाद को
`--force` के बिना छोड़ दिया जाता है।

एग्जिट कोड: `0` यदि सब कुछ सफल रहा या छोड़ दिया गया, `1` यदि कोई फ़ाइल विफल रही (त्रुटि आउटपुट पर सूची), `2` यदि कॉन्फ़िगरेशन समस्याग्रस्त है।
विफल फ़ाइल कभी नहीं लिखी जाती है, भले ही लेखन स्वयं विफल हो जाए:
सामग्री को अलग से लिखा जाता है और फिर नाम बदला जाता है। पुनः चलाना ही पर्याप्त है।

ध्यान देने योग्य मुख्य बातें:

- **अस्वीकृत अनुवाद कोई दूषित अनुवाद नहीं है।** जब वापसी पर कोई टोकन
  गायब होता है, तो फ़ाइल नहीं लिखी जाती है और भाषा को अस्वीकृत माना जाता है।
  यही बात लेख पर Grok के साथ होती है: पाँच गैर-लैटिन लिपियों में पहले खंड से
  ही चार इनलाइन कोड और तीन URL गायब हो गए।
- **यह सुरक्षा कवच शीर्षकों, तालिकाओं, front matter या टेक्स्ट को कवर नहीं करता है।**
  एक मॉडल जो किसी अनुभाग को हटा देता है, वह ऐसी फ़ाइल लौटाता है जिसे उपकरण
  बिना किसी रुकावट के लिख देता है — Mistral का यही मामला है। इन तत्वों को
  टोकन से प्रतिस्थापित नहीं किया जा सकता है, और वर्तमान सुरक्षा गार्ड इनकी जाँच
  नहीं करते हैं; `scripts/compare_structure.py` किसी खोए हुए अनुभाग का पता लगाता है, लेकिन बाद में।
- **इस README पर Grok का कोई स्कोर नहीं है**: इसका CLI सत्र बारह भाषाओं के
  बाद समाप्त हो गया, जिनमें से ग्यारह बिना किसी विचलन के थीं। बाधित अभियान का
  मूल्यांकन नहीं किया जाता है।
- **भाषा से अधिक दस्तावेज़ का घनत्व मायने रखता है।** Grok सामान्य README
  फ़ाइलों को संभाल लेता है और लिंक से भरे लेख पर लड़खड़ा जाता है, जिसमें डच भी
  शामिल है।

तिथियाँ और दस्तावेज़: "यह README" कॉलम को 9 सितंबर 2026 को इस फ़ाइल के एक स्थिर संशोधन (785 पंक्तियाँ, 285 इनलाइन कोड, 89 तालिका पंक्तियाँ) पर मापा गया था, जिसे बाद में संशोधित किया गया — सिवाय Antigravity पंक्ति के, जिसे 26 सितंबर को 1.14.0 के साथ प्रकाशित छोटे संशोधन (600 पंक्तियाँ, 257 इनलाइन कोड, 85 तालिका पंक्तियाँ) पर मापा गया था। "सघन निगरानी लेख" कॉलम 589 पंक्तियों के एक लेख पर 4 और 5 सितंबर के अभियान से आता है, सिवाय Grok पंक्ति के, जिसे 9 सितंबर को उसी निगरानी के दूसरे संस्करण पर पुनः मापा गया था, और Antigravity पंक्ति के, जिसे 26 सितंबर को उसी लेख पर मापा गया था। पूर्ण तालिकाएँ, अवधियाँ और प्रोटोकॉल [विस्तृत माप](#विस्तृत-माप) में हैं।

## Providers

### API द्वारा: OpenAI, Mistral, Claude, Gemini, Grok

```bash
aipmt --source_dir content/fr --target_dir content/en --target_lang en             # OpenAI, défaut
aipmt --use_mistral --source_dir content/fr --target_dir content/es --target_lang es
aipmt --use_claude  --source_dir content/fr --target_dir content/de --target_lang de
aipmt --use_gemini  --source_dir content/fr --target_dir content/ja --target_lang ja
aipmt --use_grok    --source_dir content/fr --target_dir content/pt --target_lang pt
```

`--eco` प्रत्येक प्रदाता के किफायती स्तर पर स्विच करता है।

| Provider    | गुणवत्ता (डिफ़ॉल्ट)                                      | किफायती (`--eco`)      |

| OpenAI      | `gpt-5.6-terra`                                       | `gpt-5.6-luna`            |
| Claude      | `claude-sonnet-5`                                     | `claude-haiku-4-5`        |
| Mistral     | `mistral-large-latest`                                | `mistral-small-latest`    |

| Grok API    | `grok-4.6`                                            | `grok-4.3`                |

### ChatGPT सदस्यता पर: `--use_codex`

आधिकारिक Codex CLI को नियंत्रित करता है: अनुवाद बिना किसी API कुंजी या उपयोग-आधारित बिलिंग के, ChatGPT सदस्यता के कोटे से काटा जाता है।

```bash
pip install openai-codex-cli-bin   # package officiel OpenAI (~250 Mo), ou : npm install -g @openai/codex
codex login
aipmt --use_codex --eco --file README.md --target_dir . --target_lang it
```

- बाइनरी को `CODEX_BIN`, फिर `PATH`, और फिर `openai-codex-cli-bin` पैकेज में खोजा जाता है। `~/.codex/auth.json` को कभी नहीं पढ़ा जाता है।
- `OPENAI_API_KEY` और `CODEX_API_KEY` को सब-प्रोसेस के परिवेश से हटा दिया जाता है: मौजूद कुंजी कभी भी API पर स्विच नहीं कराती है।
- प्रत्येक सेगमेंट 5 घंटे की विंडो में से कम से कम एक "संदेश" की खपत करता है — यदि इसका सत्यापन विफल हो जाता है और इसे पुनः प्रयास किया जाता है तो दो। OpenAI अनुमान के तौर पर Plus प्लान पर `gpt-5.6-luna` (`--eco`) के लिए 250-2,000 संदेश/5 घंटे और `gpt-5.6-sol` के लिए 10-100 संदेश/5 घंटे बताता है।
- `--model gpt-5.6-terra` और `--model gpt-5.6-luna` भी सदस्यता के माध्यम से काम करते हैं। जिस मॉडल का खाता हकदार नहीं है, वह 400 "model is not supported when using Codex with a ChatGPT account" त्रुटि देता है।
- API की तुलना में धीमा, और दस्तावेज़ के साथ यह अंतर बढ़ता जाता है: इस README पर, `gpt-5.6-sol` के साथ प्रति भाषा मीडियन 6 मिनट 46 सेकंड, जबकि `gemini-3.7-flash` के लिए 36 सेकंड।
- CI में अस्वीकृत (`CI` या `GITHUB_ACTIONS` निर्धारित होने पर): सदस्यता एक व्यक्तिगत सत्र फ़ाइल द्वारा प्रमाणित होती है, जिसका किसी साझा रनर पर कोई काम नहीं है।
- वेरिएबल्स: `CODEX_BIN`, `CODEX_TIMEOUT` (प्रति सेगमेंट सेकंड, डिफ़ॉल्ट 600)।

### Grok सदस्यता पर: `--use_grok_cli`

SuperGrok या X Premium+ सदस्यता पर आधिकारिक Grok Build CLI के साथ वही सिद्धांत।

```bash
curl -fsSL https://x.ai/cli/install.sh | bash
grok login                                      # ou : grok login --device-code
aipmt --use_grok_cli --eco --file README.md --target_dir . --target_lang pl
```

- **Codex की तुलना में कमज़ोर अलगाव।** Grok का OS सैंडबॉक्स कई हालिया Linux सिस्टमों (AppArmor, कंटेनर रनटाइम सॉकेट्स) पर लागू नहीं होता है, और जो प्रोफ़ाइल लागू नहीं हो पाती है, वह बिना किसी सूचना के असुरक्षित शुरू हो जाती है। इसलिए स्क्रिप्ट डिफ़ॉल्ट रूप से किसी प्रोफ़ाइल का अनुरोध नहीं करती है, इसकी घोषणा करती है, और CLI के `--deny` नियमों पर निर्भर करती है, जिसमें कैच-ऑल `*` शामिल है — एकमात्र ऐसी परत जो बिना बताए सुरक्षा हटाने के बजाय शुरू होने से इनकार कर देती है। `GROK_TRANSLATE_SANDBOX=read-only` OS सैंडबॉक्स की मांग करता है, और यदि मशीन इसका सम्मान नहीं कर पाती है तो स्टार्टअप विफल हो जाता है।
- कोटा साप्ताहिक है, जो Chat, Imagine और Voice के साथ साझा किया जाता है, और कोई भी कमांड इसे पढ़ने की अनुमति नहीं देती है: कोई बैच बिना किसी चेतावनी के संवादात्मक उपयोग में कटौती कर सकता है।
- वेरिएबल्स: `GROK_BIN`, `GROK_HOME` (CLI डायरेक्टरी, डिफ़ॉल्ट `~/.grok`), `GROK_TIMEOUT` (डिफ़ॉल्ट 900), `GROK_TRANSLATE_SANDBOX`।

### Google सदस्यता पर: `--use_antigravity`

Antigravity के आधिकारिक CLI, `agy` के साथ वही सिद्धांत: जो लोग Google AI Pro या Ultra के लिए भुगतान करते हैं, उनके लिए अनुवाद को टोकन द्वारा बिल किए जाने के बजाय सदस्यता कोटे से काटा जाता है। इस कोटे तक पहुँचने का यह एकमात्र तरीका है: Gemini CLI 18 जून 2026 से इन खातों की सेवा नहीं करता है ([घोषणा](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)), और Antigravity SDK केवल एक API कुंजी या Google Cloud प्रोजेक्ट स्वीकार करता है।

```bash
# agy 1.2.11 ou plus récent : https://antigravity.google/docs/cli/install/
agy                                  # une fois : se connecter avec le compte de l'abonnement
aipmt --use_antigravity --file README.md --target_dir . --target_lang en
agy -p /usage --output-format json   # quota restant, sans en consommer
```

- **कोई भी सशुल्क मार्ग खुला नहीं रहता है।** agy को आपके परिवेश से केवल वेरिएबल्स की एक सीमित सूची प्राप्त होती है — `PATH`, भाषा और समय क्षेत्र, टर्मिनल, पहचान, प्रॉक्सी और प्रमाणपत्र, सत्र बस — और कोई कुंजी नहीं: इसके कई वेरिएबल्स बिना कुछ दिखाए कॉल को स्विच कर देते हैं (परीक्षित: एक दस्तावेज़ को किसी तीसरे पक्ष के गेटवे पर भेजता है, दूसरा बिल किए गए Google Cloud प्रोजेक्ट पर), और एक अस्वीकृति सूची हर समीक्षा में कुछ न कुछ छोड़ देती थी। किसी भी सेगमेंट से पहले, `agy -p /config`, जिसमें कोई कोटा खर्च नहीं होता है, को बिना किसी API कुंजी या Google Cloud प्रोजेक्ट के सशुल्क AI क्रेडिट अक्षम दिखाना चाहिए — किसी सेटिंग की अनुपस्थिति को अस्वीकृति माना जाता है —, अन्यथा कुछ भी अनुवादित नहीं किया जाता है; इसके बाद प्रत्येक कॉल के लॉग को सदस्यता (`authMethod=consumer`) को प्रमाणित करना होगा, अन्यथा प्रतिक्रिया अस्वीकार कर दी जाती है।
- **अलगाव।** प्रत्येक कॉल एक निजी और डिस्पोजेबल होम डायरेक्टरी में, बिना किसी टूल वाले अनुवाद एजेंट के साथ चलती है: आपकी agy सेटिंग्स, नियम, प्लगइन्स, MCP सर्वर और हुक इसमें प्रवेश नहीं करते हैं, आपके इतिहास में कुछ भी नहीं जोड़ा जाता है, और लॉगिन कीचेन में रहता है, जिसे aipmt कभी नहीं पढ़ता है। एक एजेंट न मिलने पर agy बिना बताए अपने कोडिंग एजेंट और उसके टूल्स पर वापस लौट जाता है: लॉग की एक पूरी पंक्ति को सही एजेंट की पुष्टि करनी चाहिए — इस संदेश को उद्धृत करने वाला दस्तावेज़ इसे प्रतिस्थापित नहीं करता है —, अन्यथा अस्वीकार कर दिया जाता है।
- **प्लेटफ़ॉर्म**: Linux, ऐसे सत्र में जिसमें कीचेन (D-Bus सत्र बस, Secret Service) हो; macOS स्वीकृत है, हालाँकि उस पर परीक्षण नहीं किया गया है। Windows पर अस्वीकृत, जहाँ agy प्रत्येक कॉल को अलग करने वाले वेरिएबल्स को नहीं पढ़ता है, और बिना सत्र बस वाले Linux पर — SSH सत्र, कंटेनर, सर्वर: agy अपना टोकन `~/.gemini` की एक फ़ाइल में संग्रहीत करता है, जिसे अलगाव छुपा देता है। लॉगिन कोड के लिए एक मिनट की प्रतीक्षा के बजाय, कारण के साथ अस्वीकृति किसी भी लॉन्च से पहले आ जाती है।
- **मॉडल**: `agy models` वाले मॉडल। Gemini मॉडल अपने नाम में प्रयास रखते हैं (`gemini-3.7-flash-low`…): बिना प्रत्यय वाले नाम को कॉल से पहले ही अस्वीकार कर दिया जाता है, और `--reasoning_effort` का कोई प्रभाव नहीं पड़ता है। चौदह भाषाओं के एक अभियान द्वारा दोनों डिफ़ॉल्ट तय किए गए थे (देखें [विस्तृत माप](#विस्तृत-माप))। Claude और GPT-OSS का अपना कोटा है, जो काफी छोटा है: Flash में 0.05% की तुलना में प्रति मापे गए कॉल पर 5 घंटे की विंडो का लगभग 1%।
- **कोटा**: प्रति समूह, टोकन लागत के अनुपात में 5 घंटे की विंडो और एक साप्ताहिक विंडो। 32 अनुवादों के एक अभियान के आधार पर, लेखक के खाते पर मापा गया: `gemini-3.7-flash-medium` में 40,000 वर्णों के README के लिए 5 घंटे की विंडो का लगभग आधा बिंदु; साप्ताहिक सीमा टियर पर निर्भर करती है। पुनः प्रयास उसका पालन करता है जिसे agy पुनः प्रयास योग्य घोषित करता है; अन्यथा, समाप्त हो चुकी विंडो पर कभी दोबारा प्रयास नहीं किया जाता: यह `/usage` द्वारा प्रदर्शित रीसेट तक प्रत्येक फ़ाइल को विफल कर देता है।
- **API से धीमा**: मापों के सघन लेख पर, Gemini 3.7 Flash सदस्यता के माध्यम से प्रति भाषा मीडियन 3 मिनट 14 सेकंड लेता है, जबकि API के माध्यम से 1 मिनट 18 सेकंड।
- **रुकावट**: Ctrl-C, या बंद टर्मिनल, agy को आपके कोटे पर अपनी बारी समाप्त करने देने के बजाय कमांड के साथ रोक देता है; यही बात Codex, Grok CLI और OpenCode पर भी लागू होती है। `nohup` के तहत, अनुवाद जारी रहता है।
- CI में अस्वीकृत (`CI` या `GITHUB_ACTIONS` निर्धारित होने पर): लॉगिन एक व्यक्तिगत कीचेन में रहता है। रनर पर, `GOOGLE_API_KEY` के साथ `--use_gemini` का उपयोग करें।
- वेरिएबल्स: `AGY_BIN` (अन्यथा `PATH`, फिर `~/.local/bin/agy`), `AGY_TIMEOUT` (स्टार्टअप सहित प्रति सेगमेंट सेकंड, डिफ़ॉल्ट 900)।

**उपयोग की शर्तें: यह आपका खाता है जो दांव पर लगा है।** [Antigravity की शर्तें](https://antigravity.google/terms) (अनुभाग 6) और इसके [FAQ](https://antigravity.google/docs/faq/) खाता निलंबन के जोखिम के तहत Antigravity लॉगिन का उपयोग करके किसी तृतीय-पक्ष सॉफ़्टवेयर द्वारा सेवा तक पहुंचने पर रोक लगाते हैं — Claude Code, OpenClaw और OpenCode का वहाँ उल्लेख किया गया है। aipmt न तो टोकन पढ़ता है और न ही उसका पुनः उपयोग करता है: यह आधिकारिक बाइनरी को उस [हेडलेस मोड](https://antigravity.google/docs/cli/headless/) में लॉन्च करता है जिसे Google स्क्रिप्ट और CI के लिए प्रलेखित करता है। Google के एक सदस्य ने अपने काम के लिए स्थानीय स्क्रिप्ट से `agy -p` लॉन्च करने को "मानक" माना ([आधिकारिक फ़ोरम, 25 सितंबर 2026, गैर-बाध्यकारी उत्तर](https://discuss.ai.google.dev/t/is-using-the-official-agy-cli-through-a-local-mcp-server-with-third-party-ai-agents-permitted/184829)); कोई भी दस्तावेज़ इस तरह के वितरित टूल के मामले पर स्पष्ट निर्णय नहीं देता है।

**केवल सार्वजनिक दस्तावेज़।** उन्हीं शर्तों के अनुभाग 5 के अनुसार, बातचीत — प्रॉम्प्ट, प्रतिक्रियाएँ, मेटाडेटा — का उपयोग Google के उत्पादों और मशीन लर्निंग को बेहतर बनाने के लिए किया जा सकता है और सशुल्क सदस्यता सहित इंसानों द्वारा उनकी समीक्षा की जा सकती है। ऑप्ट-आउट सेटिंग `enableTelemetry` के माध्यम से होता है, जिसके प्रभाव अप्रलेखित हैं और aipmt इसे सेट नहीं करता है; आपकी agy सेटिंग्स इसके अलगाव में लागू नहीं होती हैं। इसके माध्यम से कुछ भी गोपनीय न भेजें।

### अपनी पसंद के प्रदाता की ओर: `--use_opencode`

[OpenCode](https://opencode.ai) एक ओपन-सोर्स (MIT) कोड एजेंट है जो अपने भीतर कॉन्फ़िगर किए गए प्रदाताओं को रूट करता है: API कुंजी, सदस्यता, OpenCode Zen गेटवे (बिना खाते के मुफ़्त मॉडल), या स्थानीय मॉडल। यहाँ दो तरीकों का शुरू से अंत तक परीक्षण किया गया है, Zen और Ollama।

```bash
curl -fsSL https://opencode.ai/install | bash   # ou : npm install -g opencode-ai
opencode models                                 # les modèles, au format provider/modèle
opencode auth login                             # facultatif : brancher un fournisseur

# gratuit, sans compte ni clé — données utilisables pour l'entraînement
aipmt --use_opencode --model opencode/mimo-v2.5-free --file README.md --target_dir . --target_lang en
# local, hors ligne
aipmt --use_opencode --model ollama/qwen2.5:7b --file README.md --target_dir . --target_lang de
# sur un abonnement déjà payé
aipmt --use_opencode --model github-copilot/gpt-5 --file README.md --target_dir . --target_lang ja
```

`--model` अनिवार्य है: इसके बिना, OpenCode एक मुफ़्त मॉडल पर वापस चला जाएगा जिसकी बातचीत का उपयोग प्रशिक्षण के लिए किया जा सकता है, और यह विकल्प आपकी जगह नहीं चुना जाता है।

प्रत्येक कॉल पर अलगाव:

- एक इनलाइन कॉन्फ़िगरेशन, जो आपकी कॉन्फ़िगरेशन से प्राथमिकता लेता है, एक `aipmt` एजेंट को परिभाषित करता है जिसके सभी टूल्स अस्वीकृत होते हैं (`permission: { "*": "deny" }`), सत्र साझाकरण अक्षम, `--pure`, कभी भी `--auto` नहीं;
- डिस्पोजेबल और खाली कार्य डायरेक्टरी, `OPENCODE_DISABLE_PROJECT_CONFIG` और `OPENCODE_DISABLE_CLAUDE_CODE` सेट हैं — उनके बिना, OpenCode वर्तमान डायरेक्टरी के `AGENTS.md` और `~/.claude/CLAUDE.md` को प्रॉम्प्ट में इंजेक्ट करता है। वैश्विक `~/.config/opencode/AGENTS.md` इंजेक्ट रहता है, OpenCode इसे हटाने की अनुमति नहीं देता है;
- आउटपुट अनुबंध: रिटर्न कोड 0, कोई `error` इवेंट नहीं, कोई टूल कॉल नहीं, अंतिम चरण `stop` में, गैर-रिक्त पाठ, और `aipmt` एजेंट वास्तव में लोड हुआ — एक अज्ञात `--agent` OpenCode को विफल नहीं करता है, यह बिना बताए कोडिंग एजेंट पर वापस लौट जाता है;
- स्वयं OpenCode की कुंजी `OPENCODE_API_KEY` को छोड़कर, `aipmt` की कोई भी कुंजी पास नहीं की जाती है। प्रदाताओं को `aipmt` के `.env` में नहीं, बल्कि OpenCode में कॉन्फ़िगर किया जाता है।

जानने योग्य बातें:

- Zen के मुफ़्त मॉडल परिवर्तनशील हैं, जिनकी सीमाएँ अप्रलेखित हैं, और उनकी बातचीत का उपयोग प्रशिक्षण के लिए किया जा सकता है: केवल सार्वजनिक दस्तावेज़ीकरण के लिए, निजी सामग्री के लिए नहीं।
- एक स्थानीय मॉडल को कम से कम 16 k टोकन का संदर्भ प्रदान करना चाहिए, क्योंकि सेगमेंट 16,000 वर्णों तक के होते हैं। Ollama अक्सर इसे 4,096 पर कॉन्फ़िगर करता है: `PARAMETER num_ctx 32768` के साथ `Modelfile` का उपयोग करें।
- `--eco` का कोई प्रभाव नहीं पड़ता है; `--reasoning_effort` को OpenCode के `--variant` के रूप में यथावत पास किया जाता है।
- OpenCode प्रत्येक सत्र को `~/.local/share/opencode/` में लॉग करता है।
- वेरिएबल्स: `OPENCODE_BIN` (अन्यथा `PATH`, फिर `~/.opencode/bin/opencode`), `OPENCODE_TIMEOUT` (प्रति सेगमेंट सेकंड, डिफ़ॉल्ट 600)। `OPENCODE_CONFIG` OpenCode को यथावत पास होता है।

Ollama के माध्यम से एक स्थानीय मॉडल का उदाहरण, `~/.config/opencode/opencode.json` में:

```bash
ollama pull gpt-oss:20b
printf 'FROM gpt-oss:20b\nPARAMETER num_ctx 32768\n' > gpt-oss-20b-32k.Modelfile
ollama create gpt-oss-20b-32k -f gpt-oss-20b-32k.Modelfile
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama (local)",
      "options": { "baseURL": "http://127.0.0.1:11434/v1" },
      "models": {
        "gpt-oss-20b-32k": {
          "name": "gpt-oss 20B (32k, sans réflexion)",
          "limit": { "context": 32768, "output": 8192 },
          "options": { "reasoningEffort": "none" }
        }
      }
    }
  }
}
```

`reasoningEffort: "none"` उस थिंकिंग को बंद कर देता है जिसे Ollama डिफ़ॉल्ट रूप से इन मॉडलों पर सक्षम करता है, और जिसे कोई Modelfile अक्षम नहीं कर सकता है। छह शब्दों के एक वाक्य पर मापा गया: बिना विकल्प के 919 थिंकिंग टोकन और 68 सेकंड, विकल्प के साथ 9 टोकन।

### 400 से अधिक मॉडलों के लिए: `--use_openrouter`

OpenRouter एक उपयोग-आधारित बिलिंग राउटर है, जो एकल क्रेडिट पर तीसरे पक्ष द्वारा होस्ट किए गए मॉडलों के आगे कार्य करता है — जिसमें खुले चीनी मॉडल भी शामिल हैं जिन्हें कोई अन्य प्रदाता यहाँ प्रदर्शित नहीं करता है।

```bash
aipmt --use_openrouter --model z-ai/glm-5.2 --file README.md --target_dir . --target_lang en
```

`--model` अनिवार्य है। किसी भी बिलिंग से पहले निष्पादित एक प्रीफ़्लाइट, रूटिंग की दो विशिष्टताओं को संभालता है:

- **एक ही मॉडल को अलग-अलग सीमाओं वाले दर्जनों होस्ट द्वारा परोसा जाता है** — `z-ai/glm-5.3-flash` पर, 23 होस्ट जिनमें से एक 2,048 आउटपुट टोकन तक सीमित है। प्रीफ़्लाइट `/api/v1/models/{modèle}/endpoints` को पढ़ता है, 8,000 आउटपुट टोकन से कम या ख़राब स्थिति वाले होस्ट को बाहर करता है, और बाकी को `allow_fallbacks: false` के साथ पिन करता है।
- **रीज़निंग का बिल आउटपुट दर पर लिया जाता है** — `z-ai/glm-5.2` की "OK" प्रतिक्रिया पर 2 के मुकाबले 107 टोकन। इसे डिफ़ॉल्ट रूप से बंद कर दिया जाता है; जो मॉडल इसे अनिवार्य करते हैं, वे सबसे कम स्वीकार्य प्रयास प्राप्त करते हैं, क्योंकि कैटलॉग का डिफ़ॉल्ट अनुवाद समाप्त होने से पहले आउटपुट को संतृप्त कर सकता है। `--reasoning_effort` प्राथमिकता पर रहता है।

```
→ OpenRouter : 30 hébergeur(s) épinglé(s) sur 33, contexte 1048576 tokens,
  sortie plafonnée à 32768, raisonnement coupé
```

- संदर्भ विंडो कैटलॉग से आती है। 16,400 टोकन से कम वाले मॉडल को किसी भी कॉल से पहले अस्वीकार कर दिया जाता है: प्रॉम्प्ट और सेगमेंट के लिए 8,400, न्यूनतम 8,000 आउटपुट।
- कैटलॉग में अनुपस्थित स्लग, अगम्य कैटलॉग, या सीमा को पूरा करने वाले होस्ट की अनुपस्थिति कमांड को रोक देती है।
- खाली आउटपुट के साथ `finish_reason=length` रीज़निंग द्वारा खपत किया गया बजट है, न कि ट्रंकेशन: संदेश इसे स्पष्ट रूप से अलग पहचानता है।
- `--eco` का कोई प्रभाव नहीं पड़ता है।
- वेरिएबल्स: `OPENROUTER_API_KEY` (<https://openrouter.ai/keys>), `OPENROUTER_BASE_URL` (डिफ़ॉल्ट `https://openrouter.ai/api/v1`, `https://` आवश्यक), `OPENROUTER_TIMEOUT` (डिफ़ॉल्ट 900), `OPENROUTER_PREFLIGHT_TIMEOUT` (डिफ़ॉल्ट 30)।

### अनुवाद नोट

`--add_translation_note` एक नोट जोड़ता है, `bottom` (डिफ़ॉल्ट), `top` (फ़्रंट मैटर के बाद) या `both` (`--note_position`) पर, `legacy` (बोल्ड पैराग्राफ, डिफ़ॉल्ट) या `marker` (`--note_format`) प्रारूप में। प्रारूप `marker` एक अदृश्य Markdown संदर्भ परिभाषा है, `[ai-translation-note-<placement>]: <> "v=1 source=… target=… model=… date=…"`, जिसके बाद एक बोल्ड उद्धरण होता है: GitHub पर पठनीय, remark प्लगइन द्वारा बिल्ड के समय उपयोग करने योग्य।

```bash
aipmt --file article.mdx --target_lang en --add_translation_note --note_format marker --note_position top
```

## विस्तृत माप

सभी माप चौदह भाषाओं में `aipmt` के साथ वास्तव में निष्पादित किए गए अनुवाद हैं: en, es, de, it, pt, nl, pl, sv, ro, ja, ko, zh, ar, hi। **लिखित** उन फ़ाइलों की गणना करता है जिन्हें सुरक्षा जांचों ने पास होने दिया; **बिना किसी अंतर के** वे फ़ाइलें हैं जहाँ `scripts/compare_structure.py` को कुछ भी नहीं मिलता है — अनुभागों, उपशीर्षकों, लिंकों, विशिष्ट URL, कोड ब्लॉक, इनलाइन कोड, टेबल पंक्तियों, ब्लॉककोट और बोल्ड शब्दों की समान संख्या।

"बिना किसी अंतर के" का अर्थ "कुछ भी पता नहीं चला" है, "समान" नहीं: तुलनित्र उनकी सामग्री को पढ़े बिना तत्वों की गणना करता है। यह न तो हटाए गए स्तर 4 के शीर्षक की रिपोर्ट करता है, न ही बदले गए इनलाइन कोड पाठ की, न ही बदले गए फ़्लैग की, और न ही भाषा का मूल्यांकन करता है।

### ये माप क्या नहीं हैं

- **कोई संपूर्ण रैंकिंग नहीं**: केवल OpenRouter ही चार सौ से अधिक मॉडल प्रस्तुत करता है, जिनमें से लगभग पंद्रह को मापा गया था।
- **सांकेतिक अवधियाँ**: अभियानों के आधार पर समानांतर में तीन से छह अनुवाद, और किसी प्रदाता का थ्रूपुट दिन भर में बदलता रहता है।
- **समय-विशिष्ट अवलोकन**: मॉडल एक ही नाम के तहत बदलते रहते हैं, और आपके दस्तावेज़ हमारे दस्तावेज़ों जैसे नहीं हैं।

अपने दस्तावेज़ों पर, फ़ाइल की एक फ्रीज़ की गई प्रतिलिपि पर माप को दोहराने के लिए:

```bash
aipmt --file reference.md --target_dir out/ --source_lang fr --target_lang ja --use_gemini --force
aipmt --file veille.mdx   --target_dir out/ --source_lang fr --target_lang ja --use_gemini --news --force
python scripts/compare_structure.py reference.md out/reference-ja.md
# « structure identique », ou la liste des écarts — sortie 0 si identique, 1 sinon
```

## योगदान करें

```bash
git clone https://github.com/jls42/ai-powered-markdown-translator.git
cd ai-powered-markdown-translator
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt   # les dépendances, lock entièrement épinglé
pip install -e .                  # le paquet lui-même, en mode éditable
```

दोनों पंक्तियाँ आवश्यक हैं: `pip install -e .` के बिना, `python -m aipmt` उत्तर में `No module named aipmt` देता है।

गुणवत्ता टूलिंग, वैकल्पिक लेकिन अनुशंसित:

```bash
pipx install pre-commit               # hors venv — absent des requirements
pip install -r requirements-dev.txt   # detect-secrets, pip-audit, mypy, lizard
pre-commit install                    # hooks rapides à chaque commit
pre-commit install --hook-type pre-push  # mypy, SAST, pip-audit, tests avant chaque push
```

रिपॉजिटरी के 28 अनुवाद (README और CHANGELOG, चौदह भाषाएँ) `./regen_translations.sh --force` के साथ पुनर्जीवित किए जाते हैं — डिफ़ॉल्ट रूप से ChatGPT सब्सक्रिप्शन पर Codex और `gpt-5.6-sol`, चार समानांतर में। `REGEN_PROVIDER` और `REGEN_MODEL` पथ बदलते हैं: `antigravity` एक सब्सक्रिप्शन (Google के) पर रहता है, और बिना किसी छूट के पास हो जाता है; बिल की जाने वाली API (`openai`, `gemini`, `grok`, `openrouter`) को `REGEN_ALLOW_PAID_API=1` के बिना अस्वीकार कर दिया जाता है; `REGEN_JOB_TIMEOUT` प्रत्येक जॉब को सीमित करता है (Codex और Antigravity पर 600 s, 1 800 s)। टूलिंग का विवरण `CLAUDE.md` में है।

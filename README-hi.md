Markdown फ़ाइलों का एक भाषा से दूसरी भाषा में अनुवाद करता है और उनकी
संरचना सुरक्षित रखता है: कोड ब्लॉक, इनलाइन कोड, URL, एंकर, तालिकाएँ और फ़्रंट
मैटर। मॉडल को कॉल करने के ग्यारह तरीके — पाँच API, उपयोग के आधार पर
शुल्क के बिना चार सदस्यताएँ, दो राउटर — और हर मॉडल वास्तव में क्या
सुरक्षित रखता है, इसका प्रकाशित मापन।

## संक्षेप में

- **प्रदाता तक पहुँचने के ग्यारह रास्ते**: OpenAI, Mistral, Claude, Gemini और Grok API;
  उपयोग के आधार पर शुल्क के बिना ChatGPT (Codex), Grok, Google (Antigravity) और Claude (Claude
  Code) सदस्यताएँ; OpenCode (ओपन सोर्स, मुफ़्त या स्थानीय) और OpenRouter
  (400 से अधिक मॉडल) राउटर।
- **टोकन खोने से कोई गड़बड़ी नहीं**: कॉल से पहले कोड ब्लॉक, इनलाइन कोड,
  URL, एंकर और उद्धरणों की जगह टोकन रखे जाते हैं और
  उत्तर मिलने पर उनकी जाँच होती है। एक भी टोकन गायब हो, तो फ़ाइल लिखी नहीं जाती।
- **लंबे दस्तावेज़**: मॉडल की संदर्भ सीमा के अनुसार खंडों में विभाजन।
- **`--news` मोड**: समाचार समीक्षा लेखों के लिए अंग्रेज़ी उद्धरणों की सुरक्षा और
  भाषा के अनुसार फ़्लैग का प्रबंधन।
- **`--eco` मोड**: तेज़ और कम खर्चीले मॉडल।
- वैकल्पिक **अनुवाद संबंधी टिप्पणी**, ऊपर, नीचे या दोनों जगह।

## इंस्टॉलेशन

```bash
pip install ai-powered-markdown-translator     # ou : pipx install ai-powered-markdown-translator
aipmt --help                                   # ou : python -m aipmt --help
```

Python 3.10 या उससे नया संस्करण। रिपॉज़िटरी से इंस्टॉल करने के लिए,
[योगदान दें](#योगदान-दें) देखें।

## कॉन्फ़िगरेशन

कुंजियाँ तीन जगहों से पढ़ी जाती हैं, सबसे अधिक प्राथमिकता से सबसे कम तक; हर जगह से केवल
वही जानकारी ली जाती है जो पिछली जगह पर खाली रह गई हो।

|     | कहाँ                                            | किस लिए                             |
| --- | --------------------------------------------- | ------------------------------------- |
| 1   | परिवेश चर                     | CI, कंटेनर, किसी एक अवसर पर मान बदलना |
| 2   | मौजूदा डायरेक्टरी (या उसकी किसी मूल डायरेक्टरी) का `.env` | किसी परियोजना की अपनी कुंजी            |
| 3   | `~/.config/aipmt/.env`                        | एक बार सेट करें, हर जगह लागू       |

```bash
mkdir -p ~/.config/aipmt
cat > ~/.config/aipmt/.env <<'EOF'
OPENAI_API_KEY=votre-clé-api-openai
XAI_API_KEY=votre-clé-api-xai
MISTRAL_API_KEY=votre-clé-api-mistral
ANTHROPIC_API_KEY=votre-clé-api-anthropic
GOOGLE_API_KEY=votre-clé-api-google
OPENROUTER_API_KEY=votre-clé-api-openrouter
EOF
chmod 600 ~/.config/aipmt/.env
```

`GOOGLE_API_KEY` की जगह `GEMINI_API_KEY` स्वीकार किया जाता है। उपयोगकर्ता की
फ़ाइल `XDG_CONFIG_HOME` (केवल पूर्ण पथ) और Windows पर `%APPDATA%`
का पालन करती है। कुंजी न मिलने पर कमांड तीनों स्थानों की सूची दिखाती है।

**किसी परियोजना का `.env` न तो कॉल को दूसरी जगह भेज सकता है, न ही चलाए जाने वाले प्रोग्राम को
चुन सकता है।** यह कुंजियाँ देता है, कभी गंतव्य या बाइनरी नहीं: `_BASE_URL`, `_API_BASE`, `_ENDPOINT` या `_BIN` वाले सभी
चर (`CODEX_BIN`,
`GROK_BIN`, `OPENCODE_BIN`, `AGY_BIN`), `GROK_HOME`, प्रॉक्सी (`HTTP_PROXY`,
`HTTPS_PROXY`, `ALL_PROXY`), प्रमाणपत्र भंडार (`SSL_CERT_FILE`,
`SSL_CERT_DIR`, `REQUESTS_CA_BUNDLE`, `CURL_CA_BUNDLE`) और `XDG_CONFIG_HOME` /
`APPDATA` वहाँ चेतावनी के साथ अनदेखे किए जाते हैं। क्लोन की गई रिपॉज़िटरी को
आपकी कुंजी चुराकर दूसरी जगह भेजने या पहले अनुवाद पर अपना प्रोग्राम चलवाने में
सक्षम नहीं होना चाहिए। यह फ़ाइल चर प्रतिस्थापन के बिना भी पढ़ी जाती है:
`NOM=${OPENAI_API_KEY}` वहाँ कुंजी की प्रतिलिपि नहीं बनाता। इन चरों को
परिवेश में या `~/.config/aipmt/.env` में रखें।

वैकल्पिक चर: `XAI_BASE_URL` (डिफ़ॉल्ट `https://api.x.ai/v1`),
`CLAUDE_TIMEOUT` (प्रति कॉल सेकंड, डिफ़ॉल्ट 900), `CODEX_BIN`, `CODEX_TIMEOUT`
(डिफ़ॉल्ट 600), `GROK_BIN`, `GROK_HOME` (डिफ़ॉल्ट `~/.grok`), `GROK_TIMEOUT`
(डिफ़ॉल्ट 900), `GROK_TRANSLATE_SANDBOX`, `AGY_BIN`, `AGY_TIMEOUT` (डिफ़ॉल्ट 900),
`OPENCODE_BIN`, `OPENCODE_TIMEOUT` (डिफ़ॉल्ट 600), `OPENROUTER_BASE_URL`
(`https://` आवश्यक), `OPENROUTER_TIMEOUT` (डिफ़ॉल्ट 900),
`OPENROUTER_PREFLIGHT_TIMEOUT` (डिफ़ॉल्ट 30)। हर चर का विवरण उसके
प्रदाता वाले खंड में दिया गया है।

## शुरुआत करें

```bash
# un fichier
aipmt --file document.md --target_dir out/ --source_lang fr --target_lang en

# un répertoire
aipmt --source_dir content/fr --target_dir content/en --source_lang fr --target_lang en

# un autre provider
aipmt --use_gemini --file document.md --target_dir out/ --target_lang ja
```

`document.md` का स्पेनी में अनुवाद करने पर `--target_dir` में `document-es.md` मिलता है;
`--include_model` के साथ, `document-es-gpt-5.6-terra.md`। एक्सटेंशन हमेशा
`.md` हो जाता है — `article.mdx` से `article-en.md` मिलता है — सिवाय
`--keep_filename` के, जो मूल नाम बनाए रखता है। पहले से मौजूद अनुवाद
को `--force` के बिना छोड़ दिया जाता है।

निकास कोड: सब कुछ सफल होने या छोड़ दिए जाने पर `0`, किसी फ़ाइल के
विफल रहने पर `1` (सूची मानक त्रुटि आउटपुट पर), कॉन्फ़िगरेशन की समस्या होने पर `2`।
विफल फ़ाइल कभी नहीं लिखी जाती, भले ही लिखने की प्रक्रिया ही विफल हो:
सामग्री पहले बगल की फ़ाइल में लिखी जाती है, फिर उसका नाम बदला जाता है। दोबारा चलाना पर्याप्त है।

  पहले ही खंड से चार इनलाइन कोड और

  लिखी नहीं जाती और aipmt इसका कारण बताता है।
- **यह सुरक्षा जाल शीर्षकों, तालिकाओं, फ़्रंट मैटर या

## सभी विकल्प

| विकल्प                   | विवरण                                                                                                   |

| `--use_claude`           | Claude API का उपयोग करें                                                                                         |
| `--use_gemini`           | Gemini API का उपयोग करें                                                                                         |

## प्रदाता

### API के माध्यम से: OpenAI, Mistral, Claude, Gemini, Grok

```bash
aipmt --source_dir content/fr --target_dir content/en --target_lang en             # OpenAI, défaut
aipmt --use_mistral --source_dir content/fr --target_dir content/es --target_lang es
aipmt --use_claude  --source_dir content/fr --target_dir content/de --target_lang de
aipmt --use_gemini  --source_dir content/fr --target_dir content/ja --target_lang ja
aipmt --use_grok    --source_dir content/fr --target_dir content/pt --target_lang pt
```

`--eco` प्रत्येक प्रदाता के किफ़ायती स्तर पर स्विच करता है।

| प्रदाता    | गुणवत्ता (डिफ़ॉल्ट)                                                     | किफ़ायती (`--eco`)      |
| ----------- | -------------------------------------------------------------------- | ------------------------- |
| OpenAI      | `gpt-5.6-terra`                                                      | `gpt-5.6-luna`            |
| Claude      | `claude-sonnet-5-5`                                                  | `claude-haiku-5-5`        |
| Mistral     | `mistral-large-latest`                                               | `mistral-small-latest`    |
| Gemini      | `gemini-3.7-flash`                                                   | `gemini-3.1-flash-lite`   |
| Codex       | `gpt-6.1-sol` (`--model` के माध्यम से `gpt-5.6-sol`, `terra` और `luna` भी) | `gpt-5.6-luna`            |
| Grok API    | `grok-4.6`                                                           | `grok-4.3`                |
| Grok CLI    | `grok-4.6`                                                           | `grok-4.5`                |
| Antigravity | `gemini-3.8-flash-medium`                                            | `gemini-3.7-flash-low`    |
| Claude Code | `sonnet`, प्रयास `low`                                               | वही — `--eco` का कोई प्रभाव नहीं |
| OpenCode    | `--model provider/modèle` अनिवार्य                                | वही — `--eco` का कोई प्रभाव नहीं |
| OpenRouter  | `--model fournisseur/modèle` अनिवार्य                             | वही — `--eco` का कोई प्रभाव नहीं |

### ChatGPT सदस्यता पर: `--use_codex`

आधिकारिक Codex CLI को संचालित करता है: अनुवाद ChatGPT सदस्यता के कोटे से
कटता है, API कुंजी या उपयोग के अनुसार बिलिंग के बिना।

```bash
pip install openai-codex-cli-bin   # package officiel OpenAI (~250 Mo), ou : npm install -g @openai/codex
codex login
aipmt --use_codex --eco --file README.md --target_dir . --target_lang it
```

- बाइनरी को पहले `CODEX_BIN`, फिर `PATH`, और फिर
  `openai-codex-cli-bin` पैकेज में खोजा जाता है। `~/.codex/auth.json` कभी नहीं पढ़ा जाता।
- `OPENAI_API_KEY` और `CODEX_API_KEY` को उपप्रक्रिया के परिवेश से
  हटा दिया जाता है: कुंजी मौजूद होने पर भी API पर स्विच कभी नहीं होता।
- प्रत्येक खंड पर 5 घंटे की अवधि का कम से कम एक « संदेश » खर्च होता है — सत्यापन
  विफल होने और दोबारा प्रयास किए जाने पर दो। OpenAI के अनुमान के अनुसार,
  Plus योजना पर `gpt-5.6-luna` (`--eco`) के लिए 250-2 000 संदेश/5 h और
  `gpt-5.6-sol` के लिए 10-100 संदेश मिलते हैं।
- `--model gpt-5.6-sol`, जो 1.16.3 तक डिफ़ॉल्ट था, `--model gpt-5.6-terra`
  और `--model gpt-5.6-luna` भी सदस्यता के माध्यम से चलते हैं।
- सर्वर से 429 आने पर फ़ाइल नहीं खोती: Codex अपने आप दोबारा जुड़ता है,
  aipmt बारी पूरी होने की प्रतीक्षा करता है, और यदि अंत में भी 429 बना रहता है, तो खंड
  पर 30 और फिर 60 सेकंड बाद दोबारा प्रयास होता है। खाते में जिस मॉडल की अनुमति नहीं है, वह 400
  « ChatGPT खाते के साथ Codex का उपयोग करते समय यह मॉडल समर्थित नहीं है » त्रुटि देता है।
- API से धीमा है, और दस्तावेज़ बड़ा होने पर अंतर बढ़ता है: इस README पर,
  `gpt-5.6-sol` के साथ प्रति भाषा माध्यिका समय 6 min 46 s है, जबकि
  `gemini-3.7-flash` के लिए 36 s है।
- CI में अस्वीकार किया जाता है (`CI` या `GITHUB_ACTIONS` परिभाषित होने पर): सदस्यता का प्रमाणीकरण
  व्यक्तिगत सत्र फ़ाइल से होता है, जिसे साझा रनर पर नहीं होना
  चाहिए।
- चर: `CODEX_BIN`, `CODEX_TIMEOUT` (प्रति खंड सेकंड, डिफ़ॉल्ट 600)।

### Grok सदस्यता पर: `--use_grok_cli`

यही सिद्धांत आधिकारिक Grok Build CLI के साथ, SuperGrok या
X Premium+ सदस्यता पर लागू होता है।

```bash
curl -fsSL https://x.ai/cli/install.sh | bash
grok login                                      # ou : grok login --device-code
aipmt --use_grok_cli --eco --file README.md --target_dir . --target_lang pl
```

- **Codex की तुलना में कमज़ोर पृथक्करण।** Grok का OS सैंडबॉक्स
  कई हालिया Linux प्रणालियों पर लागू नहीं होता (AppArmor, कंटेनर रनटाइम
  सॉकेट), और लागू न हो सकने वाली प्रोफ़ाइल चुपचाप बिना पृथक्करण के
  शुरू हो जाती है। इसलिए स्क्रिप्ट डिफ़ॉल्ट रूप से कोई प्रोफ़ाइल नहीं माँगती, इसकी सूचना देती है, और
  CLI के `--deny` नियमों पर निर्भर करती है, जिनमें सभी मामलों को समेटने वाला `*` भी शामिल है — यही एकमात्र
  परत है जो बिना बताए सुरक्षा हटाने के बजाय शुरू होने से इनकार करती
  है। `GROK_TRANSLATE_SANDBOX=read-only` के लिए OS सैंडबॉक्स आवश्यक है, और मशीन
  इसे लागू नहीं कर सकती तो शुरुआत विफल हो जाती है।
- कोटा साप्ताहिक है, Chat, Imagine और Voice के साथ साझा होता है, और इसे
  पढ़ने के लिए कोई कमांड नहीं है: कोई बैच बिना सूचना दिए बातचीत के उपयोग
  का कोटा खर्च कर सकता है।
- चर: `GROK_BIN`, `GROK_HOME` (CLI डायरेक्टरी, डिफ़ॉल्ट `~/.grok`),
  `GROK_TIMEOUT` (डिफ़ॉल्ट 900), `GROK_TRANSLATE_SANDBOX`।

### Google सदस्यता पर: `--use_antigravity`

यही सिद्धांत Antigravity के आधिकारिक CLI `agy` के साथ लागू होता है: Google
AI Pro या Ultra के भुगतान करने वालों के लिए अनुवाद का खर्च प्रति टोकन बिल किए जाने के बजाय
सदस्यता के कोटे से कटता है। इस कोटे तक पहुँचने का यही एकमात्र रास्ता है: Gemini CLI
18 जून 2026 से इन खातों को सेवा नहीं देता
([घोषणा](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)),
और Antigravity SDK केवल API कुंजी या Google Cloud प्रोजेक्ट स्वीकार करता है।

```bash
# agy 1.2.11 ou plus récent : https://antigravity.google/docs/cli/install/
agy                                  # une fois : se connecter avec le compte de l'abonnement
aipmt --use_antigravity --file README.md --target_dir . --target_lang en
agy -p /usage --output-format json   # quota restant, sans en consommer
```

- **सशुल्क उपयोग का कोई रास्ता खुला नहीं रहता।** agy को आपके
  परिवेश से केवल चरों की एक निर्धारित सूची मिलती है — `PATH`, भाषा और समय क्षेत्र,
  टर्मिनल, पहचान, प्रॉक्सी और प्रमाणपत्र, सत्र बस — और कोई कुंजी नहीं मिलती:
  इसके कई चर बिना कुछ दिखाए कॉल का रास्ता बदल देते हैं (मापा गया:
  एक दस्तावेज़ को तृतीय पक्ष के गेटवे पर भेजता है, दूसरा बिल किए जाने वाले
  Google Cloud प्रोजेक्ट पर), और निषेध सूची में हर समीक्षा के दौरान कुछ छूट जाता था।
  किसी भी खंड से पहले, `agy -p /config`, जिसमें कोई कोटा खर्च नहीं होता, को यह दिखाना
  होगा कि सशुल्क AI क्रेडिट निष्क्रिय हैं और कोई API कुंजी या Google Cloud प्रोजेक्ट नहीं है —
  सेटिंग अनुपस्थित होने पर अस्वीकार किया जाता है — अन्यथा कुछ भी अनुवादित नहीं होता; इसके बाद प्रत्येक
  कॉल के लॉग में सदस्यता का प्रमाण (`authMethod=consumer`) होना चाहिए, अन्यथा
  उत्तर अस्वीकार कर दिया जाता है।
- **पृथक्करण।** प्रत्येक कॉल एक निजी, अस्थायी होम डायरेक्टरी में
  बिना टूल वाले अनुवाद एजेंट के साथ चलती है: आपकी agy सेटिंग, नियम,
  प्लगइन, MCP सर्वर और हुक वहाँ नहीं पहुँचते, आपके इतिहास में कुछ नहीं जुड़ता,
  और लॉगिन कीरिंग में बना रहता है, जिसे aipmt कभी नहीं पढ़ता।
  एजेंट न मिलने पर agy चुपचाप अपने कोडिंग एजेंट
  और उसके टूल पर लौट जाता है: लॉग की एक पूरी पंक्ति को सही एजेंट की पुष्टि करनी चाहिए —
  इस संदेश का उल्लेख करने वाला दस्तावेज़ उसका विकल्प नहीं है — अन्यथा अस्वीकार किया जाता है।
- **प्लेटफ़ॉर्म**: Linux, ऐसे सत्र में जिसमें कीरिंग हो (D-Bus सत्र
  बस, Secret Service); macOS स्वीकार किया जाता है, हालाँकि उस पर माप नहीं किया गया है। Windows
  पर अस्वीकार किया जाता है, जहाँ agy प्रत्येक कॉल को अलग करने वाले चर नहीं पढ़ता, और
  सत्र बस के बिना Linux पर भी — SSH सत्र, कंटेनर, सर्वर: वहाँ agy
  अपना टोकन `~/.gemini` की एक फ़ाइल में रखता है, जिसे पृथक्करण छिपा देता है।
  लॉगिन कोड के लिए एक मिनट प्रतीक्षा कराने के बजाय, किसी भी शुरुआत से पहले
  कारण सहित अस्वीकार कर दिया जाता है।
- **मॉडल**: `agy models` वाले मॉडल। Gemini मॉडल के नाम में ही प्रयास स्तर होता है
  (`gemini-3.8-flash-medium`…): प्रत्यय के बिना नाम कॉल से पहले ही अस्वीकार कर दिया जाता है,
  और `--reasoning_effort` का कोई प्रभाव नहीं होता। डिफ़ॉल्ट `gemini-3.8-flash-medium` है,
  और `--eco` में `gemini-3.7-flash-low` है; इन्हें तय करने वाले परीक्षण अभियान
  [विस्तृत माप](#विस्तृत-माप) में वर्णित हैं। Claude और GPT-OSS
  का अपना अलग कोटा है, जो बहुत छोटा है: मापे गए प्रत्येक कॉल पर 5 घंटे की
  अवधि का लगभग 1 %, जबकि Flash में 0,05 %।
- **कोटा**: प्रत्येक समूह के लिए, टोकन लागत के अनुपात में 5 घंटे की अवधि और एक साप्ताहिक अवधि
  होती है। लेखक के खाते पर माप: प्रति दस लाख स्रोत वर्णों पर
  5 घंटे की अवधि के लगभग 16 अंक
  `gemini-3.8-flash-medium` में, 14 `gemini-3.7-flash-medium` में और 7 से 8
  निम्न प्रयास स्तर पर — इसलिए 40 000 वर्णों वाले README पर आधे अंक से
  थोड़ा अधिक खर्च होता है। साप्ताहिक सीमा सदस्यता स्तर पर निर्भर करती है। दोबारा प्रयास
  agy द्वारा पुनः प्रयास योग्य बताए गए मामलों के अनुसार होता है; अन्यथा, समाप्त कोटे वाली अवधि पर कभी
  दोबारा प्रयास नहीं होता: `/usage` में दिखाए गए रीसेट तक
  प्रत्येक फ़ाइल विफल होती रहती है।
- **API से धीमा**: माप वाले सघन लेख पर, प्रति भाषा
  माध्यिका समय `gemini-3.8-flash-medium` में 3 min 59 s और
  `gemini-3.7-flash-medium` में 3 min 14 s है, जबकि API से Gemini 3.7 Flash के लिए 1 min 18 s है।
- **रुकावट**: Ctrl-C दबाने या टर्मिनल बंद करने पर agy कमांड के
  साथ ही बंद हो जाता है, ताकि आपके कोटे पर उसकी बारी पूरी होती न रहे; यही
  Codex, Grok CLI और OpenCode पर भी लागू होता है। `nohup` के अंतर्गत अनुवाद जारी रहता है।
- CI में अस्वीकार किया जाता है (`CI` या `GITHUB_ACTIONS` परिभाषित होने पर): लॉगिन एक
  व्यक्तिगत कीरिंग में रहता है। रनर पर, `GOOGLE_API_KEY` के साथ `--use_gemini` का उपयोग करें।
- चर: `AGY_BIN` (अन्यथा `PATH`, फिर `~/.local/bin/agy`),
  `AGY_TIMEOUT` (प्रति खंड सेकंड, शुरुआत सहित, डिफ़ॉल्ट 900)।

तृतीय पक्ष सॉफ़्टवेयर के माध्यम से सेवा तक पहुँचने पर रोक लगाते हैं — इनमें Claude Code,
OpenClaw और OpenCode का उल्लेख है — और ऐसा करने पर खाता निलंबित हो सकता है। aipmt
टोकन को न पढ़ता है, न दोबारा उपयोग करता है: यह आधिकारिक बाइनरी को
[हेडलेस मोड](https://antigravity.google/docs/cli/headless/) में चलाता है, जिसे Google
स्क्रिप्ट और CI के लिए दस्तावेज़ित करता है। Google के एक सदस्य ने अपने काम के लिए स्थानीय स्क्रिप्ट से
`agy -p` चलाने को « सामान्य » माना
([आधिकारिक फ़ोरम, 25 सितंबर 2026, गैर-संविदात्मक उत्तर](https://discuss.ai.google.dev/t/is-using-the-official-agy-cli-through-a-local-mcp-server-with-third-party-ai-agents-permitted/184829));
इस तरह वितरित किए जाने वाले टूल के मामले पर कोई दस्तावेज़ स्पष्ट निर्णय नहीं देता।

**केवल सार्वजनिक दस्तावेज़।** उन्हीं शर्तों के खंड 5 के अनुसार,
आदान-प्रदान — प्रॉम्प्ट, उत्तर, मेटाडेटा — Google के उत्पादों
और मशीन लर्निंग को बेहतर बनाने के लिए उपयोग किए जा सकते हैं और मनुष्यों द्वारा
पढ़े जा सकते हैं, सशुल्क सदस्यता पर भी। इससे बाहर निकलने के लिए
`enableTelemetry` सेटिंग है, जिसका प्रभाव दस्तावेज़ित नहीं है और जिसे aipmt सेट नहीं करता; आपकी
agy सेटिंग उसके पृथक परिवेश में नहीं पहुँचतीं। इसमें कोई गोपनीय सामग्री न भेजें।
### Claude सदस्यता पर: `--use_claude_code`

यही सिद्धांत Claude Code के आधिकारिक CLI, `claude`, पर `-p` मोड में लागू होता है: जो
Claude Pro या Max के लिए भुगतान करते हैं, उनके अनुवाद की खपत
सदस्यता के कोटे से घटाई जाती है, प्रति टोकन बिल नहीं बनता। इसे
Anthropic के API, `--use_claude`, से न मिलाएँ, जिसका बिल उपयोग के अनुसार बनता है।

```bash
claude                                   # une fois : /login avec le compte de l'abonnement
aipmt --use_claude_code --file README.md --target_dir . --target_lang en
```

- **भुगतान वाला कोई रास्ता खुला नहीं रहता, और हर कॉल इसका प्रमाण देता है।** Claude
  Code को आपके परिवेश से केवल चरों की एक निश्चित सूची मिलती है — न
  API कुंजी, न टोकन, न क्लाउड प्रदाता, न उस Claude Code सत्र का कोई संकेत
  जिससे aipmt चलाया गया हो। पहले खंड से पहले, `claude auth status` में
  Console कुंजी के बिना सदस्यता से जुड़ा लॉगिन दिखना चाहिए, और `/usage`, जो
  कोई कोटा खर्च नहीं करता, को इसकी पुष्टि करनी चाहिए; हर कॉल भी अपने
  आरंभीकरण इवेंट में इसकी पुष्टि करता है, अन्यथा उत्तर अस्वीकार कर दिया जाता है।
- **« अतिरिक्त उपयोग » बंद करें** (claude.ai, सेटिंग्स → उपयोग), ताकि
  खर्च शून्य यूरो रहे: इसे चालू रखने पर, किसी समयावधि का कोटा समाप्त होते ही
  यह उसकी जगह ले लेता है और बिना त्रुटि दिखाए शुल्क लगाता है। किसी कॉल की कोटा रिपोर्ट
  में यह संकेत मिलते ही aipmt अनुवाद रोक देता है, लेकिन उस कॉल की खपत पहले ही गिनी जा चुकी होती है।
- **कोटा आपके Claude Code सत्रों के साथ साझा होता है।** हर कॉल
  5 घंटे और साप्ताहिक समयावधि का उपयोग बताता है; 80 %
  (`AIPMT_CLAUDE_MAX_UTILIZATION`) से अधिक होने पर कोई अगला खंड शुरू नहीं किया जाता, ताकि
  आपके काम के लिए उपलब्ध कोटा समाप्त न हो।
- **अलगाव।** हर कॉल बिना किसी टूल के, एक निजी और
  अस्थायी निर्देशिका में, बिना अनुकूलन वाले मोड में चलता है: न आपके `CLAUDE.md`, न आपके प्लगइन,
  हुक, MCP सर्वर या सेटिंग्स लोड होते हैं, और सत्र का कुछ भी
  सहेजा नहीं जाता। संलग्नक बंद रहते हैं: आपके दस्तावेज़ में मौजूद `@chemin`
  केवल पाठ बना रहता है और कोई फ़ाइल नहीं खोलता (जाँच में सत्यापित)।
- **मॉडल**: डिफ़ॉल्ट रूप से `sonnet`, प्रयास स्तर `low` पर, और `--eco` में भी:
  इस रास्ते पर `--eco` कुछ नहीं बदलता। उन्हीं दस्तावेज़ों पर मापने पर, `haiku`
  दोगुना धीमा है — वह तर्क करता है और इसे रोकना संभव नहीं है — जबकि
  लागत बस थोड़ी कम है, और `opus` जीवविज्ञान की सामग्री अस्वीकार करता है (अगला
  बिंदु)। दोनों `--model` के ज़रिए उपलब्ध रहते हैं; ये उपनाम अपने
  परिवार के नवीनतम मॉडल का अनुसरण करते हैं। `fable` और `[1m]` के प्रकार अस्वीकार किए जाते हैं,
  क्योंकि वे सशुल्क क्रेडिट का उपयोग करते हैं। `--reasoning_effort` प्रयास स्तर तय करता है,
  जिससे अनुवाद को कोई लाभ नहीं होता: मापी गई तर्क प्रक्रिया शून्य या लगभग शून्य है।
- **Opus जीवविज्ञान की कुछ सामग्री अस्वीकार करता है।** उसके सुरक्षा उपाय
  Sonnet से अधिक कड़े हैं, और Anthropic का त्रुटि संदेश चेतावनी देता है कि वे
  « कभी-कभी जीवविज्ञान अनुसंधान से जुड़े काम को भी चिह्नित कर सकते हैं »। माप में पाया गया: जनरेट किए गए
  279 अणुओं पर एक संक्षिप्त समाचार के कारण सभी चौदह
  भाषाओं में लेख अस्वीकार हुआ। कुछ भी लिखा नहीं जाता: aipmt कटे हुए उत्तर को अस्वीकार करता है,
  सुरक्षा उपायों का उल्लेख करता है और `--model sonnet` की सलाह देता है।
- CI में (`CI` या `GITHUB_ACTIONS` निर्धारित होने पर) और Windows पर अस्वीकार किया जाता है (मापा नहीं गया)।
- चर: `AIPMT_CLAUDE_BIN` (अन्यथा `PATH`, फिर `~/.local/bin/claude`),
  `AIPMT_CLAUDE_TIMEOUT` (प्रति खंड सेकंड, डिफ़ॉल्ट 900),
  `AIPMT_CLAUDE_MAX_UTILIZATION` (डिफ़ॉल्ट 0.8), `CLAUDE_CONFIG_DIR` (Claude Code का
  खाता, जिसे कभी परियोजना के `.env` से नहीं लिया जाता); कार्य निर्देशिकाएँ
  `XDG_CACHE_HOME/aipmt/claude-code` के अंतर्गत (डिफ़ॉल्ट `~/.cache`)।

कोई भी पाठ ऐसे वितरित टूल के मामले पर स्पष्ट निर्णय नहीं देता जो बाइनरी चलाता है।

**डेटा**: Free, Pro और Max खातों पर, गोपनीयता सेटिंग की अनुमति होने पर
मॉडल प्रशिक्षण Claude Code पर भी लागू होता है
([डेटा पृष्ठ](https://code.claude.com/docs/en/data-usage))। aipmt
कोई स्थानीय प्रतिलेख नहीं रखता (`--no-session-persistence`)। इसके ज़रिए
कोई गोपनीय जानकारी न भेजें।

### अपनी पसंद के प्रदाता तक: `--use_opencode`

[OpenCode](https://opencode.ai) एक ओपन सोर्स (MIT) कोड एजेंट है जो
अपने भीतर कॉन्फ़िगर किए गए प्रदाताओं तक अनुरोध भेजता है: API कुंजी, सदस्यता,
OpenCode Zen गेटवे (मुफ़्त मॉडल, बिना खाते के) या स्थानीय मॉडल। यहाँ दो
रास्तों को शुरू से अंत तक मापा गया है, Zen और Ollama।

```bash
curl -fsSL https://opencode.ai/install | bash   # ou : npm install -g opencode-ai
opencode models                                 # les modèles, au format provider/modèle
opencode auth login                             # facultatif : brancher un fournisseur

# gratuit, sans compte ni clé — données utilisables pour l'entraînement
aipmt --use_opencode --model opencode/mimo-v2.5-free --file README.md --target_dir . --target_lang en
# local, hors ligne
aipmt --use_opencode --model ollama/qwen2.5:7b --file README.md --target_dir . --target_lang de
# sur un abonnement déjà payé
aipmt --use_opencode --model github-copilot/gpt-5 --file README.md --target_dir . --target_lang ja
```

`--model` अनिवार्य है: इसके बिना, OpenCode किसी मुफ़्त मॉडल पर लौट जाएगा
जिसके संवाद प्रशिक्षण में इस्तेमाल हो सकते हैं, और यह चुनाव
आपकी ओर से नहीं किया जाता।

हर कॉल पर अलगाव:

- आपकी कॉन्फ़िगरेशन से अधिक प्राथमिकता वाली एक इनलाइन कॉन्फ़िगरेशन `aipmt` एजेंट निर्धारित करती है,
  जिसके सभी टूल निषिद्ध हैं (`permission: { "*": "deny" }`), सत्र साझा करना
  बंद है, `--pure`, कभी `--auto` नहीं;
- खाली और अस्थायी कार्य निर्देशिका, `OPENCODE_DISABLE_PROJECT_CONFIG` और
  `OPENCODE_DISABLE_CLAUDE_CODE` निर्धारित — इनके बिना, OpenCode वर्तमान निर्देशिका का
  `AGENTS.md` और `~/.claude/CLAUDE.md` प्रॉम्प्ट में डाल देता है। वैश्विक
  `~/.config/opencode/AGENTS.md` फिर भी डाला जाता है, OpenCode उसे
  हटाने की अनुमति नहीं देता;
- आउटपुट अनुबंध: वापसी कोड 0, कोई `error` इवेंट नहीं, कोई
  टूल कॉल नहीं, अंतिम चरण `stop` में, गैर-रिक्त पाठ, और `aipmt` एजेंट
  वास्तव में लोड हुआ हो — कोई अज्ञात `--agent` OpenCode को विफल नहीं करता, वह
  चुपचाप कोडिंग एजेंट पर लौट जाता है;
- `aipmt` की कोई कुंजी नहीं भेजी जाती, सिवाय `OPENCODE_API_KEY` के, जो
  स्वयं OpenCode की कुंजी है। प्रदाताओं को OpenCode में कॉन्फ़िगर किया जाता है,
  `aipmt` के `.env` में नहीं।

जानने योग्य बातें:

- Zen के मुफ़्त मॉडल बदलते रहते हैं, उनकी सीमाएँ दस्तावेज़ों में दर्ज नहीं हैं, और
  उनके संवाद प्रशिक्षण में इस्तेमाल हो सकते हैं: सार्वजनिक दस्तावेज़ों के
  लिए, निजी सामग्री के लिए नहीं।
- स्थानीय मॉडल में कम से कम 16 k टोकन का संदर्भ होना चाहिए, क्योंकि खंड
  16 000 अक्षरों तक के होते हैं। Ollama अक्सर 4 096 कॉन्फ़िगर करता है:
  `PARAMETER num_ctx 32768` वाले `Modelfile` का उपयोग करें।
- `--eco` का कोई प्रभाव नहीं है; `--reasoning_effort` ज्यों का त्यों
  OpenCode के `--variant` के रूप में भेजा जाता है।
- OpenCode हर सत्र का लॉग `~/.local/share/opencode/` में रखता है।
- चर: `OPENCODE_BIN` (अन्यथा `PATH`, फिर `~/.opencode/bin/opencode`),
  `OPENCODE_TIMEOUT` (प्रति खंड सेकंड, डिफ़ॉल्ट 600)। `OPENCODE_CONFIG`
  ज्यों का त्यों OpenCode को भेजा जाता है।

Ollama के ज़रिए स्थानीय मॉडल का उदाहरण, `~/.config/opencode/opencode.json` में:

```bash
ollama pull gpt-oss:20b
printf 'FROM gpt-oss:20b\nPARAMETER num_ctx 32768\n' > gpt-oss-20b-32k.Modelfile
ollama create gpt-oss-20b-32k -f gpt-oss-20b-32k.Modelfile
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama (local)",
      "options": { "baseURL": "http://127.0.0.1:11434/v1" },
      "models": {
        "gpt-oss-20b-32k": {
          "name": "gpt-oss 20B (32k, sans réflexion)",
          "limit": { "context": 32768, "output": 8192 },
          "options": { "reasoningEffort": "none" }
        }
      }
    }
  }
}
```

`reasoningEffort: "none"` उस चिंतन को बंद करता है जिसे Ollama इन
मॉडलों पर डिफ़ॉल्ट रूप से चालू करता है, और जिसे Modelfile बंद नहीं कर सकता। छह शब्दों के
एक वाक्य पर माप: विकल्प के बिना चिंतन के 919 टोकन और 68 सेकंड, विकल्प के साथ 9 टोकन।

### 400 से अधिक मॉडलों तक: `--use_openrouter`

OpenRouter उपयोग के अनुसार शुल्क लेने वाला राउटर है, जिसमें एक ही क्रेडिट बैलेंस से
तीसरे पक्ष द्वारा होस्ट किए गए मॉडलों तक पहुँचा जाता है — इनमें खुले चीनी मॉडल भी हैं जिन्हें यहाँ कोई
अन्य प्रदाता उपलब्ध नहीं कराता।

```bash
aipmt --use_openrouter --model z-ai/glm-5.2 --file README.md --target_dir . --target_lang en
```

`--model` अनिवार्य है। किसी भी शुल्क से पहले की जाने वाली प्रारंभिक जाँच
रूटिंग की दो विशेषताओं को संभालती है:

- **एक ही मॉडल दर्जनों होस्टिंग प्रदाताओं से उपलब्ध होता है, जिनकी सीमाएँ
  अलग होती हैं** — `z-ai/glm-5.3-flash` पर 23 होस्टिंग प्रदाता हैं, जिनमें से एक की सीमा
  2 048 आउटपुट टोकन है। प्रारंभिक जाँच `/api/v1/models/{modèle}/endpoints` पढ़ती है,
  8 000 आउटपुट टोकन से कम सीमा वाले या खराब स्थिति वाले प्रदाताओं को हटाती है, और
  शेष को `allow_fallbacks: false` के साथ निश्चित करती है।
- **तर्क प्रक्रिया का शुल्क आउटपुट की दर से लिया जाता है** — `z-ai/glm-5.2` के
  « OK » उत्तर पर 2 के मुकाबले 107 टोकन। इसे डिफ़ॉल्ट रूप से बंद रखा जाता है; जिन मॉडलों में
  यह अनिवार्य है, उन्हें उनके द्वारा स्वीकार किया जाने वाला सबसे कम प्रयास स्तर दिया जाता है, क्योंकि सूची का
  डिफ़ॉल्ट स्तर अनुवाद पूरा होने से पहले ही आउटपुट सीमा भर सकता है।
  `--reasoning_effort` की प्राथमिकता बनी रहती है।

```
→ OpenRouter : 30 hébergeur(s) épinglé(s) sur 33, contexte 1048576 tokens,
  sortie plafonnée à 32768, raisonnement coupé
```

- संदर्भ विंडो सूची से ली जाती है। 16 400 टोकन से कम वाला मॉडल
  किसी भी कॉल से पहले अस्वीकार कर दिया जाता है: प्रॉम्प्ट और खंड के लिए 8 400, आउटपुट के लिए
  कम से कम 8 000।
- सूची में स्लग न होना, सूची तक पहुँच न होना या
  आवश्यक सीमा पूरी करने वाला कोई होस्टिंग प्रदाता न होना कमांड को रोक देता है।
- खाली आउटपुट के साथ `finish_reason=length` का अर्थ है कि बजट
  तर्क प्रक्रिया में खर्च हो गया, पाठ काटा नहीं गया: संदेश यह अंतर स्पष्ट करता है।
- `--eco` का कोई प्रभाव नहीं है।
- चर: `OPENROUTER_API_KEY` (<https://openrouter.ai/keys>),
  `OPENROUTER_BASE_URL` (डिफ़ॉल्ट `https://openrouter.ai/api/v1`, `https://`
  आवश्यक), `OPENROUTER_TIMEOUT` (डिफ़ॉल्ट 900), `OPENROUTER_PREFLIGHT_TIMEOUT`
  (डिफ़ॉल्ट 30)।

### अनुवाद टिप्पणी

`--add_translation_note` एक टिप्पणी जोड़ता है, `bottom` (डिफ़ॉल्ट), `top` (फ्रंट मैटर
के बाद) या `both` (`--note_position`) में, `legacy` (मोटे अक्षरों वाला
अनुच्छेद, डिफ़ॉल्ट) या `marker` (`--note_format`) प्रारूप में। `marker` प्रारूप एक
अदृश्य Markdown संदर्भ परिभाषा है,
`[ai-translation-note-<placement>]: <> "v=1 source=… target=… model=… date=…"`,
जिसके बाद मोटे अक्षरों में एक उद्धरण आता है: GitHub पर पढ़ने योग्य, और बिल्ड के समय
remark प्लगइन द्वारा उपयोग करने योग्य।

```bash
aipmt --file article.mdx --target_lang en --add_translation_note --note_format marker --note_position top
```

## विस्तृत माप

सभी माप `aipmt` के साथ वास्तव में किए गए अनुवादों के हैं,
चौदह भाषाओं में: en, es, de, it, pt, nl, pl, sv, ro, ja, ko, zh, ar, hi।
**लिखी गईं** उन फ़ाइलों को गिनता है जिन्हें सुरक्षा जाँचों ने पास होने दिया; **बिना
अंतर** उन्हें जिनमें `scripts/compare_structure.py` को कुछ नहीं मिलता — अनुभागों,
उपशीर्षकों, लिंक, अलग-अलग URL, कोड ब्लॉक, इनलाइन
कोड, तालिका पंक्तियों, उद्धरण ब्लॉक और मोटे अक्षरों वाले शब्दों की समान संख्या।

« बिना अंतर » का अर्थ है « कुछ पता नहीं चला », « एकसमान » नहीं: तुलनाकार
तत्वों की सामग्री पढ़े बिना उन्हें गिनता है। वह न स्तर
4 का शीर्षक हटने, न इनलाइन कोड का पाठ बदलने, न झंडा
बदलने, न अतिरिक्त कोष्ठक के साथ प्रस्तुत आंतरिक लिंक,
`[texte]((#ancre))`, के कहीं न पहुँचने को पहचानता है — और न ही भाषा की
जाँच करता है।

(en, ja, ar, hi) पर: 4 में से 4 लिखी गईं, सभी बिना अंतर के, माध्यिका
1 min 52 s। उसी दिन समाचार संकलन के एक अधिक हालिया संस्करण,
25 सितंबर वाले (438 पंक्तियाँ, 2 अंग्रेज़ी उद्धरण), पर प्रति-जाँच की गई, जिसे
ब्लॉग के बाहर `gemini-3.7-flash-medium` से अनुवादित किया गया: 14 में से 14 लिखी गईं, सभी बिना अंतर के, प्रति भाषा 87 से
128 s।

`--use_claude_code` की पंक्तियाँ 26 सितंबर को उसी
लेख पर, चार अनुवाद समानांतर चलाकर, `low` प्रयास स्तर पर मापी गईं। `sonnet` के साथ,
अंग्रेज़ी उद्धरण सभी चौदह भाषाओं में अक्षुण्ण रहे और, अंग्रेज़ी में,
मॉडल ने फ़्रेंच अनुवाद की पंक्तियाँ स्वयं हटा दीं, बिना कोई
झंडा गढ़े। `opus` ने कोई भाषा नहीं लिखी: हर भाषा में उसके सुरक्षा उपायों ने
अंतिम खंड पर उत्तर रोक दिया, क्योंकि एक संक्षिप्त समाचार में एक बंधन स्थल के लिए जनरेट किए गए
279 अणुओं का उल्लेख था। अकेले भेजने पर, यह समाचार
« जीवविज्ञान » श्रेणी के तहत अस्वीकार होता है; `sonnet` ने इसे सभी भाषाओं में अनुवादित किया। `haiku` सभी
चौदह भाषाएँ लिखता है; तीन में (en, pl, ro), एक अनुभाग का शीर्षक
स्तर 2 से स्तर 1 पर चला जाता है। वह तर्क करता है और इसे रोकना संभव नहीं है — उसके
आउटपुट टोकन का 61 % —, इसलिए `sonnet` से दोगुने से भी अधिक समय लगता है।

### ये मापन क्या नहीं हैं

- **संपूर्ण रैंकिंग नहीं**: अकेले OpenRouter पर चार सौ से अधिक
  मॉडल उपलब्ध हैं, जबकि लगभग पंद्रह का मापन किया गया है।
- **सांकेतिक अवधियाँ**: अभियान के अनुसार तीन से छह अनुवाद समानांतर रूप से चलते हैं,
  और प्रदाता की कार्यगति दिन भर बदलती रहती है।
- **तारीख-विशिष्ट अवलोकन**: एक ही नाम के अंतर्गत मॉडल बदलते रहते हैं, और आपके
  दस्तावेज़ हमारे दस्तावेज़ों से अलग हैं।

अपने दस्तावेज़ों पर दोबारा मापन करने के लिए, फ़ाइल की एक स्थिर प्रति पर:

```bash
aipmt --file reference.md --target_dir out/ --source_lang fr --target_lang ja --use_gemini --force
aipmt --file veille.mdx   --target_dir out/ --source_lang fr --target_lang ja --use_gemini --news --force
python scripts/compare_structure.py reference.md out/reference-ja.md
# « structure identique », ou la liste des écarts — sortie 0 si identique, 1 sinon
```

## योगदान दें

```bash
git clone https://github.com/jls42/ai-powered-markdown-translator.git
cd ai-powered-markdown-translator
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt   # les dépendances, lock entièrement épinglé
pip install -e .                  # le paquet lui-même, en mode éditable
```

दोनों पंक्तियाँ आवश्यक हैं: `pip install -e .` के बिना, `python -m aipmt`
का उत्तर `No module named aipmt` होता है।

गुणवत्ता संबंधी उपकरण, वैकल्पिक लेकिन अनुशंसित:

```bash
pipx install pre-commit               # hors venv — absent des requirements
pip install -r requirements-dev.txt   # detect-secrets, pip-audit, mypy, lizard
pre-commit install                    # hooks rapides à chaque commit
pre-commit install --hook-type pre-push  # mypy, SAST, pip-audit, tests avant chaque push
```

रिपॉज़िटरी के 28 अनुवाद (README और CHANGELOG, चौदह भाषाएँ)
`./regen_translations.sh --force` से दोबारा बनाए जाते हैं — डिफ़ॉल्ट रूप से ChatGPT सदस्यता पर Codex और `gpt-6.1-sol` के साथ,
चार समानांतर रूप से। `REGEN_PROVIDER` और
`REGEN_MODEL` प्रक्रिया का रास्ता बदलते हैं: `antigravity` सदस्यता पर ही रहता है, जो
Google की है, और बिना किसी विशेष छूट के चलता है; शुल्क वाली API (`openai`, `gemini`,
`grok`, `openrouter`) को `REGEN_ALLOW_PAID_API=1` के बिना अस्वीकार किया जाता है;
`REGEN_JOB_TIMEOUT` हर कार्य की समय सीमा तय करता है (600 s, Codex और
Antigravity पर 1 800 s)। उपकरणों का विवरण `CLAUDE.md` में है।

يترجم ملفات Markdown من لغة إلى أخرى مع الحفاظ على
البنية: كتل الشيفرة، والشيفرة المضمّنة، وعناوين URL، والمراسي، والجداول، والبيانات
التمهيدية. إحدى عشرة طريقة لاستدعاء نموذج — خمس واجهات API، وأربعة اشتراكات دون
فوترة حسب الاستخدام، وموجّهان — وقياس منشور لما يحافظ عليه كل
نموذج فعليًا.

## لمحة سريعة

- **أحد عشر مسارًا لمزوّدي الخدمة**: واجهات API من OpenAI وMistral وClaude وGemini وGrok؛
  واشتراكات ChatGPT ‏(Codex) وGrok وGoogle ‏(Antigravity) وClaude ‏(Claude
  Code) دون فوترة حسب الاستخدام؛ وموجّها OpenCode ‏(مفتوح المصدر، مجاني أو محلي) وOpenRouter
  (أكثر من 400 نموذج).
- **لا أخطاء بسبب فقدان رمز بديل**: تُستبدل كتل الشيفرة والشيفرة المضمّنة
  وعناوين URL والمراسي والاقتباسات برموز بديلة قبل الاستدعاء،
  ويُتحقّق منها عند استلام النتيجة. إذا غاب أحدها، فلا يُكتب الملف.
- **المستندات الطويلة**: تقسيم بحسب نافذة سياق النموذج.
- **وضع `--news`**: حماية الاقتباسات الإنجليزية وإدارة الخيارات بحسب
  اللغة، لمقالات الرصد.
- **وضع `--eco`**: نماذج سريعة وأقل تكلفة.
- **ملاحظة ترجمة** اختيارية، في الأعلى أو الأسفل أو كليهما.

## التثبيت

```bash
pip install ai-powered-markdown-translator     # ou : pipx install ai-powered-markdown-translator
aipmt --help                                   # ou : python -m aipmt --help
```

Python 3.11 أو أحدث. للتثبيت من المستودع، راجع
[المساهمة](#المساهمة).

## الإعداد

تُقرأ المفاتيح من ثلاثة مواضع، من الأعلى أولوية إلى الأدنى؛ ولا يستكمل كل موضع
إلا ما تركه السابق فارغًا.

|     | الموضع                                            | الغرض                             |
| --- | --------------------------------------------- | ------------------------------------- |
| 1   | متغيرات البيئة                     | CI، والحاويات، والتجاوز المؤقت |
| 2   | `.env` في المجلد الحالي (أو أحد المجلدات الأصلية) | مفتاح خاص بمشروع            |
| 3   | `~/.config/aipmt/.env`                        | يُضبط مرة واحدة ويسري في كل مكان       |

```bash
mkdir -p ~/.config/aipmt
cat > ~/.config/aipmt/.env <<'EOF'
OPENAI_API_KEY=votre-clé-api-openai
XAI_API_KEY=votre-clé-api-xai
MISTRAL_API_KEY=votre-clé-api-mistral
ANTHROPIC_API_KEY=votre-clé-api-anthropic
GOOGLE_API_KEY=votre-clé-api-google
OPENROUTER_API_KEY=votre-clé-api-openrouter
EOF
chmod 600 ~/.config/aipmt/.env
```

يُقبل `GEMINI_API_KEY` بدلًا من `GOOGLE_API_KEY`. يتّبع ملف
المستخدم `XDG_CONFIG_HOME` (مسار مطلق فقط) و`%APPDATA%`
على Windows. عند غياب المفتاح، يسرد الأمر المواضع الثلاثة.

**لا يمكن لملف `.env` الخاص بمشروع إعادة توجيه الاستدعاءات أو اختيار البرنامج
الذي يُشغَّل.** فهو يوفّر مفاتيح، ولا يوفّر وجهة أو ملفًا تنفيذيًا: تُتجاهل فيه جميع
المتغيرات من نوع `_BASE_URL` أو `_API_BASE` أو `_ENDPOINT` أو `_BIN` ‏(`CODEX_BIN`،
`GROK_BIN`، `OPENCODE_BIN`، `AGY_BIN`)، و`GROK_HOME`، والخوادم الوكيلة (`HTTP_PROXY`،
`HTTPS_PROXY`، `ALL_PROXY`)، ومخازن الشهادات (`SSL_CERT_FILE`،
`SSL_CERT_DIR`، `REQUESTS_CA_BUNDLE`، `CURL_CA_BUNDLE`)، و`XDG_CONFIG_HOME` /
`APPDATA`، مع إصدار تحذير. يجب ألا يتمكّن مستودع مستنسخ من
تحويل مفتاحك إلى وجهة أخرى، أو دفعك إلى تشغيل برنامجه الخاص عند
أول ترجمة. ويُقرأ هذا الملف أيضًا دون استبدال مراجع المتغيرات:
فلا ينسخ `NOM=${OPENAI_API_KEY}` المفتاح فيه. ضع هذه المتغيرات في
البيئة أو في `~/.config/aipmt/.env`.

المتغيرات الاختيارية: `XAI_BASE_URL` (الافتراضي `https://api.x.ai/v1`)،
`CLAUDE_TIMEOUT` (ثوانٍ لكل استدعاء، الافتراضي 900)، `CODEX_BIN`، `CODEX_TIMEOUT`
(الافتراضي 600)، `GROK_BIN`، `GROK_HOME` (الافتراضي `~/.grok`)، `GROK_TIMEOUT`
(الافتراضي 900)، `GROK_TRANSLATE_SANDBOX`، `AGY_BIN`، `AGY_TIMEOUT` (الافتراضي 900)،
`OPENCODE_BIN`، `OPENCODE_TIMEOUT` (الافتراضي 600)، `OPENROUTER_BASE_URL`
(يتطلّب `https://`)، `OPENROUTER_TIMEOUT` (الافتراضي 900)،
`OPENROUTER_PREFLIGHT_TIMEOUT` (الافتراضي 30). يُشرح كل منها بالتفصيل في
قسم مزوّد الخدمة المعني.

## الخطوات الأولى

```bash
# un fichier
aipmt --file document.md --target_dir out/ --source_lang fr --target_lang en

# un répertoire
aipmt --source_dir content/fr --target_dir content/en --source_lang fr --target_lang en

# un autre provider
aipmt --use_gemini --file document.md --target_dir out/ --target_lang ja
```

تؤدي ترجمة `document.md` إلى الإسبانية إلى إنشاء `document-es.md` في `--target_dir`؛
ومع `--include_model`، تكون النتيجة `document-es-gpt-5.6-terra.md`. يصبح الامتداد
دائمًا `.md` — فيتحوّل `article.mdx` إلى `article-en.md` — إلا مع
`--keep_filename`، الذي يحتفظ بالاسم الأصلي. تُتخطّى الترجمة الموجودة مسبقًا
ما لم يُستخدم `--force`.

رموز الخروج: `0` إذا اكتمل كل شيء أو جرى تخطّيه، و`1` إذا بقي ملف
فشلت معالجته (تُعرض القائمة في مخرج الأخطاء)، و`2` إذا كان السبب في الإعداد.
لا يُكتب ملف فشلت معالجته أبدًا، حتى إذا فشلت عملية الكتابة نفسها:
يُكتب المحتوى في ملف مجاور ثم يُعاد تسميته. تكفي إعادة التشغيل.

ما ينبغي استخلاصه:

- **الترجمة المرفوضة ليست ترجمة تالفة.** عند غياب رمز بديل
  من النتيجة، لا يُكتب الملف وتُحتسب اللغة
  مرفوضة. وهذا ما يحدث مع Grok في المقال: فقدان أربع شيفرات مضمّنة
  وثلاثة عناوين URL منذ المقطع الأول، في أنظمة الكتابة الخمسة غير اللاتينية.
- **قد يرفض نموذج مستندًا كاملًا بسبب جملة واحدة.** يترجم Opus 5.5
  ملف README هذا دون أي اختلاف، لكنه لا يترجم أي مقال رصد:
  إذ توقف ضوابط الحماية استجابته بسبب خبر موجز عن علم الأحياء. لا يُكتب
  الملف، ويوضّح aipmt السبب.
- **لا تشمل شبكة الحماية هذه العناوين والجداول والبيانات
  التمهيدية والنص.** يُرجع النموذج الذي يحذف قسمًا ملفًا تكتبه الأداة
  دون اعتراض — وهذا ما يحدث مع Mistral. لا يمكن استبدال هذه العناصر
  برمز بديل، ولا تتحقّق منها آليات الحماية الحالية؛
  ويكتشف `scripts/compare_structure.py` القسم المفقود، لكن بعد وقوع الأمر.
- **لا يوجد تقييم لـGrok على ملف README هذا**: انتهت صلاحية جلسة CLI الخاصة به بعد اثنتي عشرة
  لغة، منها إحدى عشرة دون اختلاف. لا تُقيَّم حملة قياس انقطعت.
- **كثافة المستند أهم من اللغة.** ينجح Grok مع
  ملفات README العادية، ويتعثر مع مقال مليء بالروابط، حتى
  بالهولندية.

4 و5 سبتمبر على مقال من 589 سطرًا، باستثناء صف Grok، الذي أُعيد قياسه في
9 سبتمبر على عدد آخر من نشرة الرصد نفسها، وصفوف Antigravity وClaude
Code، التي قيست في 26 سبتمبر على المقال نفسه، وصفوف Claude الثلاثة هذه،
التي قيست في 18 أكتوبر. تتوفر الجداول الكاملة والمدد والمنهجية
في [القياسات التفصيلية](#القياسات-التفصيلية).

## المزوّدون

### عبر API: ‏OpenAI وMistral وClaude وGemini وGrok

```bash
aipmt --source_dir content/fr --target_dir content/en --target_lang en             # OpenAI, défaut
aipmt --use_mistral --source_dir content/fr --target_dir content/es --target_lang es
aipmt --use_claude  --source_dir content/fr --target_dir content/de --target_lang de
aipmt --use_gemini  --source_dir content/fr --target_dir content/ja --target_lang ja
aipmt --use_grok    --source_dir content/fr --target_dir content/pt --target_lang pt
```

يحوّل `--eco` إلى الفئة الاقتصادية لدى كل مزوّد.

| المزوّد    | الجودة (الافتراضي)                                                     | الاقتصادي (`--eco`)      |
| ----------- | -------------------------------------------------------------------- | ------------------------- |
| OpenAI      | `gpt-5.6-terra`                                                      | `gpt-5.6-luna`            |
| Claude      | `claude-sonnet-5-5`                                                  | `claude-haiku-5-5`        |
| Mistral     | `mistral-large-latest`                                               | `mistral-small-latest`    |
| Gemini      | `gemini-3.8-flash`                                                   | `gemini-3.1-flash-lite`   |
| Codex       | `gpt-6.1-sol` (وكذلك `gpt-5.6-sol` و`terra` و`luna` عبر `--model`) | `gpt-5.6-luna`            |
| Grok API    | `grok-4.6`                                                           | `grok-4.3`                |
| Grok CLI    | `grok-4.7`                                                           | نفسه — لا تأثير لـ `--eco` |
| Antigravity | `gemini-3.8-flash-medium`                                            | `gemini-3.7-flash-low`    |
| Claude Code | `sonnet`، بجهد `low`                                               | نفسه — لا تأثير لـ `--eco` |
| OpenCode    | `--model provider/modèle` إلزامي                                | نفسه — لا تأثير لـ `--eco` |
| OpenRouter  | `--model fournisseur/modèle` إلزامي                             | نفسه — لا تأثير لـ `--eco` |

أصبح Gemini 3.7 Flash، الذي كان الافتراضي حتى الإصدار 1.17.1، متقادماً: تقدّم Google
نموذج Gemini 3.8 Flash بدلاً منه، ويظل `--model gemini-3.7-flash` مقبولاً.
يؤدي عطل عابر في API الخاص بـ Gemini (503 أو 429 أو انتهاء المهلة) إلى إعادة
المحاولة حتى ثلاث مرات، بعد 10 ثم 20 ثم 40 ثانية. وتُلغى المحاولة
التي بقيت بلا استجابة بعد 5 دقائق، ثم تُعاد بالطريقة
نفسها: يتسبب الخادم الصامت في فشل المقطع خلال نحو عشرين دقيقة
على الأكثر، بدلاً من التعليق إلى أجل غير محدد.

### عبر اشتراك ChatGPT: ‏`--use_codex`

يشغّل CLI الرسمي لـ Codex: تُحتسب الترجمة من حصة
اشتراك ChatGPT، دون مفتاح API أو فوترة بحسب الاستخدام.

```bash
pip install openai-codex-cli-bin   # package officiel OpenAI (~250 Mo), ou : npm install -g @openai/codex
codex login
aipmt --use_codex --eco --file README.md --target_dir . --target_lang it
```

- يُبحث عن الملف التنفيذي في `CODEX_BIN`، ثم `PATH`، ثم الحزمة
  `openai-codex-cli-bin`. ولا تُقرأ `~/.codex/auth.json` أبداً.
- يُحذف `OPENAI_API_KEY` و`CODEX_API_KEY` من بيئة
  العملية الفرعية: وجود مفتاح لا يؤدي أبداً إلى التحويل نحو API.
- يستهلك كل مقطع «رسالة» واحدة على الأقل من نافذة الساعات الخمس — ورسالتين
  إذا فشل التحقق منه وأُعيدت المحاولة. وتعلن OpenAI، على سبيل
  التقدير، عن 250-2 000 رسالة/5 ساعات لـ `gpt-5.6-luna` (`--eco`)،
  و10-100 لـ `gpt-5.6-sol` ضمن خطة Plus.
- يعمل `--model gpt-5.6-sol`، الذي كان الافتراضي حتى الإصدار 1.16.3، و`--model gpt-5.6-terra`
  و`--model gpt-5.6-luna` عبر الاشتراك أيضاً.
- لا تؤدي استجابة 429 من الخادم إلى ضياع الملف: يعيد Codex الاتصال تلقائياً،
  وينتظر aipmt انتهاء الدور، وإذا ظلت النتيجة النهائية 429، تُعاد محاولة المقطع
  بعد 30 ثم 60 ثانية. ويُرجع النموذج الذي لا يحق للحساب استخدامه خطأ 400 مفاده «النموذج
  غير مدعوم عند استخدام Codex بحساب ChatGPT».
- أبطأ من API، ويزداد الفارق مع طول المستند: في ملف README هذا،
  بلغ الوسيط 6 دقائق و46 ثانية لكل لغة باستخدام `gpt-5.6-sol`، مقابل 36 ثانية باستخدام
  `gemini-3.7-flash`.
- يُرفض في CI (عند تعيين `CI` أو `GITHUB_ACTIONS`): تُجرى مصادقة الاشتراك
  عبر ملف جلسة شخصي، لا مكان له على مشغّل
  مشترك.
- المتغيرات: `CODEX_BIN` و`CODEX_TIMEOUT` (ثوانٍ لكل مقطع، الافتراضي 600).

### عبر اشتراك Grok: ‏`--use_grok_cli`

المبدأ نفسه باستخدام CLI الرسمي لـ Grok Build، ضمن اشتراك SuperGrok أو
X Premium+.

```bash
curl -fsSL https://x.ai/cli/install.sh | bash
grok login                                      # ou : grok login --device-code
aipmt --use_grok_cli --file README.md --target_dir . --target_lang pl
```

- **عزل أضعف من Codex.** لا يُطبّق عزل نظام التشغيل الخاص بـ Grok
  على كثير من أجهزة Linux الحديثة (AppArmor ومقابس بيئة تشغيل
  الحاويات)، ويبدأ التشغيل دون عزل وبصمت إذا تعذّر تطبيق ملف التعريف.
  لذلك لا يطلب البرنامج النصي أي ملف تعريف افتراضياً، ويعلن ذلك،
  ويعتمد على قواعد `--deny` الخاصة بـ CLI، ومنها القاعدة الشاملة `*` — وهي
  الطبقة الوحيدة التي ترفض بدء التشغيل بدلاً من إزالة الحماية دون
  إعلام. ويتطلب `GROK_TRANSLATE_SANDBOX=read-only` عزل نظام التشغيل، ويفشل بدء التشغيل
  إذا تعذّر على الجهاز توفيره.
- الحصة أسبوعية ومشتركة مع Chat وImagine وVoice، ولا يوجد
  أمر يتيح قراءتها: قد تستهلك دفعة ترجمة من الحصة المخصصة للمحادثات
  دون تنبيه.
- المتغيرات: `GROK_BIN` و`GROK_HOME` (مجلد CLI، الافتراضي `~/.grok`)،
  و`GROK_TIMEOUT` (الافتراضي 900)، و`GROK_TRANSLATE_SANDBOX`.

### عبر اشتراك Google: ‏`--use_antigravity`

المبدأ نفسه باستخدام `agy`، وهو CLI الرسمي لـ Antigravity: لمن يدفع مقابل Google
AI Pro أو Ultra، تُحتسب الترجمة من حصة الاشتراك بدلاً
من فوترتها بحسب عدد الرموز. وهذا هو المسار الوحيد إلى تلك الحصة: لم يعد Gemini CLI
يخدم هذه الحسابات منذ 18 يونيو 2026
([الإعلان](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/))،
ولا تقبل حزمة SDK الخاصة بـ Antigravity سوى مفتاح API أو مشروع Google Cloud.

```bash
# agy 1.2.11 ou plus récent : https://antigravity.google/docs/cli/install/
agy                                  # une fois : se connecter avec le compte de l'abonnement
aipmt --use_antigravity --file README.md --target_dir . --target_lang en
agy -p /usage --output-format json   # quota restant, sans en consommer
```

- **لا يبقى أي مسار مدفوع مفتوحاً.** لا يتلقى agy من
  بيئتك إلا قائمة محددة من المتغيرات — `PATH`، واللغة والمنطقة الزمنية،
  والطرفية، والهوية، والخوادم الوكيلة والشهادات، وناقل الجلسة — دون أي مفتاح:
  إذ تحوّل عدة متغيرات فيه مسار الطلب دون إظهار أي شيء (وفق القياس:
  يرسل أحدها المستند إلى بوابة تابعة لطرف ثالث، ويرسله آخر إلى مشروع
  Google Cloud مدفوع)، وكانت قائمة المنع تفوّت بعضها في كل مراجعة.
  قبل أي مقطع، يجب أن يُظهر `agy -p /config`، الذي لا يستهلك أي حصة،
  أن أرصدة الذكاء الاصطناعي المدفوعة معطّلة، وألا يوجد مفتاح API أو مشروع Google Cloud —
  وغياب أي إعداد يعني الرفض — وإلا فلن يُترجم شيء؛ ثم يجب أن يثبت سجل كل
  استدعاء استخدام الاشتراك (`authMethod=consumer`)، وإلا تُرفض
  الاستجابة.
- **العزل.** يعمل كل استدعاء داخل مجلد شخصي خاص
  ومؤقت، مع وكيل ترجمة بلا أدوات: لا تنتقل إليه إعداداتك أو قواعدك أو
  إضافاتك أو خوادم MCP أو خطافات agy، ولا يُضاف شيء إلى
  سجلك، وتبقى بيانات تسجيل الدخول في مخزن المفاتيح الذي لا يقرؤه aipmt أبداً.
  إذا تعذّر العثور على الوكيل، يعود agy بصمت إلى وكيل البرمجة
  وأدواته: يجب أن يؤكد سطر كامل من السجل استخدام الوكيل الصحيح —
  ولا يحل مستند يقتبس هذه الرسالة محل ذلك السطر — وإلا يُرفض الاستدعاء.
- **المنصات**: Linux، ضمن جلسة تتوفر فيها خدمة مخزن مفاتيح (ناقل جلسة
  D-Bus وSecret Service)؛ ويُقبل macOS، دون إجراء قياسات عليه. يُرفض
  على Windows، حيث لا يقرأ agy المتغيرات التي تعزل كل استدعاء، وكذلك
  على Linux دون ناقل جلسة — مثل جلسة SSH أو حاوية أو خادم: إذ يخزّن agy
  رمزه هناك في ملف داخل `~/.gemini`، يحجبه العزل. ويحدث
  الرفض قبل أي تشغيل، مع بيان سببه، بدلاً من انتظار رمز تسجيل دخول
  لمدة دقيقة.
- **النماذج**: النماذج المتاحة عبر `agy models`. تتضمن أسماء نماذج Gemini مستوى الجهد
  (`gemini-3.8-flash-medium`…): ويُرفض الاسم الذي لا يحمل لاحقة قبل الاستدعاء،
  ولا تأثير لـ `--reasoning_effort`. الافتراضي هو `gemini-3.8-flash-medium`،
  و`gemini-3.7-flash-low` عند استخدام `--eco`؛ وحملات القياس التي حدّدتهما
  موصوفة في [القياسات المفصلة](#القياسات-التفصيلية). ولـ Claude وGPT-OSS
  حصة خاصة بهما، أصغر بكثير: نحو 1 % من نافذة
  الساعات الخمس لكل استدعاء مقاس، مقابل 0,05 % مع Flash.
- **الحصة**: لكل مجموعة نافذة من 5 ساعات وأخرى أسبوعية،
  تتناسب مع تكلفة الرموز. وبحسب القياس على حساب المؤلف: نحو
  16 نقطة من نافذة الساعات الخمس لكل مليون محرف من المصدر باستخدام
  `gemini-3.8-flash-medium`، و14 باستخدام `gemini-3.7-flash-medium`، و7 إلى 8 عند
  الجهد المنخفض — لذا يستهلك ملف README من 40 000 محرف ما يزيد قليلاً على
  نصف نقطة. أما الحد الأسبوعي فيعتمد على الفئة. وتعتمد إعادة المحاولة
  على ما يعلن agy أنه قابل لإعادة المحاولة؛ وفي غياب ذلك، لا تُعاد المحاولة أبداً
  عند نفاد حصة النافذة: فيفشل كل ملف حتى موعد إعادة التعيين
  الذي يعرضه `/usage`.
- **أبطأ من API**: في المقالة الكثيفة المستخدمة في القياسات، بلغ الوسيط
  3 دقائق و59 ثانية لكل لغة باستخدام `gemini-3.8-flash-medium`، و3 دقائق و14 ثانية باستخدام
  `gemini-3.7-flash-medium`، مقابل دقيقة و18 ثانية لـ Gemini 3.7 Flash عبر API.
- **المقاطعة**: يؤدي Ctrl-C أو إغلاق الطرفية إلى إيقاف agy مع
  الأمر، بدلاً من تركه يُكمل دوره مستهلكاً حصتك؛ وينطبق
  الشيء نفسه على Codex وGrok CLI وOpenCode. أما تحت `nohup`، فتستمر الترجمة.
- يُرفض في CI (عند تعيين `CI` أو `GITHUB_ACTIONS`): تُحفظ بيانات تسجيل الدخول في
  مخزن مفاتيح شخصي. وعلى مشغّل، استخدم `--use_gemini` مع `GOOGLE_API_KEY`.
- المتغيرات: `AGY_BIN` (وإلا `PATH` ثم `~/.local/bin/agy`)،
  و`AGY_TIMEOUT` (ثوانٍ لكل مقطع، بما في ذلك بدء التشغيل، الافتراضي 900).

**شروط الاستخدام: حسابك هو الذي يتحمل العواقب.** تحظر
[شروط Antigravity](https://antigravity.google/terms) (القسم 6)
و[الأسئلة الشائعة](https://antigravity.google/docs/faq/) الوصول إلى الخدمة
عبر برنامج تابع لطرف ثالث باستخدام بيانات تسجيل الدخول إلى Antigravity — وتذكر Claude Code
وOpenClaw وOpenCode بالاسم — تحت طائلة تعليق الحساب. لا يقرأ aipmt
الرمز ولا يعيد استخدامه: بل يشغّل الملف التنفيذي الرسمي في
[الوضع بلا واجهة](https://antigravity.google/docs/cli/headless/) الذي توثّقه Google
للبرامج النصية وCI. وقد وصف أحد أعضاء Google تشغيل `agy -p` من برنامج نصي محلي لأداء العمل الشخصي بأنه «اعتيادي»
([المنتدى الرسمي، 25 سبتمبر 2026، إجابة غير ملزمة تعاقدياً](https://discuss.ai.google.dev/t/is-using-the-official-agy-cli-through-a-local-mcp-server-with-third-party-ai-agents-permitted/184829))؛
ولا يوجد نص يحسم حالة أداة موزّعة كهذه.

**للمستندات العامة فقط.** وفق القسم 5 من الشروط نفسها، قد تُستخدم
التبادلات — المطالبات والاستجابات والبيانات الوصفية — لتحسين
منتجات Google والتعلم الآلي لديها، وقد يراجعها
بشر، حتى مع الاشتراك المدفوع. ويتم الانسحاب عبر الإعداد
`enableTelemetry`، الذي لم يُوثّق تأثيره ولا يضبطه aipmt؛ ولا تنتقل إعداداتك
في agy إلى بيئته المعزولة. لا تمرّر عبره أي معلومات سرية.
### باستخدام اشتراك Claude: `--use_claude_code`

ينطبق المبدأ نفسه مع `claude`، وهو CLI الرسمي لـ Claude Code، في وضع `-p`: بالنسبة إلى
من يدفع مقابل Claude Pro أو Max، تُحتسب الترجمة من حصة
الاشتراك بدلًا من احتساب تكلفتها بحسب عدد الرموز. وينبغي عدم الخلط بينه وبين
`--use_claude`، وهو API الخاص بـ Anthropic الذي تُحتسب تكلفته بحسب الاستخدام.

```bash
claude                                   # une fois : /login avec le compte de l'abonnement
aipmt --use_claude_code --file README.md --target_dir . --target_lang en
```

- **لا يبقى أي مسار مدفوع متاحًا، وكل استدعاء يثبت ذلك.** لا يتلقى Claude
  Code من بيئتك سوى قائمة مغلقة من المتغيرات — بلا
  مفتاح API أو رمز وصول أو مزود سحابي أو علامة لجلسة Claude Code
  التي يُشغَّل منها aipmt. قبل المقطع الأول، يجب أن يُظهر `claude auth status`
  الاتصال عبر الاشتراك، دون مفتاح Console، وأن يؤكد ذلك `/usage`، الذي لا يستهلك
  أي حصة؛ ويؤكد كل استدعاء ذلك بدوره في
  حدث التهيئة الخاص به، وإلا تُرفض الاستجابة.
- **عطّل «الاستخدام الإضافي»** (claude.ai، الإعدادات ← الاستخدام) حتى
  تظل التكلفة صفر يورو: عند تفعيله، يتولى المتابعة بعد نفاد حصة إحدى النوافذ
  ويفرض رسومًا دون إظهار خطأ. يوقف aipmt الترجمة فور أن يشير تقرير
  حصة أحد الاستدعاءات إلى ذلك، لكن هذا الاستدعاء يكون قد احتُسب بالفعل.
- **الحصة مشتركة مع جلسات Claude Code الخاصة بك.** يُبلغ كل استدعاء
  عن استخدام نافذة الساعات الخمس والنافذة الأسبوعية؛ وعند تجاوز 80 %
  (`AIPMT_CLAUDE_MAX_UTILIZATION`)، لا يبدأ أي مقطع إضافي، حتى لا
  تُستنفد الحصة التي تحتاج إليها في عملك.
- **العزل.** يعمل كل استدعاء دون أدوات، داخل مجلد خاص
  ومؤقت، في وضع دون تخصيص: فلا تُحمَّل ملفات `CLAUDE.md` الخاصة بك، ولا إضافاتك،
  ولا hooks أو خوادم MCP أو إعداداتك، ولا يُحتفَظ بشيء من
  الجلسة. المرفقات معطّلة: يظل `@chemin` الموجود في مستندك
  نصًا ولا يفتح أي ملف (جرى قياس ذلك).
- **النماذج**: `sonnet` افتراضيًا، بجهد `low`، وكذلك في `--eco`:
  لا يغيّر `--eco` شيئًا في هذا المسار. عند القياس على المستندات نفسها، يستغرق `haiku`
  ضعف الوقت — فهو يستدل دون إمكانية منعه من ذلك — مقابل
  تكلفة أقل بقليل، ويرفض `opus` محتويات في علم الأحياء (النقطة
  التالية). يظل كلاهما متاحًا عبر `--model`؛ وتتبع هذه الأسماء المستعارة
  أحدث نموذج في عائلتها. يُرفض `fable` ومتغيرات `[1m]`،
  لأنها تستخدم أرصدة مدفوعة. يضبط `--reasoning_effort` الجهد،
  الذي لا تستفيد منه الترجمة: فالاستدلال المقاس معدوم أو شبه معدوم.
- **يرفض Opus بعض محتويات علم الأحياء.** ضوابطه الوقائية
  أشد من ضوابط Sonnet، وتحذر رسالة الخطأ الصادرة عن Anthropic من أنها
  «قد ترصد أحيانًا أعمالًا ذات صلة بأبحاث علم الأحياء». القياس: تسبب خبر موجز
  عن 279 جزيئًا مولّدًا في رفض المقال باللغات الأربع عشرة.
  لا يُكتب شيء: يرفض aipmt الاستجابة المقطوعة، ويذكر
  الضوابط الوقائية ويوصي بـ `--model sonnet`.
- مرفوض في CI (عند تعيين `CI` أو `GITHUB_ACTIONS`) وعلى Windows (لم يُقَس).
- المتغيرات: `AIPMT_CLAUDE_BIN` (وإلا `PATH`، ثم `~/.local/bin/claude`)،
  `AIPMT_CLAUDE_TIMEOUT` (الثواني لكل مقطع، الافتراضي 900)،
  `AIPMT_CLAUDE_MAX_UTILIZATION` (الافتراضي 0.8)، `CLAUDE_CONFIG_DIR` (حساب
  Claude Code، ولا يؤخذ أبدًا من `.env` خاص بالمشروع)؛ مجلدات العمل تحت
  `XDG_CACHE_HOME/aipmt/claude-code` (الافتراضي `~/.cache`).

**شروط الاستخدام: حسابك هو الذي يتحمل المسؤولية.** لا تمنع
[الصفحة القانونية لـ Claude Code](https://code.claude.com/docs/en/legal-and-compliance)
«مستخدمًا نهائيًا من تسجيل الدخول إلى الملف التنفيذي غير المعدّل لـ Claude Code
باستخدام اشتراك Claude الخاص به»: وهذا ما يفعله aipmt، إذ يشغّل
الملف التنفيذي الرسمي ولا يقرأ رمز الوصول أبدًا. لكن Anthropic «لا تسمح
لمطوري الأطراف الثالثة […] بتوجيه الطلبات عبر بيانات اعتماد خطط Free أو Pro أو Max
نيابةً عن مستخدميهم»، وتفضّل مفتاح API للأدوات
التابعة لأطراف ثالثة، «بما فيها المشاريع مفتوحة المصدر»، وتحتفظ بحق احتساب
استخدامها من الأرصدة المدفوعة
([مساعدة Claude](https://support.claude.com/en/articles/13189465-logging-in-to-your-claude-account)).
ولا يوجد نص يحسم حالة أداة موزَّعة تشغّل الملف التنفيذي.

**البيانات**: في حسابات Free وPro وMax، ينطبق تدريب النماذج
أيضًا على Claude Code عندما يسمح إعداد الخصوصية بذلك
([صفحة البيانات](https://code.claude.com/docs/en/data-usage)). لا يحتفظ aipmt
بأي سجل محادثة محلي (`--no-session-persistence`). لا تمرّر عبره
أي محتوى سري.

### إلى المزود الذي تختاره: `--use_opencode`

[OpenCode](https://opencode.ai) وكيل برمجة مفتوح المصدر (MIT)
يوجّه الطلبات إلى المزودين المضبوطين داخله: مفتاح API، أو اشتراك،
أو بوابة OpenCode Zen (نماذج مجانية، دون حساب)، أو نموذج محلي. جرى هنا
قياس مسارين من البداية إلى النهاية، هما Zen وOllama.

```bash
curl -fsSL https://opencode.ai/install | bash   # ou : npm install -g opencode-ai
opencode models                                 # les modèles, au format provider/modèle
opencode auth login                             # facultatif : brancher un fournisseur

# gratuit, sans compte ni clé — données utilisables pour l'entraînement
aipmt --use_opencode --model opencode/mimo-v2.5-free --file README.md --target_dir . --target_lang en
# local, hors ligne
aipmt --use_opencode --model ollama/qwen2.5:7b --file README.md --target_dir . --target_lang de
# sur un abonnement déjà payé
aipmt --use_opencode --model github-copilot/gpt-5 --file README.md --target_dir . --target_lang ja
```

`--model` إلزامي: بدونه، سيعود OpenCode إلى نموذج مجاني
قد تُستخدم المحادثات معه في التدريب، ولا يُتخذ هذا القرار
نيابةً عنك.

العزل في كل استدعاء:

- يحدد إعداد مضمّن، له الأولوية على إعدادك، وكيلًا `aipmt`
  تُرفض جميع أدواته (`permission: { "*": "deny" }`)، مع تعطيل مشاركة
  الجلسة، و`--pure`، ودون `--auto` مطلقًا؛
- مجلد عمل مؤقت وفارغ، مع تعيين `OPENCODE_DISABLE_PROJECT_CONFIG` و
  `OPENCODE_DISABLE_CLAUDE_CODE` — فبدونهما يُدرج OpenCode في
  الموجّه `AGENTS.md` الخاص بالمجلد الحالي و`~/.claude/CLAUDE.md`. ويظل
  `~/.config/opencode/AGENTS.md` العام مُدرجًا، إذ لا يتيح OpenCode
  استبعاده؛
- شروط المخرجات: رمز خروج 0، وعدم وجود أي حدث `error`، أو أي استدعاء
  أداة، وأن تكون الخطوة الأخيرة في `stop`، والنص غير فارغ، وأن يكون الوكيل `aipmt`
  قد حُمّل بالفعل — فالقيمة غير المعروفة لـ `--agent` لا تتسبب في فشل OpenCode، بل
  يعود بصمت إلى وكيل البرمجة؛
- لا يُمرَّر أي مفتاح من `aipmt` باستثناء `OPENCODE_API_KEY`، وهو مفتاح
  OpenCode نفسه. تُضبط إعدادات المزودين داخل OpenCode، وليس في
  `.env` الخاص بـ `aipmt`.

ما ينبغي معرفته:

- تتغير نماذج Zen المجانية، وحدودها غير موثقة، وقد
  تُستخدم المحادثات معها في التدريب: تصلح للوثائق
  العامة، لا للمحتوى الخاص.
- يجب أن يوفّر النموذج المحلي سياقًا لا يقل عن 16 k رمز، إذ يصل طول
  المقاطع إلى 16 000 محرف. غالبًا ما يضبط Ollama ذلك على 4 096: استخدم
  `Modelfile` مع `PARAMETER num_ctx 32768`.
- لا تأثير لـ `--eco`؛ ويُمرَّر `--reasoning_effort` كما هو بوصفه
  `--variant` في OpenCode.
- يسجّل OpenCode كل جلسة في `~/.local/share/opencode/`.
- المتغيرات: `OPENCODE_BIN` (وإلا `PATH`، ثم `~/.opencode/bin/opencode`)،
  `OPENCODE_TIMEOUT` (الثواني لكل مقطع، الافتراضي 600). ويُمرَّر `OPENCODE_CONFIG`
  كما هو إلى OpenCode.

مثال لنموذج محلي عبر Ollama، في `~/.config/opencode/opencode.json`:

```bash
ollama pull gpt-oss:20b
printf 'FROM gpt-oss:20b\nPARAMETER num_ctx 32768\n' > gpt-oss-20b-32k.Modelfile
ollama create gpt-oss-20b-32k -f gpt-oss-20b-32k.Modelfile
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama (local)",
      "options": { "baseURL": "http://127.0.0.1:11434/v1" },
      "models": {
        "gpt-oss-20b-32k": {
          "name": "gpt-oss 20B (32k, sans réflexion)",
          "limit": { "context": 32768, "output": 8192 },
          "options": { "reasoningEffort": "none" }
        }
      }
    }
  }
}
```

يعطّل `reasoningEffort: "none"` التفكير الذي يفعّله Ollama افتراضيًا في هذه
النماذج، والذي لا يمكن لملف Modelfile تعطيله. القياس على جملة من
ست كلمات: 919 رمز تفكير و68 ثانية دون الخيار، و9 رموز معه.

### إلى أكثر من 400 نموذج: `--use_openrouter`

OpenRouter موجّه تُحتسب تكلفته بحسب الاستخدام، برصيد موحّد، للوصول إلى
نماذج تستضيفها أطراف ثالثة — ومنها النماذج الصينية المفتوحة التي لا
يتيحها هنا أي مزود آخر.

```bash
aipmt --use_openrouter --model z-ai/glm-5.2 --file README.md --target_dir . --target_lang en
```

`--model` إلزامي. يعالج فحص مسبق، يُنفَّذ قبل احتساب أي رسوم،
خاصيتين من خصائص التوجيه:

- **يقدّم النموذج نفسه عشرات من مزودي الاستضافة ذوي حدود
  مختلفة** — في `z-ai/glm-5.3-flash`، يوجد 23 مزود استضافة، أحدهم يحدّ المخرجات عند
  2 048 رمزًا. يقرأ الفحص المسبق `/api/v1/models/{modèle}/endpoints`،
  ويستبعد مزودي الاستضافة الذين يقل حد مخرجاتهم عن 8 000 رمز أو تتراجع جودة خدمتهم،
  ويثبّت الباقين باستخدام `allow_fallbacks: false`.
- **تُحتسب تكلفة الاستدلال بسعر المخرجات** — 107 رموز مقابل 2
  لإجابة «حسنًا» من `z-ai/glm-5.2`. يُعطَّل افتراضيًا؛ أما النماذج
  التي تفرضه فتتلقى أدنى جهد تقبله، إذ قد يؤدي الإعداد الافتراضي
  في الفهرس إلى استنفاد سعة المخرجات قبل اكتمال الترجمة.
  وتظل الأولوية لـ `--reasoning_effort`.

```
→ OpenRouter : 30 hébergeur(s) épinglé(s) sur 33, contexte 1048576 tokens,
  sortie plafonnée à 32768, raisonnement coupé
```

- تُؤخذ نافذة السياق من الفهرس. يُرفض أي نموذج تقل نافذته عن 16 400 رمز
  قبل أي استدعاء: 8 400 للموجّه والمقطع، و8 000 للمخرجات
  كحد أدنى.
- يتوقف الأمر إذا كان المعرّف المختصر غائبًا عن الفهرس، أو تعذّر الوصول إلى الفهرس،
  أو لم يوجد مزود استضافة يستوفي الحد المطلوب.
- يشير `finish_reason=length` مع مخرجات فارغة إلى ميزانية استهلكها
  الاستدلال، لا إلى اقتطاع: وتوضح الرسالة هذا الفرق.
- لا تأثير لـ `--eco`.
- المتغيرات: `OPENROUTER_API_KEY` (<https://openrouter.ai/keys>)،
  `OPENROUTER_BASE_URL` (الافتراضي `https://openrouter.ai/api/v1`، و`https://`
  مطلوب)، `OPENROUTER_TIMEOUT` (الافتراضي 900)، `OPENROUTER_PREFLIGHT_TIMEOUT`
  (الافتراضي 30).

### ملاحظة الترجمة

يضيف `--add_translation_note` ملاحظة، في `bottom` (الافتراضي)، أو `top` (بعد
البيانات الوصفية الافتتاحية)، أو `both` (`--note_position`)، بتنسيق `legacy` (فقرة
بخط عريض، وهو الافتراضي)، أو `marker` (`--note_format`). وتنسيق `marker` هو
تعريف مرجعي غير مرئي في Markdown،
`[ai-translation-note-<placement>]: <> "v=1 source=… target=… model=… date=…"`،
يتبعه اقتباس بخط عريض: يمكن قراءته على GitHub، والاستفادة منه أثناء البناء عبر
إضافة remark.

```bash
aipmt --file article.mdx --target_lang en --add_translation_note --note_format marker --note_position top
```

## القياسات التفصيلية

جميع القياسات لترجمات نُفّذت بالفعل باستخدام `aipmt`، إلى
أربع عشرة لغة: الإنجليزية، والإسبانية، والألمانية، والإيطالية، والبرتغالية، والهولندية، والبولندية، والسويدية، والرومانية، واليابانية، والكورية، والصينية، والعربية، والهندية.
تحصي **المكتوبة** الملفات التي سمحت آليات الحماية بمرورها؛ وتحصي **بلا
اختلاف** الملفات التي لم يرصد فيها `scripts/compare_structure.py` شيئًا — أي العدد نفسه من
الأقسام، والعناوين الفرعية، والروابط، وعناوين URL المختلفة، وكتل الشيفرة،
والشيفرات المضمّنة، وصفوف الجداول، وكتل الاقتباس، والكلمات المكتوبة بخط عريض.

تعني «بلا اختلاف» أنه «لم يُرصد شيء»، لا أنها «متطابقة»: فالمقارن
يعدّ العناصر دون قراءة محتواها. ولا يرصد حذف عنوان من
المستوى 4، أو استبدال نص شيفرة مضمّنة، أو تبديل علم،
أو إخراج رابط داخلي بقوس زائد،
`[texte]((#ancre))`، بحيث لا يعود يؤدي إلى أي مكان — كما أنه لا يقيّم
اللغة.

إلى فعل أي شيء. في `--eco` (`gemini-3.7-flash-low`)، وعلى أربع لغات
فقط (الإنجليزية واليابانية والعربية والهندية): كُتبت 4 من أصل 4، كلها بلا اختلاف، وبوسيط 1 دقيقة و52 ثانية.
وأُجري اختبار تحقّق في اليوم نفسه على إصدار أحدث من الرصد،
هو إصدار 25 سبتمبر (438 سطرًا، واقتباسان إنجليزيان)، تُرجم خارج
المدونة باستخدام `gemini-3.7-flash-medium`: كُتبت 14 من أصل 14، كلها بلا اختلاف، واستغرقت كل لغة من 87 إلى
128 ثانية.

قِيست صفوف `--use_claude_code` في 26 سبتمبر على
المقال نفسه، بأربع ترجمات متوازية، وبجهد `low`. مع `sonnet`،
ظلت الاقتباسات الإنجليزية سليمة في اللغات الأربع عشرة، وفي الإنجليزية
أزال النموذج بنفسه أسطر الترجمة الفرنسية، دون اختلاق
علم. لم يكتب `opus` أي لغة: ففي كل لغة أوقفت ضوابطه الوقائية
الاستجابة عند المقطع الأخير، بسبب خبر موجز عن 279 جزيئًا
مولّدًا لموقع ارتباط. وعند إرسال هذا الخبر وحده، رُفض
ضمن فئة «علم الأحياء»؛ بينما ترجمه `sonnet` إلى جميع اللغات. يكتب `haiku`
اللغات الأربع عشرة؛ وفي ثلاث منها (الإنجليزية والبولندية والرومانية)، ينتقل عنوان قسم من
المستوى 2 إلى المستوى 1. وهو يستدل دون إمكانية منعه من ذلك — بما يشكل 61 % من
رموز مخرجاته —، لذا يستغرق أكثر من ضعف وقت `sonnet`.

قِيست صفوف `claude-sonnet-5-5` و`claude-haiku-5-5` و`claude-haiku-4-5`
في 18 أكتوبر عبر API الخاص بـ Anthropic، على المقال نفسه، بأربع
ترجمات متوازية لكل نموذج. يرفض Sonnet 5.5 تعطيل
تفكيره: يرسل إليه aipmt أدنى إعداد يقبله، ولا تحمل
استجاباته أي أثر للتفكير. يكتب اللغات الأربع عشرة بلا اختلاف ودون
إعادة معالجة أي مقطع؛ وفي الإنجليزية، أزال بنفسه أسطر
الترجمة الفرنسية، دون اختلاق علم، وظلت الاقتباسات الإنجليزية
سليمة في جميع اللغات. قِيس Haiku 5.5 باستخدام تفكيره التكيفي: فعند تعطيل
التفكير، كان يترك فقرات كاملة بالفرنسية ترفضها آلية الحماية —
فكُتبت 3 لغات من أصل 14. ويتعثر نموذجا Haiku عند الخبر الموجز نفسه: إذ يغيّر Haiku 5.5
مستوى عنوانه أو يكرره في اليابانية والكورية
والصينية، ويرفعه Haiku 4.5 إلى المستوى 1 في سبع لغات، ويتركه
بالفرنسية في الترجمة اليابانية. تبلغ تكلفة Haiku 4.5 للمستندين
باللغات الأربع عشرة 3,67 $، وتكلفة Haiku 5.5 هي 0,57 $، وتكلفة Sonnet 5.5 هي 9,21 $.

### ما لا تمثّله هذه القياسات

- **ليست ترتيبًا شاملًا**: يوفّر OpenRouter وحده أكثر من أربعمئة
  نموذج، وقد قِيس نحو خمسة عشر منها.
- **مدد استرشادية**: من ثلاث إلى ست ترجمات بالتوازي بحسب
  الحملة، كما يتغيّر معدل معالجة المزوّد خلال اليوم.
- **ملاحظات مرتبطة بتاريخها**: تتغيّر النماذج مع احتفاظها بالاسم نفسه، ومستنداتكم
  تختلف عن مستنداتنا.

لإعادة القياس على مستنداتكم، باستخدام نسخة مثبّتة من الملف:

```bash
aipmt --file reference.md --target_dir out/ --source_lang fr --target_lang ja --use_gemini --force
aipmt --file veille.mdx   --target_dir out/ --source_lang fr --target_lang ja --use_gemini --news --force
python scripts/compare_structure.py reference.md out/reference-ja.md
# « structure identique », ou la liste des écarts — sortie 0 si identique, 1 sinon
```

## المساهمة

```bash
git clone https://github.com/jls42/ai-powered-markdown-translator.git
cd ai-powered-markdown-translator
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt   # les dépendances, lock entièrement épinglé
pip install -e .                  # le paquet lui-même, en mode éditable
```

كلا السطرين ضروري: من دون `pip install -e .`، يردّ `python -m aipmt`
بـ`No module named aipmt`.

أدوات الجودة، اختيارية ولكن يُوصى بها:

```bash
pipx install pre-commit               # hors venv — absent des requirements
pip install -r requirements-dev.txt   # detect-secrets, pip-audit, mypy, lizard
pre-commit install                    # hooks rapides à chaque commit
pre-commit install --hook-type pre-push  # mypy, SAST, pip-audit, tests avant chaque push
```

تُعاد توليد ترجمات المستودع الـ28 (README وCHANGELOG، بأربع عشرة لغة)
باستخدام `./regen_translations.sh --force` — عبر Codex و`gpt-6.1-sol` على
اشتراك ChatGPT افتراضيًا، أربع ترجمات بالتوازي. يغيّر `REGEN_PROVIDER` و
`REGEN_MODEL` المسار: يظل `antigravity` معتمدًا على اشتراك، وهو
اشتراك Google، ويُسمح به دون استثناء؛ أما API المدفوعة (`openai` و`gemini`،
و`grok` و`openrouter`) فتُرفض دون `REGEN_ALLOW_PAID_API=1`؛
ويضع `REGEN_JOB_TIMEOUT` حدًا أقصى لكل مهمة (600 s، و1 800 s على Codex و
Antigravity). تفاصيل الأدوات موجودة في `CLAUDE.md`.

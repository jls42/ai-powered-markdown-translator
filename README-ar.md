يترجم ملفات Markdown من لغة إلى أخرى مع الحفاظ على
البنية: كتل الشيفرة، والشيفرة المضمنة، وعناوين URL، والمراسي، والجداول،
والبيانات الوصفية الافتتاحية. إحدى عشرة طريقة لاستدعاء نموذج — خمس واجهات API، وأربعة اشتراكات دون
فوترة حسب الاستخدام، وموجّهان — مع قياس منشور لما يحافظ عليه كل
نموذج فعليًا.

## لمحة سريعة

- **أحد عشر مسارًا للمزوّدين**: واجهات API من OpenAI وMistral وClaude وGemini وGrok؛
  واشتراكات ChatGPT ‏(Codex) وGrok وGoogle ‏(Antigravity) وClaude ‏(Claude
  Code) دون فوترة حسب الاستخدام؛ والموجّهان OpenCode (مفتوح المصدر، مجاني أو محلي) وOpenRouter
  (أكثر من 400 نموذج).
- **لا تلف بسبب فقدان رمز بديل**: تُستبدل كتل الشيفرة، والشيفرة المضمنة،
  وعناوين URL، والمراسي، والاقتباسات برموز بديلة قبل الاستدعاء،
  ثم يُتحقق منها عند عودة النتيجة. إذا فُقد أحدها، فلا يُكتب الملف.
- **المستندات الطويلة**: تقسيم وفق نافذة سياق النموذج.
- **وضع `--news`**: اقتباسات إنجليزية محمية وأعلام تُدار حسب
  اللغة، لمقالات الرصد.
- **وضع `--eco`**: نماذج سريعة وأقل تكلفة.
- **ملاحظة ترجمة** اختيارية، في الأعلى أو الأسفل أو كليهما.

## التثبيت

```bash
pip install ai-powered-markdown-translator     # ou : pipx install ai-powered-markdown-translator
aipmt --help                                   # ou : python -m aipmt --help
```

Python 3.11 أو أحدث. للتثبيت من المستودع، راجع
[المساهمة](#المساهمة).

## الإعداد

تُقرأ المفاتيح من ثلاثة مواضع، من الأعلى أولوية إلى الأدنى؛ ولا يملأ كل موضع
إلا ما تركه السابق فارغًا.

|     | الموضع                                            | الغرض                             |
| --- | --------------------------------------------- | ------------------------------------- |
| 1   | متغيرات البيئة                     | CI، والحاويات، والتجاوز المؤقت للإعدادات |
| 2   | `.env` في المجلد الحالي (أو أحد المجلدات الأصل) | مفتاح خاص بمشروع            |
| 3   | `~/.config/aipmt/.env`                        | يُعدّ مرة واحدة ويسري في كل مكان       |

```bash
mkdir -p ~/.config/aipmt
cat > ~/.config/aipmt/.env <<'EOF'
OPENAI_API_KEY=votre-clé-api-openai
XAI_API_KEY=votre-clé-api-xai
MISTRAL_API_KEY=votre-clé-api-mistral
ANTHROPIC_API_KEY=votre-clé-api-anthropic
GOOGLE_API_KEY=votre-clé-api-google
OPENROUTER_API_KEY=votre-clé-api-openrouter
EOF
chmod 600 ~/.config/aipmt/.env
```

يُقبل `GEMINI_API_KEY` بدلًا من `GOOGLE_API_KEY`. يتبع ملف
المستخدم `XDG_CONFIG_HOME` (مسار مطلق فقط) و`%APPDATA%`
على Windows. عند عدم وجود مفتاح، يسرد الأمر المواضع الثلاثة.

**لا يمكن لملف `.env` الخاص بمشروع إعادة توجيه الاستدعاءات أو اختيار البرنامج
الذي يُشغّل.** فهو يوفّر مفاتيح، ولا يحدّد وجهة أو ملفًا تنفيذيًا: تُتجاهل فيه جميع
المتغيرات من نوع `_BASE_URL` أو `_API_BASE` أو `_ENDPOINT` أو `_BIN` ‏(`CODEX_BIN`،
`GROK_BIN`، `OPENCODE_BIN`، `AGY_BIN`)، و`GROK_HOME`، والخوادم الوكيلة (`HTTP_PROXY`،
`HTTPS_PROXY`، `ALL_PROXY`)، ومخازن الشهادات (`SSL_CERT_FILE`،
`SSL_CERT_DIR`، `REQUESTS_CA_BUNDLE`، `CURL_CA_BUNDLE`)، و`XDG_CONFIG_HOME` /
`APPDATA`، مع إصدار تحذير. يجب ألا يتمكن مستودع مستنسخ من
تحويل مفتاحك إلى وجهة أخرى، أو دفعك إلى تشغيل برنامجه الخاص عند
أول ترجمة. ويُقرأ هذا الملف أيضًا دون استيفاء المتغيرات:
فلا ينسخ `NOM=${OPENAI_API_KEY}` المفتاح فيه. ضع هذه المتغيرات في
البيئة أو في `~/.config/aipmt/.env`.

المتغيرات الاختيارية: `XAI_BASE_URL` (القيمة الافتراضية `https://api.x.ai/v1`)،
`CLAUDE_TIMEOUT` (ثوانٍ لكل استدعاء، القيمة الافتراضية 900)، `CODEX_BIN`، `CODEX_TIMEOUT`
(القيمة الافتراضية 600)، `GROK_BIN`، `GROK_HOME` (القيمة الافتراضية `~/.grok`)، `GROK_TIMEOUT`
(القيمة الافتراضية 900)، `GROK_TRANSLATE_SANDBOX`، `AGY_BIN`، `AGY_TIMEOUT` (القيمة الافتراضية 900)،
`OPENCODE_BIN`، `OPENCODE_TIMEOUT` (القيمة الافتراضية 600)، `OPENROUTER_BASE_URL`
(يتطلب `https://`)، `OPENROUTER_TIMEOUT` (القيمة الافتراضية 900)،
`OPENROUTER_PREFLIGHT_TIMEOUT` (القيمة الافتراضية 30). تجد تفاصيل كل منها في
قسم المزوّد المعني.

## الخطوات الأولى

```bash
# un fichier
aipmt --file document.md --target_dir out/ --source_lang fr --target_lang en

# un répertoire
aipmt --source_dir content/fr --target_dir content/en --source_lang fr --target_lang en

# un autre provider
aipmt --use_gemini --file document.md --target_dir out/ --target_lang ja
```

تؤدي ترجمة `document.md` إلى الإسبانية إلى إنشاء `document-es.md` في `--target_dir`؛
ومع `--include_model`، تكون النتيجة `document-es-gpt-5.6-terra.md`. يصبح الامتداد
دائمًا `.md` — فيتحول `article.mdx` إلى `article-en.md` — إلا عند استخدام
`--keep_filename`، الذي يحافظ على الاسم الأصلي. تُتخطى الترجمة الموجودة مسبقًا
ما لم يُستخدم `--force`.

رموز الخروج: `0` إذا نجح كل شيء أو جرى تخطيه، و`1` إذا بقي ملف
فشلت معالجته (تُعرض القائمة في مخرج الأخطاء)، و`2` إذا كان السبب هو الإعداد.
لا يُكتب الملف الذي فشلت معالجته مطلقًا، حتى لو فشلت عملية الكتابة نفسها:
يُكتب المحتوى في ملف مجاور ثم يُعاد تسميته. تكفي إعادة التشغيل.

ما ينبغي استخلاصه:

- **الترجمة المرفوضة ليست ترجمة تالفة.** عندما يُفقد رمز بديل
  في النتيجة، لا يُكتب الملف وتُحسب اللغة ضمن
  اللغات المرفوضة. وهذا ما يحدث مع Grok في المقال: أربع شيفرات مضمنة
  وثلاثة عناوين URL مفقودة منذ المقطع الأول، في أنظمة الكتابة الخمسة غير اللاتينية.
- **قد يرفض نموذج مستندًا كاملًا بسبب جملة واحدة.** يترجم Opus 5.5
  ملف README هذا دون أي اختلاف، لكنه لا يترجم أي مقال رصد: إذ
  توقف آليات الحماية استجابته عند خبر موجز في علم الأحياء. لا يُكتب
  الملف، ويوضح aipmt السبب.
- **لا تشمل شبكة الحماية هذه العناوين أو الجداول أو البيانات الوصفية الافتتاحية أو
  النص.** إذا حذف نموذج قسمًا، يعيد ملفًا تكتبه الأداة
  دون اعتراض — وهذا ما يحدث مع Mistral. لا يمكن
  استبدال هذه العناصر برمز بديل، ولا تتحقق منها آليات الحماية الحالية؛
  ويكشف `scripts/compare_structure.py` القسم المفقود، لكن بعد وقوع ذلك.
- **لم يُقيَّم Grok على ملف README هذا**: انتهت صلاحية جلسة CLI الخاصة به بعد اثنتي عشرة
  لغة، منها إحدى عشرة دون اختلاف. لا تُقيَّم حملة توقفت قبل اكتمالها.
- **كثافة المستند أهم من اللغة.** ينجح Grok مع
  ملفات README العادية، ويتعثر في مقال مليء بالروابط، حتى
  بالهولندية.

4 و5 سبتمبر على مقال من 589 سطرًا، باستثناء صف Grok، الذي أُعيد قياسه في
9 سبتمبر على إصدار آخر من الرصد نفسه، وصفوف Antigravity
وClaude Code، التي قِيست في 26 سبتمبر على المقال نفسه، وصفوف Claude
الثلاثة هذه، التي قِيست في 18 أكتوبر. تتوفر الجداول الكاملة والمدد وبروتوكول القياس
في [القياسات التفصيلية](#القياسات-التفصيلية).
## جميع الخيارات

| الخيار                   | الوصف                                                                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------------------------- |

| `--model`                | نموذج محدد لاستخدامه                                                                                  |
| `--eco`                  | استخدام النماذج الاقتصادية                                                                              |

| `--use_claude`           | استخدام API الخاص بـ Claude                                                                                         |
| `--use_gemini`           | استخدام API الخاص بـ Gemini                                                                                         |
| `--use_grok`             | استخدام API الخاص بـ xAI (Grok) — يتطلب `XAI_API_KEY`                                                           |

| `--use_grok_cli`         | استخدام CLI الخاص بـ Grok ضمن حصة اشتراك Grok                                                        |

| `--use_claude_code`      | استخدام CLI الخاص بـ Claude Code (`claude -p`) ضمن حصة اشتراك Claude Pro أو Max                      |

### ضمن اشتراك ChatGPT:‏ `--use_codex`

يشغّل CLI الرسمي لـ Codex: تُخصم الترجمة من حصة
اشتراك ChatGPT، دون مفتاح API أو فوترة بحسب الاستخدام.

```bash
pip install openai-codex-cli-bin   # package officiel OpenAI (~250 Mo), ou : npm install -g @openai/codex
codex login
aipmt --use_codex --eco --file README.md --target_dir . --target_lang it
```

- يُبحث عن الملف التنفيذي في `CODEX_BIN`، ثم في `PATH`، ثم في الحزمة
  `openai-codex-cli-bin`. ولا يُقرأ `~/.codex/auth.json` مطلقًا.
- يُحذف `OPENAI_API_KEY` و`CODEX_API_KEY` من بيئة
  العملية الفرعية: لا يؤدي وجود مفتاح مطلقًا إلى التحويل إلى API.
- يستهلك كل مقطع «رسالة» واحدة على الأقل من نافذة الساعات الخمس — ورسالتين
  إذا فشل التحقق منه وأُعيدت المحاولة. تعلن OpenAI، على سبيل
  التقدير، عن 250-2 000 رسالة لكل 5 ساعات لـ `gpt-5.6-luna` (`--eco`) و
  10-100 لـ `gpt-5.6-sol` ضمن خطة Plus.
- يعمل `--model gpt-5.6-sol`، الذي كان الافتراضي حتى الإصدار 1.16.3، و`--model gpt-5.6-terra`
  و`--model gpt-5.6-luna` أيضًا عبر الاشتراك.
- لا يؤدي خطأ 429 من الخادم إلى فقدان الملف: يعيد Codex الاتصال تلقائيًا،
  وينتظر aipmt انتهاء الدور، وإذا استمر خطأ 429 حتى النهاية، يُعاد تشغيل المقطع
  بعد 30 ثم 60 ثانية. ويؤدي استخدام نموذج لا يحق للحساب الوصول إليه إلى خطأ 400 «النموذج
  غير مدعوم عند استخدام Codex بحساب ChatGPT».
- أبطأ من API، ويتسع الفارق مع طول المستند: في ملف README هذا،
  بلغ الوسيط 6 دقائق و46 ثانية لكل لغة باستخدام `gpt-5.6-sol`، مقابل 36 ثانية باستخدام
  `gemini-3.7-flash`.
- يُرفض في CI (عند تعيين `CI` أو `GITHUB_ACTIONS`): تتم مصادقة الاشتراك
  عبر ملف جلسة شخصي، لا مكان له على مشغّل
  مشترك.
- المتغيرات: `CODEX_BIN` و`CODEX_TIMEOUT` (ثوانٍ لكل مقطع، الافتراضي 600).

### ضمن اشتراك Grok:‏ `--use_grok_cli`

المبدأ نفسه مع CLI الرسمي Grok Build، ضمن اشتراك SuperGrok أو
X Premium+.

```bash
curl -fsSL https://x.ai/cli/install.sh | bash
grok login                                      # ou : grok login --device-code
aipmt --use_grok_cli --file README.md --target_dir . --target_lang pl
```

- **عزل أضعف من Codex.** لا يعمل عزل نظام التشغيل الخاص بـ Grok
  على كثير من أجهزة Linux الحديثة (AppArmor، ومقابس بيئة تشغيل
  الحاويات)، ويبدأ التشغيل بصمت دون عزل إذا تعذّر تطبيق ملف التعريف.
  لذلك لا يطلب البرنامج النصي أي ملف تعريف افتراضيًا، ويعلن ذلك،
  ويعتمد على قواعد `--deny` في CLI، بما فيها القاعدة الشاملة `*` — وهي
  الطبقة الوحيدة التي ترفض بدء التشغيل بدلًا من إزالة الحماية دون
  إبلاغ. يفرض `GROK_TRANSLATE_SANDBOX=read-only` عزل نظام التشغيل، ويفشل بدء التشغيل
  إذا تعذّر على الجهاز توفيره.
- الحصة أسبوعية، ومشتركة مع Chat وImagine وVoice، ولا يوجد
  أمر يتيح قراءتها: قد تستهلك دفعة من الملفات حصة المحادثات
  دون أي تنبيه.
- المتغيرات: `GROK_BIN` و`GROK_HOME` (مجلد CLI، الافتراضي `~/.grok`)،
  و`GROK_TIMEOUT` (الافتراضي 900)، و`GROK_TRANSLATE_SANDBOX`.

### ضمن اشتراك Google:‏ `--use_antigravity`

المبدأ نفسه مع `agy`، وهو CLI الرسمي لـ Antigravity: لمن يدفع مقابل Google
AI Pro أو Ultra، تُخصم الترجمة من حصة الاشتراك بدلًا
من فوترتها بحسب الرموز. وهذا هو المسار الوحيد إلى تلك الحصة: لم يعد Gemini CLI
يخدم هذه الحسابات منذ 18 يونيو 2026
([الإعلان](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/))،
ولا يقبل SDK الخاص بـ Antigravity سوى مفتاح API أو مشروع Google Cloud.

```bash
# agy 1.2.11 ou plus récent : https://antigravity.google/docs/cli/install/
agy                                  # une fois : se connecter avec le compte de l'abonnement
aipmt --use_antigravity --file README.md --target_dir . --target_lang en
agy -p /usage --output-format json   # quota restant, sans en consommer
```

- **لا يبقى أي مسار مدفوع مفتوحًا.** لا يتلقى agy من
  بيئتك سوى قائمة محددة من المتغيرات — `PATH`، واللغة والمنطقة الزمنية،
  والطرفية، والهوية، والوكلاء والشهادات، وناقل الجلسة — ولا يتلقى أي مفتاح:
  إذ إن عددًا من متغيراته يغيّر مسار الاستدعاء دون إظهار أي شيء (وفق القياس:
  يرسل أحدها المستند إلى بوابة خارجية، ويرسله آخر إلى مشروع
  Google Cloud مدفوع)، وكانت قائمة الحظر تُغفل بعضها في كل مراجعة.
  قبل أي مقطع، يجب أن يُظهر `agy -p /config`، الذي لا يستهلك أي حصة،
  تعطيل أرصدة الذكاء الاصطناعي المدفوعة، مع عدم وجود مفتاح API أو مشروع Google Cloud — ويُعدّ
  غياب أي إعداد سببًا للرفض — وإلا فلن يُترجم شيء؛ وبعد ذلك، يجب أن يثبت سجل كل
  استدعاء استخدام الاشتراك (`authMethod=consumer`)، وإلا
  تُرفض الاستجابة.
- **العزل.** يعمل كل استدعاء في مجلد شخصي خاص
  ومؤقت، مع وكيل ترجمة بلا أدوات: لا تدخله إعداداتك أو قواعدك
  أو إضافاتك أو خوادم MCP أو خطافات agy، ولا يُضاف شيء إلى
  سجلك، وتبقى بيانات تسجيل الدخول في سلسلة المفاتيح، التي لا يقرأها aipmt مطلقًا.
  إذا تعذّر العثور على الوكيل، يعود agy بصمت إلى وكيل البرمجة
  وأدواته: يجب أن يؤكد سطر كامل في السجل استخدام الوكيل الصحيح — ولا
  يحلّ محلّه مستند يقتبس تلك الرسالة — وإلا يُرفض الاستدعاء.
- **المنصات**: Linux، ضمن جلسة تتوفر فيها سلسلة مفاتيح (ناقل جلسة
  D-Bus، وSecret Service)؛ ويُقبل macOS، دون إجراء قياسات عليه. يُرفض
  تحت Windows، حيث لا يقرأ agy المتغيرات التي تعزل كل استدعاء، وكذلك
  تحت Linux دون ناقل جلسة — مثل جلسة SSH أو حاوية أو خادم: إذ يخزّن agy
  رمزه هناك في ملف ضمن `~/.gemini`، يحجبه العزل. ويحدث
  الرفض قبل أي تشغيل، مع بيان سببه، بدلًا من الانتظار دقيقة
  للحصول على رمز تسجيل الدخول.
- **النماذج**: النماذج الواردة في `agy models`. تتضمن أسماء نماذج Gemini مستوى الجهد
  (`gemini-3.8-flash-medium`…): يُرفض أي اسم بلا لاحقة قبل الاستدعاء،
  ولا يؤثر `--reasoning_effort`. الافتراضي هو `gemini-3.8-flash-medium`،
  و`gemini-3.7-flash-low` في وضع `--eco`؛ وتُوصف حملات القياس التي حددتها
  في [القياسات التفصيلية](#القياسات-التفصيلية). لدى Claude وGPT-OSS
  حصة خاصة بهما، أصغر بكثير: نحو 1 % من نافذة
  الساعات الخمس لكل استدعاء مقاس، مقابل 0,05 % في Flash.
- **الحصة**: لكل مجموعة نافذة مدتها 5 ساعات وأخرى أسبوعية،
  بما يتناسب مع تكلفة الرموز. وفق القياسات على حساب المؤلف: نحو
  16 نقطة من نافذة الساعات الخمس لكل مليون حرف مصدر في
  `gemini-3.8-flash-medium`، و14 في `gemini-3.7-flash-medium`، و7 إلى 8 عند
  الجهد المنخفض — لذا يستهلك ملف README من 40 000 حرف أكثر بقليل من
  نصف نقطة. أما الحد الأسبوعي فيعتمد على المستوى. تتبع إعادة المحاولة
  ما يصرّح agy بإمكان إعادة محاولته؛ وخلاف ذلك، لا تُعاد المحاولة مطلقًا
  عند نفاد حصة نافذة: بل يفشل كل ملف إلى حين إعادة التعيين
  التي يعرضها `/usage`.
- **أبطأ من API**: في مقالة القياسات الكثيفة، بلغ الوسيط 3 دقائق و59 ثانية لكل
  لغة في `gemini-3.8-flash-medium`، و3 دقائق و14 ثانية في
  `gemini-3.7-flash-medium`، مقابل دقيقة و18 ثانية لـ Gemini 3.7 Flash عبر API.
- **المقاطعة**: يؤدي Ctrl-C أو إغلاق الطرفية إلى إيقاف agy مع
  الأمر، بدلًا من تركه يُكمل دوره على حساب حصتك؛ وينطبق الأمر
  نفسه على Codex وGrok CLI وOpenCode. تحت `nohup`، تستمر الترجمة.
- يُرفض في CI (عند تعيين `CI` أو `GITHUB_ACTIONS`): تُحفظ بيانات تسجيل الدخول في
  سلسلة مفاتيح شخصية. على مشغّل، استخدم `--use_gemini` مع `GOOGLE_API_KEY`.
- المتغيرات: `AGY_BIN` (وإلا `PATH`، ثم `~/.local/bin/agy`)،
  و`AGY_TIMEOUT` (ثوانٍ لكل مقطع، بما فيها بدء التشغيل، الافتراضي 900).

**شروط الاستخدام: حسابك هو الذي يتحمل المسؤولية.** تحظر
[شروط Antigravity](https://antigravity.google/terms) (القسم 6) و
[الأسئلة الشائعة](https://antigravity.google/docs/faq/) الوصول إلى الخدمة
عبر برنامج تابع لجهة خارجية باستخدام تسجيل الدخول إلى Antigravity — وتذكر Claude Code
وOpenClaw وOpenCode — تحت طائلة تعليق الحساب. لا يقرأ aipmt
الرمز ولا يعيد استخدامه: بل يشغّل الملف التنفيذي الرسمي في
[الوضع دون واجهة](https://antigravity.google/docs/cli/headless/) الذي توثّقه Google
للبرامج النصية وCI. وقد وصف أحد أعضاء Google تشغيل `agy -p`
من برنامج نصي محلي لإنجاز عمل شخصي بأنه «اعتيادي»
([المنتدى الرسمي، 25 سبتمبر 2026، رد غير ملزم تعاقديًا](https://discuss.ai.google.dev/t/is-using-the-official-agy-cli-through-a-local-mcp-server-with-third-party-ai-agents-permitted/184829))؛
ولا يوجد نص يحسم حالة أداة موزّعة مثل هذه.

**المستندات العامة فقط.** وفقًا للقسم 5 من الشروط نفسها، قد تُستخدم
التبادلات — من مطالبات وردود وبيانات وصفية — لتحسين
منتجات Google والتعلّم الآلي لديها، وقد يطّلع عليها
بشر، حتى مع اشتراك مدفوع. ويجري الانسحاب عبر الإعداد
`enableTelemetry`، الذي لم يُوثّق تأثيره، ولا يضبطه aipmt؛ كما أن إعداداتك
في agy لا تنتقل إلى بيئته المعزولة. لا تمرّر عبره أي شيء سري.
### باستخدام اشتراك Claude: `--use_claude_code`

ينطبق المبدأ نفسه مع `claude`، وهو CLI الرسمي لـ Claude Code، في وضع `-p`: لمن
يدفع مقابل Claude Pro أو Max، تُخصم الترجمة من حصة
الاشتراك بدلًا من احتساب تكلفتها حسب عدد الرموز. ويجب عدم الخلط بينه وبين
`--use_claude`، وهو API الخاص بـ Anthropic، الذي تُحتسب تكلفته حسب الاستخدام.

```bash
claude                                   # une fois : /login avec le compte de l'abonnement
aipmt --use_claude_code --file README.md --target_dir . --target_lang en
```

- **لا يبقى أي مسار مدفوع متاحًا، وكل استدعاء يثبت ذلك.** لا يتلقى Claude
  Code من بيئتك سوى قائمة مغلقة من المتغيرات — لا
  مفتاح API، ولا رمز وصول، ولا مزوّد سحابي، ولا علامة تدل على جلسة Claude Code
  التي قد يُشغَّل منها aipmt. قبل المقطع الأول، يجب أن يُظهر `claude auth status`
  الاتصال عبر الاشتراك، دون مفتاح Console، وأن يؤكد ذلك `/usage`، الذي لا يستهلك
  أي حصة؛ ويؤكد كل استدعاء ذلك بدوره في
  حدث التهيئة، وإلا تُرفض الاستجابة.
- **عطّل «الاستخدام الإضافي»** (claude.ai، الإعدادات ← الاستخدام) لضمان
  بقاء التكلفة عند صفر يورو: عند تفعيله، يتولى العمل بعد نفاد حصة النافذة
  ويحتسب رسومًا دون إظهار خطأ. يوقف aipmt الترجمة فور أن يشير تقرير
  الحصة لأحد الاستدعاءات إلى ذلك، لكن هذا الاستدعاء يكون قد احتُسب بالفعل.
- **الحصة مشتركة مع جلسات Claude Code لديك.** يُبلغ كل استدعاء عن
  استهلاك نافذتي الساعات الـ 5 والأسبوع؛ وبعد تجاوز 80 %
  (`AIPMT_CLAUDE_MAX_UTILIZATION`)، لا يُبدأ أي مقطع إضافي، حتى لا
  تُستنفد الحصة اللازمة لعملك.
- **العزل.** يعمل كل استدعاء دون أدوات، في مجلد خاص
  مؤقت، وفي وضع بلا تخصيص: لا تُحمَّل ملفات `CLAUDE.md` لديك، ولا إضافاتك،
  ولا hooks، ولا خوادم MCP أو إعداداتك، ولا يُحتفظ بأي شيء من
  الجلسة. المرفقات معطّلة: يظل `@chemin` في مستندك
  نصًا ولا يفتح أي ملف (جرى التحقق بالقياس).
- **النماذج**: `sonnet` افتراضيًا، بمستوى الجهد `low`، وكذلك في `--eco`:
  لا يغيّر `--eco` شيئًا في هذا المسار. وفق القياس على المستندات نفسها، فإن `haiku`
  أبطأ بمرتين — إذ يستدل دون إمكانية منعه — مقابل
  تكلفة أقل بفارق طفيف، ويرفض `opus` محتويات في علم الأحياء (النقطة
  التالية). ويظل كلاهما متاحًا عبر `--model`؛ وتتبع هذه الأسماء البديلة
  أحدث نموذج في عائلتها. يُرفض `fable` والمتغيرات `[1m]`،
  لأنها تستخدم أرصدة مدفوعة. يضبط `--reasoning_effort` مستوى الجهد،
  الذي لا تستفيد منه الترجمة: فالاستدلال المقاس معدوم أو شبه معدوم.
- **يرفض Opus بعض محتويات علم الأحياء.** ضوابطه أشد
  صرامة من ضوابط Sonnet، وتحذّر رسالة الخطأ من Anthropic بأنها
  «قد تُصنّف أحيانًا أعمالًا قريبة من أبحاث علم الأحياء على أنها مخالفة». وفق القياس: أدّى خبر موجز
  عن 279 جزيئًا مولّدًا إلى رفض المقال في اللغات الأربع عشرة.
  لا يُكتب شيء: يرفض aipmt الاستجابة المبتورة، ويذكر
  ضوابط الحماية وينصح باستخدام `--model sonnet`.
- مرفوض في CI (عند تعيين `CI` أو `GITHUB_ACTIONS`) وعلى Windows (لم يُقَس).
- المتغيرات: `AIPMT_CLAUDE_BIN` (وإلا `PATH`، ثم `~/.local/bin/claude`)،
  `AIPMT_CLAUDE_TIMEOUT` (ثوانٍ لكل مقطع، الافتراضي 900)،
  `AIPMT_CLAUDE_MAX_UTILIZATION` (الافتراضي 0.8)، `CLAUDE_CONFIG_DIR` (حساب
  Claude Code، ولا يُؤخذ مطلقًا من `.env` خاص بالمشروع)؛ مجلدات العمل ضمن
  `XDG_CACHE_HOME/aipmt/claude-code` (الافتراضي `~/.cache`).

**شروط الاستخدام: حسابك هو الذي يتحمل المسؤولية.** لا تمنع
[الصفحة القانونية لـ Claude Code](https://code.claude.com/docs/en/legal-and-compliance)
«مستخدمًا نهائيًا من تسجيل الدخول إلى الملف التنفيذي غير المعدّل لـ Claude Code
باستخدام اشتراك Claude الخاص به»: وهذا ما يفعله aipmt، إذ يشغّل
الملف التنفيذي الرسمي ولا يقرأ رمز الوصول مطلقًا. لكن Anthropic «لا تسمح
لمطوّري الجهات الخارجية […] بتوجيه الطلبات عبر بيانات اعتماد خطط Free أو Pro أو Max
نيابة عن مستخدميهم»، وتفضّل مفتاح API للأدوات
الخارجية، «بما في ذلك المشاريع مفتوحة المصدر»، وتحتفظ بحق خصم
استخدامها من الأرصدة المدفوعة
([مساعدة Claude](https://support.claude.com/en/articles/13189465-logging-in-to-your-claude-account)).
ولا يوجد نص يحسم حالة أداة موزّعة تشغّل الملف التنفيذي.

**البيانات**: في حسابات Free وPro وMax، ينطبق تدريب النماذج
أيضًا على Claude Code عندما يسمح إعداد الخصوصية بذلك
([صفحة البيانات](https://code.claude.com/docs/en/data-usage)). لا يحتفظ aipmt
بأي سجل محادثة محلي (`--no-session-persistence`). لا تمرّر عبره
أي معلومات سرية.

### إلى المزوّد الذي تختاره: `--use_opencode`

[OpenCode](https://opencode.ai) وكيل برمجة مفتوح المصدر (MIT)
يوجّه الطلبات إلى المزوّدين المُعدّين فيه: مفتاح API، أو اشتراك،
أو بوابة OpenCode Zen (نماذج مجانية، دون حساب)، أو نموذج محلي. جرى
قياس مسارين من البداية إلى النهاية هنا، هما Zen وOllama.

```bash
curl -fsSL https://opencode.ai/install | bash   # ou : npm install -g opencode-ai
opencode models                                 # les modèles, au format provider/modèle
opencode auth login                             # facultatif : brancher un fournisseur

# gratuit, sans compte ni clé — données utilisables pour l'entraînement
aipmt --use_opencode --model opencode/mimo-v2.5-free --file README.md --target_dir . --target_lang en
# local, hors ligne
aipmt --use_opencode --model ollama/qwen2.5:7b --file README.md --target_dir . --target_lang de
# sur un abonnement déjà payé
aipmt --use_opencode --model github-copilot/gpt-5 --file README.md --target_dir . --target_lang ja
```

`--model` إلزامي: بدونه، سيعود OpenCode إلى نموذج مجاني
قد تُستخدم تبادلاته في التدريب، ولا يُتخذ هذا القرار
نيابة عنك.

العزل في كل استدعاء:

- يحدّد إعداد مضمّن، له الأولوية على إعدادك، وكيلًا `aipmt`
  تُمنع جميع أدواته (`permission: { "*": "deny" }`)، مع تعطيل مشاركة
  الجلسة، و`--pure`، وليس `--auto` مطلقًا؛
- مجلد عمل مؤقت وفارغ، مع تعيين `OPENCODE_DISABLE_PROJECT_CONFIG` و
  `OPENCODE_DISABLE_CLAUDE_CODE` — بدونهما، يدرج OpenCode في
  الموجّه `AGENTS.md` من المجلد الحالي و`~/.claude/CLAUDE.md`. ويظل
  `~/.config/opencode/AGENTS.md` العام مُدرجًا، إذ لا يسمح OpenCode
  باستبعاده؛
- شروط المخرجات: رمز خروج 0، وعدم وجود أي حدث `error` أو أي استدعاء
  لأداة، وأن تكون الخطوة الأخيرة في `stop`، وأن يكون النص غير فارغ، وأن يكون الوكيل `aipmt`
  قد حُمّل بالفعل — فاستخدام `--agent` غير معروف لا يؤدي إلى فشل OpenCode، بل
  يعود بصمت إلى وكيل البرمجة؛
- لا يُمرَّر أي مفتاح من `aipmt`، باستثناء `OPENCODE_API_KEY`، وهو مفتاح
  OpenCode نفسه. يُضبط المزوّدون في OpenCode، لا في
  `.env` الخاص بـ `aipmt`.

ما ينبغي معرفته:

- تتغيّر نماذج Zen المجانية، وحدودها غير موثّقة،
  وقد تُستخدم تبادلاتها في التدريب: تصلح للتوثيق
  العام، لا للمحتوى الخاص.
- يجب أن يوفّر النموذج المحلي سياقًا لا يقل عن 16 k رمز، إذ تصل المقاطع
  إلى 16 000 محرف. وغالبًا ما يضبط Ollama السياق على 4 096: استخدم
  `Modelfile` مع `PARAMETER num_ctx 32768`.
- ليس لـ `--eco` أي تأثير؛ ويُمرَّر `--reasoning_effort` كما هو بوصفه
  `--variant` في OpenCode.
- يسجّل OpenCode كل جلسة في `~/.local/share/opencode/`.
- المتغيرات: `OPENCODE_BIN` (وإلا `PATH`، ثم `~/.opencode/bin/opencode`)،
  `OPENCODE_TIMEOUT` (ثوانٍ لكل مقطع، الافتراضي 600). يُمرَّر `OPENCODE_CONFIG`
  كما هو إلى OpenCode.

مثال لنموذج محلي عبر Ollama، في `~/.config/opencode/opencode.json`:

```bash
ollama pull gpt-oss:20b
printf 'FROM gpt-oss:20b\nPARAMETER num_ctx 32768\n' > gpt-oss-20b-32k.Modelfile
ollama create gpt-oss-20b-32k -f gpt-oss-20b-32k.Modelfile
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama (local)",
      "options": { "baseURL": "http://127.0.0.1:11434/v1" },
      "models": {
        "gpt-oss-20b-32k": {
          "name": "gpt-oss 20B (32k, sans réflexion)",
          "limit": { "context": 32768, "output": 8192 },
          "options": { "reasoningEffort": "none" }
        }
      }
    }
  }
}
```

يعطّل `reasoningEffort: "none"` التفكير الذي يفعّله Ollama افتراضيًا في هذه
النماذج، والذي لا يستطيع Modelfile تعطيله. وفق القياس على جملة من
ست كلمات: 919 رمز تفكير و68 ثانية دون الخيار، و9 رموز معه.

### إلى أكثر من 400 نموذج: `--use_openrouter`

OpenRouter موجّه تُحتسب تكلفته حسب الاستخدام، من رصيد موحّد، ويوفّر الوصول إلى
نماذج تستضيفها جهات خارجية — بما فيها النماذج الصينية المفتوحة التي لا
يوفّرها أي مزوّد آخر هنا.

```bash
aipmt --use_openrouter --model z-ai/glm-5.2 --file README.md --target_dir . --target_lang en
```

`--model` إلزامي. يعالج فحص مسبق، يُنفَّذ قبل احتساب أي رسوم،
خاصيتين للتوجيه:

- **تقدّم عشرات الجهات المستضيفة النموذج نفسه بحدود قصوى
  مختلفة** — في `z-ai/glm-5.3-flash`، توجد 23 جهة مستضيفة، إحداها محدودة بـ
  2 048 رمز إخراج. يقرأ الفحص المسبق `/api/v1/models/{modèle}/endpoints`،
  ويستبعد الجهات التي يقل حدها عن 8 000 رمز إخراج أو التي تعاني تراجعًا في الخدمة،
  ويثبّت الجهات الأخرى باستخدام `allow_fallbacks: false`.
- **تُحتسب تكلفة الاستدلال بسعر الإخراج** — 107 رموز مقابل 2
  لاستجابة «حسنًا» من `z-ai/glm-5.2`. يُعطَّل افتراضيًا؛ أما النماذج
  التي تفرضه فتتلقى أدنى مستوى جهد تقبله، لأن القيمة الافتراضية في
  الفهرس قد تستنفد سعة الإخراج قبل اكتمال الترجمة.
  وتبقى الأولوية لـ `--reasoning_effort`.

```
→ OpenRouter : 30 hébergeur(s) épinglé(s) sur 33, contexte 1048576 tokens,
  sortie plafonnée à 32768, raisonnement coupé
```

- تُؤخذ نافذة السياق من الفهرس. يُرفض أي نموذج يقل سياقه عن 16 400 رمز
  قبل أي استدعاء: 8 400 للموجّه والمقطع، و8 000 للإخراج
  كحد أدنى.
- يؤدي غياب المعرّف من الفهرس، أو تعذّر الوصول إلى الفهرس، أو عدم وجود
  جهة مستضيفة تستوفي الحد المطلوب إلى إيقاف الأمر.
- يشير `finish_reason=length` مع إخراج فارغ إلى ميزانية استهلكها
  الاستدلال، لا إلى اقتطاع: وتوضّح الرسالة هذا الفرق.
- ليس لـ `--eco` أي تأثير.
- المتغيرات: `OPENROUTER_API_KEY` (<https://openrouter.ai/keys>)،
  `OPENROUTER_BASE_URL` (الافتراضي `https://openrouter.ai/api/v1`، و`https://`
  مطلوب)، `OPENROUTER_TIMEOUT` (الافتراضي 900)، `OPENROUTER_PREFLIGHT_TIMEOUT`
  (الافتراضي 30).

### ملاحظة الترجمة

يضيف `--add_translation_note` ملاحظة، في `bottom` (الافتراضي)، أو `top` (بعد
البيانات الوصفية الافتتاحية)، أو `both` (`--note_position`)، بتنسيق `legacy` (فقرة
بخط عريض، وهو الافتراضي) أو `marker` (`--note_format`). والتنسيق `marker` هو
تعريف مرجع Markdown غير مرئي،
`[ai-translation-note-<placement>]: <> "v=1 source=… target=… model=… date=…"`،
يتبعه اقتباس بخط عريض: يمكن قراءته على GitHub، والاستفادة منه أثناء البناء عبر
إضافة remark.

```bash
aipmt --file article.mdx --target_lang en --add_translation_note --note_format marker --note_position top
```

## القياسات التفصيلية

جميع القياسات تخص ترجمات نُفّذت فعليًا باستخدام `aipmt`، إلى
أربع عشرة لغة: en، es، de، it، pt، nl، pl، sv، ro، ja، ko، zh، ar، hi.
يُحصي **المكتوبة** الملفات التي سمحت آليات التحقق بمرورها؛ ويُحصي **دون
اختلاف** الملفات التي لم يرصد فيها `scripts/compare_structure.py` شيئًا — أي العدد نفسه من
الأقسام، والعناوين الفرعية، والروابط، وعناوين URL المميزة، وكتل الشيفرة،
والشيفرات المضمّنة، وصفوف الجداول، وكتل الاقتباس، والكلمات بخط عريض.

تعني «دون اختلاف» أنه «لم يُكتشف شيء»، وليس أنها «مطابقة»: فالمقارن
يعدّ العناصر دون قراءة محتواها. ولا يكشف عن حذف عنوان من
المستوى 4، أو استبدال نص شيفرة مضمّنة، أو تبديل
علم، أو إخراج رابط داخلي بقوس زائد،
`[texte]((#ancre))`، بحيث لا يعود يؤدي إلى أي مكان — كما أنه لا يقيّم
اللغة.

علم. لم يكتب `opus` أي لغة: ففي كل لغة، أوقفت ضوابطه
الاستجابة عند المقطع الأخير، بسبب خبر موجز عن 279 جزيئًا
مولّدًا لموقع ارتباط. وعند إرسال هذا الخبر منفردًا، رُفض
ضمن فئة «علم الأحياء»؛ بينما ترجمه `sonnet` في جميع اللغات. يكتب `haiku`
اللغات الأربع عشرة؛ وفي ثلاث منها (en، pl، ro)، ينتقل عنوان قسم من
المستوى 2 إلى المستوى 1. وهو يستدل دون إمكانية منعه — ويستهلك ذلك 61 % من
رموز إخراجه —، ولذلك يستغرق أكثر من ضعف وقت `sonnet`.

قِيست صفوف `claude-sonnet-5-5` و`claude-haiku-5-5` و`claude-haiku-4-5`
يوم 18 أكتوبر عبر API الخاص بـ Anthropic، على المقال نفسه، بأربع
ترجمات بالتوازي لكل نموذج. يرفض Sonnet 5.5 تعطيل
تفكيره: يرسل إليه aipmt أدنى إعداد يقبله، ولا تحمل
استجاباته أي أثر للتفكير. يكتب اللغات الأربع عشرة دون اختلاف ودون
إعادة معالجة أي مقطع؛ وفي الإنجليزية، أزال بنفسه أسطر
الترجمة الفرنسية، دون اختلاق علم، وظلت الاقتباسات الإنجليزية
سليمة في جميع اللغات. قِيس Haiku 5.5 باستخدام تفكيره التكيّفي: فعند تعطيل
التفكير، كان يترك فقرات كاملة بالفرنسية، وهو ما ترفضه آلية التحقق —
فكُتبت 3 لغات من أصل 14. يتعثر نموذجا Haiku عند الخبر الموجز نفسه: يغيّر Haiku 5.5
مستوى عنوانه أو يكرّره في اليابانية والكورية
والصينية، وينقله Haiku 4.5 إلى المستوى 1 في سبع لغات، ويتركه
بالفرنسية في الترجمة اليابانية. تبلغ تكلفة Haiku 4.5 مبلغ 3,67 $ للمستندين باللغات
الأربع عشرة، وHaiku 5.5 مبلغ 0,57 $، وSonnet 5.5 مبلغ 9,21 $.

### ما لا تمثله هذه القياسات

- **ليست تصنيفًا شاملًا**: يتيح OpenRouter وحده أكثر من أربعمئة
  نموذج، بينما قِيس نحو خمسة عشر نموذجًا.
- **مدد استرشادية**: من ثلاث إلى ست ترجمات بالتوازي بحسب
  حملة الاختبار، ويتغير معدل معالجة المزود خلال اليوم.
- **ملاحظات مرتبطة بتاريخها**: تتغير النماذج مع بقاء الاسم نفسه، كما أن
  مستنداتكم تختلف عن مستنداتنا.

لإعادة القياس على مستنداتكم، باستخدام نسخة ثابتة من الملف:

```bash
aipmt --file reference.md --target_dir out/ --source_lang fr --target_lang ja --use_gemini --force
aipmt --file veille.mdx   --target_dir out/ --source_lang fr --target_lang ja --use_gemini --news --force
python scripts/compare_structure.py reference.md out/reference-ja.md
# « structure identique », ou la liste des écarts — sortie 0 si identique, 1 sinon
```

## المساهمة

```bash
git clone https://github.com/jls42/ai-powered-markdown-translator.git
cd ai-powered-markdown-translator
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt   # les dépendances, lock entièrement épinglé
pip install -e .                  # le paquet lui-même, en mode éditable
```

كلا السطرين ضروري: من دون `pip install -e .`، يرد `python -m aipmt`
بـ`No module named aipmt`.

أدوات الجودة، اختيارية لكن موصى بها:

```bash
pipx install pre-commit               # hors venv — absent des requirements
pip install -r requirements-dev.txt   # detect-secrets, pip-audit, mypy, lizard
pre-commit install                    # hooks rapides à chaque commit
pre-commit install --hook-type pre-push  # mypy, SAST, pip-audit, tests avant chaque push
```

تُعاد توليد ترجمات المستودع البالغ عددها 28 ترجمة (README وCHANGELOG، بأربع عشرة لغة)
باستخدام `./regen_translations.sh --force` — عبر Codex و`gpt-6.1-sol` على
اشتراك ChatGPT افتراضيًا، أربع ترجمات بالتوازي. يغيّر `REGEN_PROVIDER` و
`REGEN_MODEL` المسار: يظل `antigravity` معتمدًا على اشتراك، وهو اشتراك
Google، ويُسمح به دون استثناء؛ أما API المدفوعة (`openai` و`gemini`،
و`grok` و`openrouter`) فتُرفض دون `REGEN_ALLOW_PAID_API=1`؛
ويحدد `REGEN_JOB_TIMEOUT` الحد الأقصى لمدة كل مهمة (600 s، و1 800 s على Codex و
Antigravity). تفاصيل الأدوات موجودة في `CLAUDE.md`.

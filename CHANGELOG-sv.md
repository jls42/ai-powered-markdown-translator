- **1.19.1** `--use_codex --eco` återgår till GPT-5.6 Luna, som förbrukar mindre kvot; sökvägen för en fil utanför källkatalogen visas som den angavs (2026-11-15):

- **1.18.0** Gemini övergår till 3.8 Flash, återförsöker vid tillfälliga avbrott och väntar inte längre obegränsat; Python 3.11 som lägsta krav och Python 3.15 testat; den nya huvudversionen av Geminis SDK är validerad (2026-11-15):

  - **`--use_gemini` övergår till Gemini 3.8 Flash.** Google fasade ut Gemini 3.7 Flash den 8 oktober: den har tagits bort från AI Studio, och dess slutpunkt levererar Gemini 3.8 Flash i dess ställe. Standardinställningen i aipmt namngav alltså en modell som inte längre var den som översatte. Den 14 november förbrukade ett tjugotal anrop till 3.7 Flash på API:ets gratisskikt hela dags-kvoten för 3.8 Flash. Priset och resonemangsnivåerna ändras inte, och `--model gemini-3.7-flash` stöds fortfarande. Uppmätt den 15 november på gratisskiktet med en kort fil översatt två gånger med identisk struktur: 3.8 Flash avvisar resonemang med `minimal`, precis som 3.7, och accepterar nästa nivå, men det tog 4 och sedan 8 minuter när Google rapporterade hög belastning; föregående kväll svarade `--eco` på en sekund. Modellen för `--eco`, Gemini 3.1 Flash Lite, avvecklas den 7 maj 2027: dess utsedda ersättare, Gemini 3.5 Flash Lite, kommer att utvärderas innan den tar dess plats.

  - **Ett tillfälligt avbrott hos Gemini kostar inte längre hela filen.** Googles SDK gör inga återförsök som standard: vid första ”503 high demand” avbröt aipmt filen, trots att samma fel återförsöks på Antigravity sedan 1.17.1. Felkoder 503, 429 eller överskriden tidsgräns leder nu till att anropet återförsöks upp till tre gånger, efter 10, 20 och sedan 40 sekunder. Förbrukad förbetald kredit eller en avvisad förfrågan misslyckas fortfarande omedelbart.

  - **Ett Gemini-anrop utan svar låser inte längre aipmt.** SDK:t väntade utan tidsgräns: den 14 november hängde sig en översättning i över fem minuter i väntan på en tyst server tills den avbröts. Varje försök avbryts nu efter 5 minuter och återförsöks sedan som ett tillfälligt avbrott: en tyst server gör att segmentet misslyckas efter som mest ett tjugotal minuter. aipmt kräver för detta en tillräckligt ny version av Gemini SDK för att kunna göra återförsök vid överskriden tidsgräns, och pip uppdaterar den vid behov.

  - **Återförsök med Gemini syns.** Googles SDK loggar sina återförsök i en logg som ingen visar: fyra minuters väntan på en liten fil gick inte att skilja från att processen låst sig. Varje återförsök visas nu, med felet och väntetiden: den 15 november, en ”504 DEADLINE_EXCEEDED” efter 5 minuter, som lyckades vid återförsök 10 sekunder senare. Varningarna som SDK:t redan visade visas fortfarande.

  - **Den nya huvudversionen av google-genai, validerad med ett verkligt anrop.** Detta SDK tillhandahåller inte längre `httpx`, som har blivit ett tillval, och byter till `httpx2`. aipmt importerar varken det ena eller det andra och dess översättningsanrop ändras inte. En Markdown-guide översatt i `--eco` av `gemini-3.1-flash-lite`, med denna version, behåller identisk struktur med källan. Endast ett test konstruerade ett Anthropic-fel med `httpx`: under Python 3.11 och 3.12 fanns det inget som installerade det längre, och testsviten misslyckades redan vid import. Det använder nu `httpx2`, precis som SDK:erna för Anthropic och Mistral.

  - **Python 3.11 blir lägsta version.** Python 3.10 underhålls inte längre sedan den 1 oktober 2026, och den nya huvudversionen av google-genai, publicerad den 6 november, kan endast installeras från och med Python 3.11; sex andra paket i de låsta versionerna kräver det också. Under Python 3.10 installerar pip nu endast 1.17.1, den sista versionen som stöder den.

  - **Python 3.15 testas.** Testsviten körs på varje Python-version från 3.11 till 3.15, med paketet installerat och dess beroenden hämtade vid sina publika gränser. SonarCloud-analysen, beroendekontrollen och publiceringen på PyPI körs under Python 3.15.

  - **Beroenden.** I de låsta versionerna har `anthropic`, `openai` och `mistralai` fått sina mindre uppdateringar, föreslagna av Dependabot och automatiskt sammanslagna. `pyasn1`, som medföljer Googles autentisering, har fått en rättning för fyra säkerhetsvarningar med hög allvarlighetsgrad: avkodningar med kvadratisk komplexitet som manipulerade data kunde få att ta mycket lång tid. En installation från PyPI använde redan den åtgärdade versionen. `httpx` och `httpcore` tas bort från de låsta versionerna eftersom inget paket längre efterfrågar dem. Åtgärderna för Python-installation, PyPI-publicering och SonarCloud-analys har uppdaterats manuellt.

- **1.16.3** Filslut: en översättning via API behåller källans avslutande radbrytning, och SDK 3.0 för Mistral är validerat (2026-10-04):

  - **En översättning via API behåller källans avslutande radbrytning.** API-leverantörer — OpenAI, Anthropic, Gemini, Mistral — rensar modellens svar från omgivande blanksteg. På det sista segmentet tog denna rensning bort källans avslutande radbrytning: en översatt fil utan översättarnot avslutades utan radbrytning, vilket git varnar för och som formateringsverktyg korrigerar vid varje körning. Detta upptäcktes vid valideringen av SDK 3.0 för Mistral, på en guide som slutade med en radbrytning vars översättning inte längre hade någon. Översättarnoten lade tillbaka en, och kommandoradsleverantörer — Codex, Grok CLI, Antigravity, Claude Code, OpenCode — kopierar segmentets slut: endast en översättning via API utan not berördes. Översättningen återger nu källans avslutande radbrytning, oavsett leverantör, och lägger inte till någon om källan saknar den.

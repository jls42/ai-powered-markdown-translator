    - Neue CLI-Optionen (additiv, unveränderte Standardwerte → **nicht abwärtsinkompatibel**) :
      - `--note_position {top,bottom,both}` (Standard: `bottom`): platziert die Notiz oben, unten oder an beiden Stellen der übersetzten Datei.

        - `legacy` reproduziert das Verhalten von v1.8 strikt (fetter Absatz `**…**`) **byte-for-byte**.
        - `marker` gibt eine unsichtbare Markdown-Link-Referenzdefinition (`[ai-translation-note-<placement>]: <> "v=1 source=… target=… model=… date=…"`) aus, gefolgt von einem strukturierten **Blockquote mit 3 Absätzen** für eine Darstellung als „GitHub repo embed card“: Projekttitel als Inline-Code (`**\`ai-powered-markdown-translator\`\*\*`), vom LLM übersetzte Beschreibung und CTA-Link (`[Voir le projet sur GitHub ↗](URL)`) mit sichtbarem Pfeil. Kann beim Build von einem remark-Plugin verarbeitet werden (siehe Blog jls42.org → Plugin `remark-translation-banner`).

Dies entspricht dem Validator im Astro-remark-Plugin und neutralisiert Zeichen, die das Marker-Format beschädigen würden (Leerzeichen, Anführungszeichen, Klammern, Kommas usw.).
